## Accomplished

Feature session — issue #5064 (`feat(Ch5 #4905 glue-3): character of (A/det)_d as
an antitone-indexed Schur sum`). Added, sorry-free, in
`Chapter5/CauchyDetQuotientDegree.lean`:

- `quotDetDegree_char_as_antitone_sum (N d)`: the deliverable. For every `d`,
  `formalCharacter k N (quotDetDegreeFDRep k N d) = ∑ ν ∈ S, (c ν : ℚ) • schurPoly N ν.val`
  with `S : Finset {l : Fin N → ℕ // Antitone l}`, `c : {l // Antitone l} → ℕ`, and
  every `ν ∈ S` carrying a zero coordinate — the exact input shape consumed by
  `simple_constituent_formalCharacter_eq_schurPoly_mem` (the #4905 final assembly).

Supporting lemmas (all sorry-free, `#print axioms` clean = `[propext,
Classical.choice, Quot.sound]`):

- `schurPoly_eval_one_isNat (k) (l) (hl : Antitone l)`: the Schur dimension
  `s_l(1,…,1) = eval₁(schurPoly N l)` is a natural number. Proof: `eval_eq'` writes it
  as the sum of coefficients over the support; each coefficient is a weight-space
  dimension `dim (L_l)_μ = [x^μ] s_l` by `schurModule_weight_eq_schurPoly_coeff`, a
  `Nat.cast`. (k must be an explicit parameter — the statement is k-independent so the
  section variable is not auto-included.)
- `boundedToAntitone` / `boundedToAntitone_injective`: the injection
  `BoundedPartition N d ↪ {l // Antitone l}`, `ν ↦ ⟨ν.parts, ν.decreasing⟩`.
- `detSubmodule_inf_homogeneous_lt (d) (hd : d < N)`: `(det) ∩ A_d = ⊥` for `d < N`
  (det homogeneous of degree N, so the ideal misses degree `d < N`). Mirrors the
  homogeneous-component computation in `homogeneousComponent_detPoly_mul`.
- `quotDetDegree_formalCharacter_eq_polyRight_of_lt (d) (hd : d < N)`:
  `char (A/det)_d = char A_d` for `d < N`, via injectivity (from the inf-bot lemma) +
  surjectivity + equivariance of the quotient projection and `formalCharacter_eq_of_rep_iso`.

Two-case proof of the main result: `d ≥ N` translates the part-B formula
`quotDetDegreeFDRep_formalCharacter` along `boundedToAntitone` (`Finset.sum_image`);
`d < N` uses the iso to the full Cauchy character `polyRightDegreeFDRep_formalCharacter`,
with the zero-coordinate property following from pigeonhole (N antitone coordinates
summing to `d < N` force a zero part).
