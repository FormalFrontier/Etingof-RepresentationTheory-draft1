- `spechtComplexRatBaseChangeEquiv n la :
    ℂ ⊗[ℚ] ↥(SpechtModuleK ℚ n la) ≃ₗ[ℂ] ↥(SpechtModuleK ℂ n la)` — the `ℂ`-linear iso.
- `spechtComplexRatBaseChangeEquiv_equivariant n la σ` — it intertwines the base-changed

  `ℂ`-action `ρ_ℂ(σ) = spechtModuleActionK ℂ n la σ` (both the existing left-multiplication-by
  `of σ` actions). So it is an iso of `S_n`-representations.

## Method (build, don't search)

`SpechtModuleK k n la = k[S_n]·c_λ` with `c_λ = mapRange(YoungSymmetrizerZ)` over ℤ. Let
`j = mapRingHom (algebraMap ℚ ℂ) : ℚ[S_n] →+* ℂ[S_n]`. Define the scalar-extension map

```
Ψ = (g).liftBaseChange ℂ : ℂ ⊗_ℚ ↥V_λ(ℚ) →ₗ[ℂ] ℂ[S_n],   g v = j v,   Ψ(z ⊗ v) = z • j v.
```

Three ingredients, each a clean Mathlib hook:

1. **Range = V_λ(ℂ)** via `LinearMap.range_liftBaseChange` (`range Ψ = span ℂ (range g)`), then a
   span double-inclusion using `j c_ℚ = c_ℂ` (`jHom_youngSymmetrizer`) and `j` multiplicative.
   The ⊇ direction: `Finsupp.induction_linear` on `b` showing every `b * c_ℂ ∈ span ℂ (range g)`
   (each `of σ * c_ℂ = g ⟨of σ * c_ℚ, _⟩`).
2. **Injective** via flatness: `Ψ = finsuppScalarRight ∘ lTensor ℂ (incl)` and
   `Module.Flat.lTensor_preserves_injective_linearMap` (ℂ is free, hence flat, over ℚ) makes
   `lTensor ℂ` of the injective inclusion `V_λ(ℚ) ↪ ℚ[S_n]` injective;
   `TensorProduct.finsuppScalarRight ℚ ℂ ℂ G : ℂ ⊗[ℚ] (G →₀ ℚ) ≃ₗ (G →₀ ℂ)` is an equiv.
3. **Equivariance** is one line of algebra: `j (of σ * x) = of σ * j x` and `mul_smul_comm`.

Then `Φ = (LinearEquiv.ofInjective Ψ).trans (LinearEquiv.ofEq … psiMap_range)`; the target
`↥((SpechtModuleK ℂ).restrictScalars ℂ)` is defeq to `↥(SpechtModuleK ℂ)` so the corestriction
lands directly, and `(Φ t : ℂ[S_n]) = Ψ t` holds by `rfl`.

## Key Mathlib API discovered (reusable)

- `LinearMap.liftBaseChange` / `liftBaseChange_tmul` / `range_liftBaseChange`
  (`Mathlib/RingTheory/TensorProduct/Basic.lean`): `A`-linear map out of `A ⊗_R M`, range is
  `span A (range l)`. The clean way to build + analyse a base-changed map into an `A`-module.
- `TensorProduct.finsuppScalarRight R S M ι : M ⊗[R] (ι →₀ R) ≃ₗ[S] (ι →₀ M)` (note: only four
  explicit args — `N` is unused). `MonoidAlgebra ℚ G` is defeq `G →₀ ℚ`, so this gives the
  group-algebra base-change `ℂ[S_n] ≅ ℂ ⊗_ℚ ℚ[S_n]` even though `S_n` is **non-commutative**
  (`MonoidAlgebra.scalarTensorEquiv` needs `CommMonoid` and is unusable here).
- `Module.Flat.lTensor_preserves_injective_linearMap [Flat R M] f hf` — flatness ⇒ `lTensor`
  preserves injectivity. The honest replacement for "rational vectors ℚ-indep ⇒ ℂ-indep".
- `AddMonoidHom.toRatLinearMap` — turn the additive `mapRingHom` into a `ℚ`-linear map.
- `Submodule.restrictScalars_mem`, `LinearEquiv.ofInjective`, `LinearEquiv.ofEq`.
