## Accomplished

One-shot dispatch on issue #5679 (Discussion_5.25.1: number of conjugacy
classes per type in GL₂(𝔽_q)). The initial formalization had already landed on
`main` (PR #5803): the four `numXClasses` definitions plus `numScalarClasses_eq
= q−1` were proved in full, with parabolic/split/elliptic counts and the grand
total `card_conjClasses_eq = q²−1` left as top-down `sorry`s.

This turn advanced `EtingofRepresentationTheory/Chapter5/GL2ConjugacyClassCount.lean`:

- Added conjugacy-transfer lemmas `GL2.isScalar_of_isConj`,
  `isParabolic_of_isConj`, `isSplitSemisimple_of_isConj` (the type predicates are
  class functions), built from the existing `*_conj_iff` invariance lemmas.
- Added `GL2.disjoint_conjImage`: two type-images under `ConjClasses.mk` are
  disjoint when no conjugate pair realises both predicates.
- Proved `GL2.card_conjClasses_eq_sum` **in full** (no sorry): the total number
  of conjugacy classes equals the sum of the four type counts, via a genuine
  partition of `ConjClasses (GL₂)` into the four `ConjClasses.mk`-images
  (exhaustiveness from `GL2.conjugacyClass_exhaustive`, pairwise disjointness
  from the transfer lemmas + element-level disjointness).
- Rewrote `GL2.card_conjClasses_eq` (previously an isolated `sorry`) to **derive**
  `q²−1` from `card_conjClasses_eq_sum` + the four per-type counts + the ℕ
  arithmetic identity `(q−1)+(q−1)+(q−1)(q−2)/2+q(q−1)/2 = q²−1` (exact because
  `q = pⁿ` is odd and ≥ 3).

Net: direct `sorry`s in the file drop from 4 to 3; a new fully-proved partition
lemma is added, and the headline total is no longer an independent sorry.
