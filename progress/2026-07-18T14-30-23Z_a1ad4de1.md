## Accomplished
Proved `so3_tetrahedral_of_poleData` (Ch4 Problem 4.12.8, issue #6960) sorry-free —
the tetrahedral disjunct `{2,3,3} → A₄` of the SO(3) finite-subgroup classification.

Route taken (fully group-theoretic, avoiding any geometric "lands in A₄" argument):
1. The counting identity on `{2,3,3}` (RHS sum `1/2 + 2/3 + 2/3 = 11/6`) forces `|G| = 12`.
2. Pick an order-`3` pole `b` (from `hpole 3`); its `G`-orbit has `4` elements by
   orbit-stabilizer (`orbitProdStabilizerEquivGroup`).
3. `G` acts faithfully on this 4-pole orbit: a kernel element `g ≠ 1` would fix all four
   poles, but a nontrivial SO(3) rotation fixes only `{v₀, -v₀}` (2 poles) —
   `nontrivial_fixed_unit_vectors` + `Nat.card_le_card_of_injective` gives `4 ≤ 2`, absurd.
4. Transport the faithful action to `Fin 4` via `Equiv.permCongrHom`, obtaining
   `G ≃* H ≤ S₄` with `|H| = 12`, hence `H.index = 2`.
5. `Equiv.Perm.eq_alternatingGroup_of_index_eq_two` gives `H = alternatingGroup (Fin 4)`;
   compose `MonoidHom.ofInjective` with `MulEquiv.subgroupCongr` for the final iso.

Key discovery: `Equiv.Perm.eq_alternatingGroup_of_index_eq_two` (the alternating group is the
unique index-2 subgroup of `Sₙ`) turns the hard realization into a pure cardinality argument.
This same pattern applies directly to the octahedral (#6961, `{2,3,4}→S₄`, `|H|=24=|S₄|` so
`H=⊤`) and icosahedral (#6962, `{2,3,5}→A₅`, `|H|=60`, index-2 in `S₅`) cases.
