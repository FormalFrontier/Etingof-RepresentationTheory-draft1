## Accomplished

Closed issue #5172 (coverage gap from #5137): formalized the **base-point
independence** of the little-group construction for irreps of `G ⋉ A` (A
abelian) in `EtingofRepresentationTheory/Chapter5/Theorem5_27_1.lean`.

New public theorem (sorry-free):

```
Etingof.inducedRepV_basepoint_independent
  (φ : G →* MulAut A) {χ₁ χ₂ : A →* ℂˣ} {g : G} (hg : dualSmulAux φ g χ₁ = χ₂)
  (U : FDRep ℂ ↥(stabAux φ χ₁)) :
  Nonempty (inducedRepV φ χ₂ (transportRep φ hg U) ≅ inducedRepV φ χ₁ U)
```

i.e. when `χ₂ = g · χ₁`, `V_(O,χ₂,g(U)) ≅ V_(O,χ₁,U)` as `A ⋊[φ] G`-reps, where
`g(U)` (= `transportRep`) is `U` transported along the conjugation iso
`G_{χ₂} ≅ G_{χ₁}`.

Supporting private machinery added:
- `dualSmulAux_mul`, `dualSmulAux_one` (dual action is a left action).
- `stabAux_conj_mem` / `stabAux_conj_mem'` (conjugation by `g⁻¹`/`g` maps the
  stabilizers into each other).
- `conjStabHom : G_{χ₂} →* G_{χ₁}` and `transportRep` (= `g(U)`).
- `cosetEquiv : G ⧸ G_{χ₁} ≃ G ⧸ G_{χ₂}` (`[p] ↦ [p·g⁻¹]`) and
  `cosetEquiv_smul` (commutes with the left `G`-action).
- `wElt` (the `G_{χ₁}` bookkeeping element correcting representative mismatch).
- `rhoEquiv`, `baseChangeEquiv` (the underlying `ℂ`-linear iso
  `f ↦ (p ↦ ρ_U(w p)(f(p·g⁻¹)))`).
- `baseChange_comm_A`, `baseChange_comm_G`, `baseChange_comm` (the iso
  intertwines the `A`- and induced `G`-actions; combined via
  `x = ⟨x.left,1⟩ * ⟨1,x.right⟩`).

Verification: `lake build EtingofRepresentationTheory.Chapter5.Theorem5_27_1`
passes; `#print axioms Etingof.inducedRepV_basepoint_independent` shows only
`propext, Classical.choice, Quot.sound` (no `sorryAx`).
