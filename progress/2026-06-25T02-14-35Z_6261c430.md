## Accomplished

One-shot session on #5208 (Krull–Schmidt 4/5: exchange / uniqueness of indecomposable
decompositions). Created `EtingofRepresentationTheory/Chapter9/KrullSchmidt/Exchange.lean`:

- **`Etingof.indecomposable_summand_iso_factor`** (the required deliverable) — **fully proved,
  no `sorry` in its body**. An indecomposable retract `X` of a finite biproduct `⨁ Y` of
  indecomposables is isomorphic to some factor `Y k`. Proof follows the issue's Azumaya/exchange
  strategy: expand `𝟙 X = ∑ k, (s ≫ π k) ≫ (ι k ≫ r)` via `biproduct.total`; since `End X` is
  local, the unit sum has a unit summand `α ≫ β` (iso); set `rr := β ≫ (α ≫ β)⁻¹`, so
  `α ≫ rr = 𝟙 X` and the idempotent `rr ≫ α : End (Y k)` is `0` or `𝟙` (local ring ⇒ trivial
  idempotents); `0` would force `𝟙 X = 0`, so `rr ≫ α = 𝟙 (Y k)` and `α` is the iso `X ≅ Y k`.

- **`Etingof.krullSchmidt_unique`** (the optional recommended companion) — **stated with a
  documented `sorry`** (top-down). Gives §9.7 the API to pin multiplicities. Strategy documented:
  induction on `Fintype.card κ`, peeling a matched summand via the exchange property and cancelling.
  The cancellation step is the deferred categorical content.
