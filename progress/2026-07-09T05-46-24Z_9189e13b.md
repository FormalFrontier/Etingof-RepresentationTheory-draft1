Completed issue #6029: discharged the `sorry` in

The proof is assembled from five new reusable, sorry-free lemmas in the same file:

- `fibre_cancel` — the combinatorial heart: `n • [f] = n • [g] ⟹` a fibre-preserving
  bijection `τ` (multiset cancellation for `n > 0`, via per-fibre `Fintype.card` counting
  and `Equiv.sigmaFiberEquiv`).
- `iSupIndep_prod_of_blocks` — two-level independence in a modular lattice: independent
  blocks with internally independent block-families give a jointly independent doubly indexed
  family. This is the lattice fact that makes `Vⁿ = ⨁_c ⨁_i (image of summand i in coord c)`
  an internal direct sum.
- `ks_uniqueness_index` — Krull-Schmidt uniqueness reindexed from `Fin`-families to an
  arbitrary `Fintype` index, returning the matching bijection on the index types directly.
- `single_injective` / `transport_decomp` — coordinate-inclusion injectivity, and the
  arbitrary-index generalisation of the existing `indecDecomp_map`.
- `powerDecomp` — the `n`-fold power `Fin n → M` of a module with an internal indecomposable
  decomposition carries an internal indecomposable decomposition indexed by `Fin n × Fin p`.

Main-proof strategy: decompose `V`, `W` (Krull-Schmidt existence); build the two power
decompositions of `Fin n → V` (one directly, one transported from `Fin n → W` along the given
`Vⁿ ≅ Wⁿ`); match them with `ks_uniqueness_index`; feed the resulting index permutation into
`fibre_cancel` using an iso-class type built as `Quotient` of the finite `Fin p ⊕ Fin q` by the
iso relation (this sidesteps the universe mismatch between submodules of `V` and of `W`); obtain
`τ : Fin p ≃ Fin q` with `DV i ≃ₗ DW (τ i)`; assemble
`V ≃ₗ ⨁ DV ≃ₗ ⨁ DW(τ·) ≃ₗ W` via `DirectSum.IsInternal` and `DFinsupp.mapRange.linearEquiv`.
