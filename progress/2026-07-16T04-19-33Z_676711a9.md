### Proof structure (character of the 3-dim simple `A₄`-rep at `h ∈ H`)

Case-split via `by_cases h = 1`, then for `h ≠ 1` the order dichotomy from `A4std_sq_or_cube`
(transported through `exists_conj_H12`'s conjugator `d`): `(h:A5)^2 = 1 ∨ (h:A5)^3 = 1`.

1. **Identity** (`h = 1`): `χ(1) = finrank = 3`; `classIdxA5 1 = 0` via
   `classRepA5 0 = 1` (`rfl`) + `classIdxA5_classRepA5`; RHS `![3,0,-1,0,0] 0 = 3`.
2. **Involution** (`(h:A5)^2 = 1`): `χ(h) = -1` by `charval_A4_involution` (#6706/#6713),
   `classIdxA5 = 2` by `classIdx_of_involution`; RHS `= -1`.
3. **Three-cycle** (`(h:A5)^3 = 1`, so `(h:A5)^2 ≠ 1`): `classIdxA5 = 1`, RHS `= 0`. Show
   `χ(h) = 0` by **row orthonormality** `⟨χ,χ⟩ = 1` (`FDRep.char_orthonormal σ σ`,
   `if_pos ⟨Iso.refl σ⟩`): `∑_{g∈H} χ(g)·χ(g⁻¹) = |H| = 12`, and each summand is
   `↑(normSq χ(g))` (`char_inv_eq_conj` + `Complex.mul_conj`). Cast to a real sum `= 12`; split
   off the Klein four `V = {g : (g:A5)^2=1}` (identity + 3 involutions), whose contribution is
   `9 + 3·1 = 12` — so the complement `{g : (g:A5)^2 ≠ 1}` sums to `0`. Each `normSq` term is
   nonnegative (`Finset.sum_eq_zero_iff_of_nonneg`), and `h` lies in the complement, hence
   `normSq χ(h) = 0`, i.e. `χ(h) = 0` (`Complex.normSq_eq_zero`).
