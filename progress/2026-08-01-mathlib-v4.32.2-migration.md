# Mathlib v4.32.2 migration

Date: 2026-08-01

Branch: `codex/upgrade-mathlib-v4.32.2`

## Objective

Upgrade the project from the `v4.32.0-rc1` toolchain and Mathlib snapshot to the latest stable
Lean/Mathlib release, `v4.32.2`, repair all source and linter regressions idiomatically, regenerate
toolchain-sensitive proof evidence, and merge the validated result.

## Completed

- Updated `lean-toolchain` and the Mathlib pin in `lakefile.toml` to `v4.32.2`.
- Refreshed `lake-manifest.json` and downloaded the matching Mathlib cache.
- Ran repository-wide and root-aggregate builds and repaired every migration failure exposed by
  the new toolchain.
- Migrated the following upstream changes and verified the affected modules:
  - opaque one-field `MonoidAlgebra` (`.coeff`, `MonoidAlgebra.basis`, and the new linear
    equivalence/submodule API);
  - `RingQuot` to `RingCon.Quotient`, including the presentation of `U(sl₂)`;
  - the new `Nat.card` convention in Mathlib character orthogonality while preserving this
    project's existing public theorem statements;
  - `Module.addCommMonoidToAddCommGroup`, the revised `Relation.ReflTransGen.mono` signature,
    the relocated natural antidiagonal lemma, and smaller basis/disjointness APIs.
- Replaced compatibility imports that would have created a forward book dependency with the
  infrastructure-only `CharacterOrthogonalityCompat` shim.
- Removed broad file-local `Coe (MonoidAlgebra R M) (M →₀ R)` shims and used explicit coefficient
  conversions instead.
- Avoided adding newly deprecated `MonoidAlgebra.coeff_single_apply` calls; the migrated sites now
  expose `.coeff` and use `Finsupp.single_apply`.
- Scoped every new heartbeat allowance to the declaration that needs it and retained explanatory
  comments.
- Regenerated the warning baseline from the exact successful CI-style per-module sweep.
- Regenerated the Stage 3.4 kernel dependency evidence and Stage 3.5 proof-polishing evidence.
- Obtained an independent pre-merge review. It found no semantic regression or correctness blocker;
  its actionable dependency/coercion/deprecation findings were incorporated before publication.
