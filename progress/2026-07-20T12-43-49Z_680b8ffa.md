## Accomplished

Proved `simpleGroup_card60_exists_index_five` sorry-free (issue #6982): every finite simple
group of order `60` has a subgroup of index `5`. This removes one of the two remaining `sorry`s
on the icosahedral critical path in
`EtingofRepresentationTheory/Chapter4/Problem4_12_8.lean`.

Route (pure finite group theory, no `SO(3)` dependency):
- Added `simpleGroup_card_dvd_index_factorial`: a simple group with a subgroup of index `≥ 2`
  embeds into `Equiv.Perm (Grp ⧸ K)` (core-free coset action; kernel is `K.normalCore`, which is
  `⊥` by simplicity), so `|Grp| ∣ (K.index)!`. This is the abstract "`G ↪ S_n`" bound.
- Added `exists_index_five_of_sylow2_card_fifteen` handling the hard `n₂ = 15` case: since
  `n₅ = 6` (24 order-`5` elements, only `36` elements of order `≠ 5`), two distinct Sylow
  `2`-subgroups must share a non-identity element `t` (else the `45` non-identity elements of the
  Sylow `2`-subgroups, all of `2`-power order, would exceed `36`). Sylow `2`-subgroups have order
  `4 = 2²` hence are abelian (`IsPGroup.isMulCommutative_of_card_eq_prime_sq`), so both lie in the
  centralizer `C = C_G(t)`; thus `4 ∣ |C|`, `|C| > 4`, forcing `|C| ∈ {12, 20, 60}`. `|C| = 60`
  puts `t` in the (trivial, by simplicity) center; `|C| = 20` gives an index-`3` subgroup
  (`60 ∤ 3!`). So `|C| = 12`, index `5`.
- Main theorem dispatches on `n₂ ∈ {3, 5, 15}` (`n₂ ∣ 15`, `n₂ ≠ 1` by simplicity): `n₂ = 3`
  contradicts via the index-`3` normalizer and the factorial bound; `n₂ = 5` returns the
  normalizer of a Sylow `2` (`Sylow.card_eq_index_normalizer`); `n₂ = 15` delegates to the helper.

The theorem was moved below the existing Sylow-counting helper lemmas (`sylow_card_eq_pow`,
`card_orderOf_eq_prime_mul_card_sylow`, `sylow5_card_eq_five`, `count_aux_card_ne_one`) so it can
reuse them. `#print axioms simpleGroup_card60_exists_index_five` returns the clean
`[propext, Classical.choice, Quot.sound]`.
