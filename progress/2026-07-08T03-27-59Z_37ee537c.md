Proof structure (all self-contained, no heavy machinery):
- **Nilpotency lemma** `nil`: any `q : A` with `constantCoeff q = 0` maps to a nilpotent in
  `A/I`. Decompose `q = ∑ᵢ homogeneousComponent i q` (`MvPolynomial.sum_homogeneousComponent`),
  push through `Ideal.Quotient.mk` with `map_sum`, then `isNilpotent_sum`. The degree-0 term is
  `C (constantCoeff q) = 0`; for `i ≥ 1`, `(homogeneousComponent i q)^N` is homogeneous of degree
  `i·N ≥ N` (via `IsHomogeneous.pow` and `le_mul_of_one_le_left`), hence in `I` by `hI`.
- **Locality** `hlocal`: `∀ a, IsUnit a ∨ IsUnit (1 - a)`. Split a lift `p` as
  `C c + (p - C c)` where `c = constantCoeff p`; `(p - C c)̄` is nilpotent. If `c ≠ 0`, `C c̄`
  is a unit and `a = unit + nilpotent` (`IsNilpotent.isUnit_add_left_of_commute`); if `c = 0`,
  `a` is nilpotent so `1 - a` is a unit (`IsNilpotent.isUnit_one_sub`).
- **Submodule = ideal** `hideal`: an `A`-submodule of `A/I` is closed under `A/I`-multiplication
  (`Algebra.smul_def` + `Ideal.Quotient.algebraMap_eq`, then `Submodule.smul_mem`).
- **Assembly**: from `IsCompl W₁ W₂`, write `1 = e₁ + e₂` with `eᵢ ∈ Wᵢ`; `e₁e₂ ∈ W₁ ⊓ W₂ = ⊥`
  gives `e₁` idempotent; locality forces `e₁ ∈ {0,1}` (via `IsUnit.mul_right_eq_zero`), and each
  case collapses one summand to `⊥`.
