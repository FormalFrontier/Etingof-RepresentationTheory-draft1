## Key findings (recorded so successors don't re-derive)

Verified concretely against pinned Mathlib `v4.32.0-rc1`:

1. **The deliverable does not typecheck.** `Module.Flat A P` requires `[CommSemiring A]`
   (`Mathlib/RingTheory/Flat/Basic.lean:82`, `class Flat` at line 113). Our `A` is a
   *noncommutative* `k`-algebra. Minimal repro errors with `failed to synthesize CommSemiring A`.
   Mathlib has **no** flatness predicate for left modules over a noncommutative ring — `class Flat`
   in `Flat/Basic.lean` is the only one and is commutative-base; `FaithfullyFlat`, `RingHom.Flat`,
   AG `Flat` morphisms all build on it.

2. **No balanced tensor product `X ⊗_A P` over a noncommutative base in Mathlib.** The `⊗[R]`
   notation is `TensorProduct R M N` with `[CommSemiring R]`
   (`Mathlib/LinearAlgebra/TensorProduct/Defs.lean:88`). The issue's proof outline (tensor–hom
   adjunction `Hom_{Aᵐᵒᵖ}(X, P*) ≅ Hom_k(X ⊗_A P, k)`) cannot even be *stated*. The cited
   precedent `Module.Flat.iff_characterModule_injective` (`Flat/Tensor.lean:54`) works only
   because its base is `ℤ` (commutative) with cogenerator `ℚ⧸ℤ`; it does not transfer to
   noncommutative `A`.

### Recommended replan routes (in the issue comment)

- **(A)** Build the missing infra first: balanced tensor `X ⊗_A P` (as a quotient of the existing
  `X ⊗[k] P` by `x·a⊗p − x⊗a·p`, via `IsScalarTower k A`), a hand-rolled left-flatness predicate
  (replacing the ill-typed `Module.Flat A P`), and the tensor–hom adjunction. Faithful, works for
  arbitrary `P`, but multi-issue (Mathlib-contribution-sized).
- **(B)** Reformulate Example 8.1.7 via the `k`-linear duality `D = Hom_k(-,k)`, avoiding tensor.
  Crux lemma `Module.Dual k A` injective as a right `A`-module is reachable with existing Mathlib
  (`Module.Baer` + `LinearMap.exists_extend` + the bilinear-form description
  `Hom_{Aᵐᵒᵖ}(I, Hom_k(A,k)) ≅ Hom_k(I,k)`). Caveat: duality route only proves the biconditional
  for **finite-dimensional `P`** (needs `P ≅ P**`), so it narrows the theorem unless combined
  with (A).
