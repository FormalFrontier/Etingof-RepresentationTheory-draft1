Discharged the single `sorry` in `EtingofRepresentationTheory/Chapter4/Problem4_12_4.lean`,
proving `Etingof.Problem4_12_4` (issue #6123): a finite simple graph with a nonabelian
automorphism group has an adjacency matrix whose characteristic polynomial is not squarefree
(a repeated eigenvalue).

Proof structure (four supporting lemmas + main theorem, all in the `Etingof.Problem4_12_4`
namespace):
- `injective_of_squarefree_prod`: `Squarefree (∏ i, (X - C (d i)))` ⟹ `d` injective (a repeat
  puts `(X - C (d i))²` into the product, forcing the non-unit `X - C (d i)` to be a unit).
- `eq_diagonal_of_commute`: a matrix commuting with `diagonal d` for injective `d` is diagonal.
- `commute_of_commute_isHermitian`: the crux. For a real Hermitian `A` with squarefree charpoly,
  any two matrices commuting with `A` commute with each other. Uses Mathlib's spectral theorem
  (`Matrix.IsHermitian.conjStarAlgAut_star_eigenvectorUnitary`, `charpoly_eq`): the ⋆-algebra
  automorphism `Ψ X = star U * X * U` sends `A` to `diagonal (eigenvalues)`; squarefree charpoly
  makes the eigenvalues distinct, so `Ψ N` is diagonal for every `N` commuting with `A`, and
  diagonal matrices commute; `Ψ` injective transports the identity back.
- `adjMatrix_commute`: the permutation matrix of a graph automorphism commutes with the
  adjacency matrix (adjacency invariance via `SimpleGraph.Iso.map_adj_iff`, `PEquiv` submatrix
  lemmas).
- Main theorem: the permutation matrices of two automorphisms commute with `A`, hence (crux)
  with each other; `PEquiv.toMatrix` injectivity transports this to `σ * τ = τ * σ`,
  contradicting the given non-commuting pair.
