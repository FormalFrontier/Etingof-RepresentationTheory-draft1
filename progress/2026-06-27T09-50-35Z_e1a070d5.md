## Accomplished

Discharged the single remaining `sorry` in
`EtingofRepresentationTheory/Chapter9/KrullSchmidt/Length.lean` — the **upper bound** of categorical
Jordan–Hölder additivity, `clength_le_add` (issue #5520). The file (and the whole KrullSchmidt
cluster) is now sorry-free.

Three new private lemmas implement the route recorded in the original `clength_le_add` docstring:

- `height_prod_le` — pure order theory: `Order.height (a, b) ≤ Order.height a + Order.height b` in a
  product of preorders, by `RelSeries.inductionOn'` on a chain ending at `(a, b)` (each link is a
  strict step in ≥ 1 coordinate, `Prod.lt_iff`).
- `mem_pullback_obj` — pseudoelement membership in `(pullback f).obj y`, lifting across the pullback
  square `Subobject.isPullback f y` transported to the concrete limit via `IsPullback.isoPullback`
  so `Abelian.Pseudoelement.pseudo_pullback` applies.
- `Φ_reflecting` — the categorical second-isomorphism content: for `A ≤ B` with equal `f`-preimages
  and equal `g`-images, `B ≤ A`. Proved by showing `ofLE A B` is epi via a pseudoelement chase
  (`sub_of_eq_image` for the "difference" `z`, exactness of `ShortComplex.cokernelSequence` for
  membership, and the preimage equality `h1` to land `z ∈ A`).

`clength_le_add` then assembles these: `Φ B = ((pullback f).obj B, imageSubobject (B.arrow ≫ g))`
is monotone + order-reflecting, hence `StrictMono`; `height_le_height_apply_of_strictMono` +
`height_prod_le` + monotonicity give `height ⊤(X₂) ≤ height ⊤(X₁) + height ⊤(X₃)`, and `ENat.toNat`
transports to `clength`.

Also moved the `Abelian.Pseudoelement` local-instance block up to just after `variable` (it is now
needed by `Φ_reflecting`, which precedes the old block site), and refreshed the module docstring to
state additivity is now proved.
