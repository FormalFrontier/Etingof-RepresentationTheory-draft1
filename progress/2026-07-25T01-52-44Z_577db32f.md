## Decisions made

- **Independence via a dual family, not degreewise finset filtering.** Each `gzero i` / `gone i`
  has a distinguished matrix entry where it is `1` and its siblings vanish (`LoopIdx.pos`).
  Pairing that entry with "take the `t^{I.deg}` coefficient" gives functionals `loopCoord I`
  with `loopCoord I (loopVec J) = δ_{IJ}`, after which `linearIndependent_iff'` plus
  `Finset.sum_eq_single_of_mem` is three lines. Filtering a `Finset LoopIdx` by degree and
  invoking `linearIndependent_gzero`/`gone` per degree would have been much longer.
- **`(2 : k) ≠ 0` is needed only for `gzero`.** The `-1`-eigenspace characterization holds over
  any commutative ring; it is the `+1` side (entries `a₀₂`, `a₁₁`, `a₂₀` killed only by `2a = 0`)
  that forces the hypothesis. So `loopBasis` takes `h2` but `mem_span_gone_of_sigInv_eq_neg`
  does not.
- Worth recording: the `-1`-eigenspace of σ on all of `𝔤𝔩₃` is 6-dimensional (`σ(1) = -1`); it is
  the traceless condition, not σ, that cuts it down to the 5-dimensional `gone`.

## Key patterns discovered

- `ext a b` on a goal about `Matrix _ _ k[X]` descends *through* the polynomial into a coefficient
  goal, which breaks `map_smul'`-style proofs. Use `Matrix.ext fun a b => ...` to stop at the
  entry level.
- A 25-case `fin_cases i <;> fin_cases i' <;> simp_all [...]` blast timed out at 200000
  heartbeats. Replacing `simp_all` with `first | exact absurd rfl hi | simp [...]` — a plain
  `simp` that ignores hypotheses, with the diagonal cases peeled off first — brought the whole
  file to a 16s build.
- `set_option linter.unnecessarySeqFocus false in` must go *before* the docstring, not between
  it and the `theorem`.
- The file did not previously import `Mathlib.Tactic.LinearCombination`; `linear_combination`
  failed with a confusing `unknown tactic` at an unrelated line. Added that import and
  `Mathlib.Algebra.Polynomial.Degree.Support` (for `Polynomial.as_sum_range'`).
