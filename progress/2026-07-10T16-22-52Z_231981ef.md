* Restrict `h` to `H` as `h' := h.comp H.subtype`.
* `h'.range = H.map h` via `range_eq_map` + `map_map` + `range_subtype`.
* Lagrange / first-iso count `Nat.card H = Nat.card (H.map h) · Nat.card h'.ker`
  via `card_eq_card_quotient_mul_card_subgroup` and `quotientKerEquivRange`.
* Kernel is `{1}` or `{1, g}` (where `g` has matrix `-1`) according to whether
  `-1 ∈ H`, using injectivity of the `H → SU(2) → Matrix` coercion

  `Subtype.val`) and `Nat.card_eq_two_iff` / `Subgroup.card_bot`.
