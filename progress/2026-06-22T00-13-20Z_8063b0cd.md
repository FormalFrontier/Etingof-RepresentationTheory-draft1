```
theorem quotDetDegreeFDRep_formalCharacter (N d : ℕ) (hd : N ≤ d) :
    formalCharacter k N (quotDetDegreeFDRep k N d)
      = ∑ ν ∈ Finset.univ.filter (fun ν : BoundedPartition N d => (0:ℕ) ∈ Set.range ν.parts),
          (MvPolynomial.eval (fun _ => (1:ℚ)) (schurPoly N ν.parts)) • schurPoly N ν.parts
```

Proof sketch (residual work):
1. `ι := (mulDet k N).restrict hιmap : twistFDRep(d-N) → polyRightDegreeFDRep(d)`
   (mulDet raises degree by `N`; `mulDet_isHomogeneous`).
2. `π := (Submodule.mkQ (detSubmodule k N)).restrict hπmap : polyRightDegreeFDRep(d)
   → quotDetDegreeFDRep(d)` (`hπmap x hx = ⟨x, hx, rfl⟩`).
3. Hypotheses for `formalCharacter_add_of_shortExact`:
   - `hι` (intertwine): `Subtype.ext` + `restrict_coe_apply` + `twistFDRep_ρ_apply`
     + `detChar_diagUnit_val`(no, use `mulDet_intertwine` + `polyOf_rho`).
   - `hπ` (intertwine): `Subtype.ext` + `restrict_coe_apply` + `quotDetRep_mk` + `polyOf_rho`.
   - `hι_inj` from `mulDet_injective`; `hπ_surj` from `w.2` (image membership).
   - `hexact` (`range ι = ker π`): map both to `MvPolynomial` via `subtype`
     (`map_injective_of_injective`); `(range ι).map subtype = (A_{d-N}).map mulDet`
     (`subtype_comp_restrict`, `range_comp`, `range_subtype`),

     equal by `detSubmodule_inf_homogeneous d hd`.
