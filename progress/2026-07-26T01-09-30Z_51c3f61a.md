## Decisions made / patterns discovered

- **The orbit basis was already there.** The book's hint ("similar to Problem 2.7.4(c)") is
  realized by the *existing* dimension proof: it builds the `y`-eigenvector orbit `xⁱ·v`, shows
  it is a basis, and then discards everything but its cardinality. Exhaustiveness needed no new
  mathematics, only exposing that data. The issue suggested diagonalizing `x` and taking the
  `y`-orbit instead; refactoring the existing `y`-eigenvector/`x`-orbit argument gives the same
  classification with no duplicated proof, so I did that.
- **Do not let a `letI`-bound module instance into a defeq-heavy proof.** The first version
  proved the `Algebra.adjoin` induction directly against
  `letI := famModule q α β N hqorder`, which is `Module.compHom … (QWeyl.toEnd …)`. Every
  `rw`/`change` touching a `•` on that module made `isDefEq` unfold `toEnd` → `toEndLinear` →
  `Basis.constr`, and the proof blew the 200000-heartbeat limit in four separate places.
  Hoisting the induction into `nonempty_linearEquiv_of_intertwines_generators`, where both
  module structures are *abstract instance variables*, made the whole file compile in 6.9s.
  General rule: when a proof about a concretely-constructed module needs structural
  induction over the acting algebra, state the induction over an opaque module and apply it.
- **Generating the subalgebra from inside itself.** `qWeylAlgebra ℂ q` is *defined* as
  `Algebra.adjoin ℂ {x, x⁻¹, y, y⁻¹}` inside `End ℂ (QWeylModule ℂ)`, which gives membership
  facts about the *ambient* elements. `Algebra.adjoin_adjoin_coe_preimage` turns that into
  `Algebra.adjoin ℂ {x, x⁻¹, y, y⁻¹} = ⊤` *within* the subalgebra, so the induction runs over
  honest elements of `qWeylAlgebra ℂ q` instead of `⟨g, hg⟩` subtype literals — which is both
  faster and much more readable than the `show ((⟨u, hu⟩ + ⟨v, hv⟩ : A)) • …` pattern used
  elsewhere in `Problem2_7_5.lean`.
- **Session-start hygiene caught a stale worktree.** `git status` showed 364 lines of pure
  deletions under `.claude/` (the same regression as #7834/#7835). Restored with
  `git checkout HEAD -- .claude/` and re-read the skill before doing anything else; the
  restored copy is what supplied the `Algebra.adjoin`-vs-`change` and publish-time scope
  guidance used above.
