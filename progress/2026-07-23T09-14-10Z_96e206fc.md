## Accomplished

Fixed the build regression in `EtingofRepresentationTheory/Chapter8/Exercise8_2_9.lean`
(issue #7492). The file failed a fresh Lean check at two `Algebra.smul_def` rewrites:

- line 291, inside the `map_smul'` field of the by-hand `k[x]`-linear map `φ`;
- line 333, inside the surjectivity proof `hsurj` for the lift `h`.

Root cause: on the current toolchain the `Module (Polynomial k) (Polynomial k ⧸ I)`
smul instance carried by these goals is no longer syntactically `Algebra.toSMul`, so
`Algebra.smul_def` (whose LHS pattern `?r • ?x` is anchored on `Algebra.toSMul`) could
not find the smul to rewrite. Repaired by converting the `Polynomial k`-smul to the
quotient-ring multiplication through `IsScalarTower.algebraMap_smul`
(`algebraMap R A r • x = r • x`), which depends only on the ambient `SMul`/`IsScalarTower`
instances and therefore matches regardless of which defeq module instance is present:

- φ's `map_smul'`: `... map_smul, ← IsScalarTower.algebraMap_smul (k[x]⧸(p)) a (b.coord i (mk x)), Ideal.Quotient.algebraMap_eq`;
- `hsurj`: `map_smul, ← IsScalarTower.algebraMap_smul (k[x]⧸(pᴺ)) c (h y₀), smul_eq_mul, Ideal.Quotient.algebraMap_eq, ...`.
