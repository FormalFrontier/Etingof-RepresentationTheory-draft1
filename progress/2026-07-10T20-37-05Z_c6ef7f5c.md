```
theorem sumTranspositions_isSemisimple_and_integer_eigenvalues
    (m : ℕ) {V : Type*} [AddCommGroup V] [Module ℂ V] [Module.Finite ℂ V]

       ∃ la : Nat.Partition m, μ = (content la : ℂ))
```

## Key decisions / patterns

- **Universe.** The deliverable (and downstream #6285) use `{V : Type*}`, but the
  ℂ-hardcoded `Theorem5_12_2_classification` is stated for `M : Type` (Type 0). Used the
  universe-polymorphic `Etingof.classification_general_u ℂ` instead, which returns an iso to
  `SpechtModuleK ℂ m la`; bridged `SpechtModuleK ℂ m la = SpechtModule m la` via the existing
  `YoungSymmetrizerK_eq_mapRange` / `YoungSymmetrizer_eq_mapRange` so the ℂ content-action
  lemma `sumTranspositions_mul_eq_content_smul` applies.
- **Proof shape.** `p := ∏_{c ∈ contents} (X - C c)` is squarefree
  (`separable_prod_X_sub_C_iff'` → `Separable.squarefree`). `q := aeval C p` is central
  (polynomial in the central `sumTranspositions`), so its kernel is an `A`-submodule of
  `ρ.asModule`; on each simple summand (classification) `q` acts by `p(c(λ)) = 0`, so by
  `IsSemisimpleModule.sSup_simples_eq_top` the kernel is `⊤`, giving `aeval T p = 0` via
  `aeval_algHom_apply` + `asModuleEquiv_map_smul`. Semisimplicity is then
  `Module.End.isSemisimple_of_squarefree_aeval_eq_zero`; each eigenvalue is a root of `p`
  (`aeval_apply_of_hasEigenvector`), i.e. a content.
- Maschke's `IsSemisimpleModule (SymGroupAlgebra m) ρ.asModule` is found by `inferInstance`
  (the `Etingof.neZero_card_perm` instance supplies the `NeZero (Nat.card Sₘ : ℂ)` side goal).
