## Key findings / patterns

- The #4830 plan referenced a hypothetical `card_lt_of_injective_comorphism_degreeZero`
  but #4828 actually landed `card_lt_of_scaleInvariant_image_fractionRing`, which
  takes a *scaling automorphism family* on the fraction field (not a localization
  B). The degree-0 fact is therefore phrased as `scale μ (φ (X w)) = φ (X w)`,
  reduced to `map_smul_conj_eq` on `(genMatB j).map ιB · V · ((genMatB i).map ιB)⁻¹`.
- `IsScalarTower.toAlgHom_apply` (a `rfl` lemma) works where
  `IsScalarTower.coe_toAlgHom` (about the `⇑` coercion) fails to rewrite an
  application.
- `Matrix.inv_smul'` has the matrix `A` made **explicit** (`variable (A)`), so call
  it as `Matrix.inv_smul' C μ hCdet`, not `Matrix.inv_smul' μ hCdet`.
- `Matrix.map_apply`'s reverse is a metavariable-headed rule; instead of
  `rw [← Matrix.map_apply]` use `(Matrix.map_apply).symm.trans (congrFun (congrFun H _) _)`
  to push a matrix equality `H : M.map Φ = M` down to a single entry.
- `omit [..] in` must come **before** `@[simp]`, not after.
