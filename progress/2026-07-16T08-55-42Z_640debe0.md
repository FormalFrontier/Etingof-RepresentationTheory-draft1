## Accomplished

Proved `isDynkinDiagram_unique_degree_three` (issue #6768, Ch6 Problem 6.1.3 part
(d), second half): a Dynkin diagram has at most one vertex of degree three. This
closes the last `sorry` of part (d) in
`EtingofRepresentationTheory/Chapter6/Problem6_1_3_continued_E7_E8.lean`.

Proof (sorry-free, axioms limited to `propext, Classical.choice, Quot.sound`):

- Added a helper `reachable_of_isChain`: converts the raw `List` connectivity
  clause of `IsDynkinDiagram` (a `List.IsChain G.Adj`) into
  `SimpleGraph.Reachable`.
- Build the `SimpleGraph` of the diagram, extract a **shortest path** `p` (geodesic,
  `p.length = dist v w = m`) via `Reachable.exists_path_of_dist`.
- Distance-coordinate lemmas `dist v pₖ = k`, `dist pₖ w = m - k` (via `Walk.take`/
  `Walk.drop` lengths + `dist_triangle_left`), which force each degree-3 vertex's
  two extra neighbours (pendants) to lie **off the path**.
- Key simplification: the test vector `x = 2·[on path] + [is a pendant]` uses
  **boolean** indicators, so the off-path property keeps every weight ≤ 2 and the
  subharmonic bound `2·xᵢ ≤ (adj·x)ᵢ` holds at every vertex with **no case split**
  on short cycles / small `m`. Then `xᵀ(2I − adj)x ≤ 0` with `x ≠ 0` contradicts
  positive-definiteness. This avoided the triangle/4-cycle degenerate-case analysis
  the issue anticipated.
