### Statement change (as the issue required)

The theorem as written in #6160 was **false** (it had no acyclicity/finiteness
hypothesis; a single loop `0 ⟶ 0` acting as `id` on `k` is an irreducible
representation isomorphic to no vertex simple). Corrected signature:

```lean
theorem irreducible_isSimpleRep [DecidableEq Q] [Finite Q]
    (hQ : NoOrientedCycles Q) (ρ : QuiverRepresentation k Q)
    (hρ : IsIrreducible ρ) :
    ∃ i : Q, Nonempty (QuiverRepresentationEquiv k Q ρ (simpleRep i))
```

I used `[Finite Q]` rather than the issue's suggested `[Fintype Q]` — it is all the
proof needs (via `Set.finite_univ.wellFoundedOn`), gives a strictly more general
theorem, and clears the `unusedArguments` linter.

### Proof structure

- **`subsingleton_of_bot_eq_top`** (new top-level private helper): a `k`-module with
  `⊥ = ⊤` in its submodule lattice is a subsingleton. Kept top-level to stay
  universe-polymorphic (a local `have ∀ {M : Type*}` breaks async elaboration with a
  level-params mismatch).
- **Well-foundedness of the arrow relation** `fun a b => Nonempty (a ⟶ b)`: its
  `Relation.TransGen` is irreflexive (a cycle builds a positive-length `Quiver.Path i i`,
  contradicting `NoOrientedCycles`), hence a strict order on a finite type, hence
  well-founded (`Finite.wellFoundedOn` + `Set.wellFoundedOn_univ`); pull back to the base
  relation with `Subrelation.wf`.
- **Step A — all arrow maps vanish.** The image family `W b = ⨆_{e : a ⟶ b} range (ρ_e)`
  is arrow-stable, so by irreducibility it is all-`⊥` or all-`⊤`. All-`⊤` is impossible:
  a well-founded induction along the arrow relation shows every carrier is trivial,
  contradicting nontriviality. Hence all-`⊥`, i.e. every arrow map is `0`.
- **Step B — concentration.** With arrows zero, the family supported at the nontrivial
  vertex `v₀` is arrow-stable; irreducibility forces `ρ.obj v = 0` for all `v ≠ v₀`.
- **Simplicity at `v₀`.** Any submodule `U ≤ ρ.obj v₀`, extended by `Function.update` to a
  vertex family, is arrow-stable, so `U = ⊥` or `U = ⊤`: `IsSimpleModule k (ρ.obj v₀)`,
  hence `finrank = 1`.
- **Step C — assemble.** `finrank`-equality gives vertexwise equivalences
  `ρ.obj v ≃ₗ (simpleRep v₀).obj v` (`1`-dim at `v₀`, subsingleton elsewhere via
  `LinearEquiv.ofBijective 0`); `commutes` is automatic since both sides' arrow maps vanish.
