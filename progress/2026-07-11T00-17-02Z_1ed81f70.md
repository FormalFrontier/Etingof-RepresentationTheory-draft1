## Accomplished

Proved `Etingof.realGEndAlgebra_equiv_complex_of_isComplexType` (Problem 5.1.2(a), complex
type) **sorry-free** in `EtingofRepresentationTheory/Chapter5/Problem5_1_2.lean` (issue #6326).
`#print axioms` shows only `propext, Classical.choice, Quot.sound` (no `sorryAx`).

Strategy (the ±-decomposition route from the issue):

- Showed the `ℂ`-embedding `complexToRealGEnd ρ : ℂ →ₐ[ℝ] realGEndAlgebra ρ` is **surjective**;
  combined with the existing injectivity, `AlgEquiv.ofBijective … |>.symm` gives the iso.
- For `f ∈ End_{ℝ[G]} V`, split `f = f₊ + f₋` (existing `realPlus`/`realMinus`).
  - `f₊` commutes with `J = i•`, so it upgrades to a `ℂ`-linear `G`-equivariant endomorphism
    (`toCLinear`); by Schur it is a scalar `c` (proved `schur_scalar` via
    `Module.End.exists_eigenvalue` + the eigenspace being a `G`-invariant subspace of a simple
    representation, hence `⊤`).
  - `f₋` anticommutes with `J`, so it is conjugate-linear (`toAntilinear`). If `f₋ ≠ 0`, its
    kernel is a proper `G`-invariant `ℂ`-subspace of the simple `V`, hence `⊥`, so `f₋` is
    injective; composing with the antilinear equivariant map `hermToDual H` (from the invariant
    positive-definite Hermitian form) yields a `ℂ`-linear equivariant `V ≃ₗ[ℂ] V*`, contradicting
    `IsComplexType`. Hence `f₋ = 0` and `f = f₊ = complexToRealGEnd ρ c`.

New shared toolkit (public, reusable by #6327/#6328):
- `hermToDual`, `hermToDual_apply`, `hermToDual_equivariant`, `hermToDual_injective` — the
  antilinear `G`-equivariant map `V →ₗ⋆[ℂ] Module.Dual ℂ V`, `w ↦ (v ↦ H v w)`.

Private helpers: `real_coe_smul`, `complex_smul_eq_real`, `invSubmodule_eq_bot_or_top` (a nonzero
`G`-invariant `ℂ`-subspace of a simple rep is `⊤`, via `Subrepresentation` + `IsIrreducible`),
`toCLinear`, `toAntilinear`, `schur_scalar`.

No new imports needed (everything via `import Mathlib`). No `def`/statement signatures changed;
the real, quaternionic, and part-(b) sorries were left untouched.
