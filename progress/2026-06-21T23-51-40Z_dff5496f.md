with `lake build <module>`, committed individually, pushed):

- **Chapter3/Theorem3_8_1** — `Submodule.finrank_le` for the `finrank k ↥⊤ ≤
  finrank k V` obligation; `simp [Equiv.ofBijective_apply]` → `rw` (simp choked
  on a `σ_fun` let-binding under `instances` transparency).
- **Chapter5/Theorem5_10_1** — restriction functor: `(Action.res _ H.subtype).obj V`
  → `Rep.res H.subtype V` (Mathlib's `Rep.indResHomEquiv` codomain is now `A ⟶ res φ B`).
- **Chapter5/Corollary5_12_4** — `MonoidAlgebra.mapRangeRingHom` → `mapRingHom`.
  `mapRangeRingHom` is now a deprecated *alias* for `mapRingHom`, and the rewrite
  lemmas (`mapRingHom_single`, `mapRingHom_apply`) have head symbol `mapRingHom`,
  so simp never matched the alias-headed term. Switching the `let φ` to `mapRingHom`
  fixed both unsolved goals.
- **Infrastructure/RegularCharacter** — `Finsupp.basisSingleOne_repr` /
  `LinearEquiv.refl_apply` for the matrix-trace diag step; `mulLeft_apply` rewrite
  failed under `instances` transparency (MonoidAlgebra/Finsupp defeq), worked
  around with `show`; `convert ... using 1` now leaves an extra defeq subgoal,
  closed with `all_goals first | rfl | (split_ifs <;> ring)`.
- **Infrastructure/ColumnRepSimple** — `Representation.IntertwiningMap.isIntertwining'`
  changed from a pointwise field (`∀ g v, f (ρ g v) = σ g (f v)`) to a composition
  equation (`∀ g, toLinearMap ∘ₗ ρ g = σ g ∘ₗ toLinearMap`). Build the forward map
  via the new helper `LinearMap.intertwiningMap_of_isIntertwiningMap ρ σ f hf`
  (ρ σ f all explicit, no dot notation); convert the inverse map's field via
  `LinearMap.congr_fun (f.isIntertwining' g) v`.
- **Chapter7/Example7_6_3** — `Action.res _ φ` → `Rep.resFunctor φ`;
  `LieRing.ofAssociativeRing` (commutator Lie structure on an associative ring)
  is now only a *local* instance upstream, so re-enabled it with
  `attribute [local instance 100] LieRing.ofAssociativeRing` before `uea_adjunction`
  (the global `LieAlgebra.ofAssociativeAlgebra` depends on it).
