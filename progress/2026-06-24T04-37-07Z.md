Key Lean lessons (added to lean-formalization skill): `QuiverPathIndex` must be
a *reducible* `abbrev`, not a `def` — otherwise the `*` binop unfolds it to the
raw `Σ` type while instance search won't unfold it back, so `Mul` is not found
when a basis index is a literal `⟨i,i,nil⟩`. And inside a structure-update
`{ src with … }`, use `(inferInstance : T)`, not `inferInstanceAs T` (the latter
reports spurious "expected type contains metavariables").
