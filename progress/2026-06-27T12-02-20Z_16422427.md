Reusable declarations (namespace `Etingof`):

- `w0ShiftWeight N lam s` (`fun j => s - lam (Fin.rev j)`) — the `w₀`-twisted,
  `s`-shifted weight `ν`. This is `(λ.w0Twist).toNatWeight` in the integer-weight
  bookkeeping of `Theorem5_23_2Core.lean` (`w0Twist` negates+reverses, the `det^s`
  twist shifts by `s`).
- `w0ShiftWeight_antitone` — for antitone `λ`, `ν` is again antitone (so it is a
  valid dominant weight). Proof: `Fin.rev_anti` + `λ` antitone + `omega`.
- `schurPoly_inverseShift` (**the reusable core**) — for `λ : Fin N → ℕ` and `s`
  with `∀ j, λ j ≤ s`,
  `det(alternantMatrix N (fun j => (s+N-1) - shiftedExps N λ j))
    = sgn(Fin.revPerm) · (schurPoly N ν · Δ)`,
  where `Δ = det(alternantMatrix N (vandermondeExps N))` is the Vandermonde.

Design note: the repo uses honest polynomials (`schurPoly N : (Fin N → ℕ) →
MvPolynomial (Fin N) ℚ`, no Laurent variables), so the inverse substitution
`xᵢ ↦ xᵢ⁻¹` is encoded *honestly* as the **complemented-exponent alternant**
`det(Xᵢ^{(s+N-1) - (λ_j+δ_j)})`, which equals `(x₁⋯x_N)^{s+N-1}·a_{λ+δ}(x⁻¹)`
(every exponent is `≥ 0` because `λ_j + δ_j ≤ s + N - 1` when `λ_j ≤ s`).
Reversing the columns (`Fin.revPerm`) turns the exponent sequence into the
shifted-exponent sequence of `ν` up to the reversal sign `ε`, so the determinant
is `ε · s_ν · Δ`. Cancelling the common Vandermonde from numerator and denominator
of the alternant ratio (the denominator `a_δ(x⁻¹)` carries the *same* `ε`, which is
why the consumer sees a sign-free `s_ν`) recovers exactly fact (b).

The proof is pure alternant linear algebra: the column-reversal identity
`Matrix.det_permute'` plus the alternant-ratio defining property of `schurPoly`
(`schurPoly_mul_vandermonde`). The only arithmetic content is the pointwise
exponent identity `(s+N-1) - shiftedExps λ j = shiftedExps ν (rev j)`
(`complementExps_eq`, via `Fin.val_rev`/`Fin.rev_rev` + `omega`). No
`formalCharacter`, no representation theory — a clean leaf decoupled from the
character machinery, as the issue scoped it.
