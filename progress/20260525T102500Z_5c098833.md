### Caveat: initial label tally with default --limit

The first orient pass used `gh issue list --label
agent-plan --state open --json number,labels` without
`--limit`, which defaults to **30** items. That returned
`{"agent-plan,blocked,feature":6, "agent-plan,feature,has-pr":1,
"agent-plan,feature,replan":23}` for a total of 30 —
matching the page size, not the real total. Re-running
with `--limit 100` returned the true tally of 45 with the
canonical composition above. **Future planner cycles must
always pass `--limit 100`** (or higher) when grouping
agent-plan labels; the default 30 silently truncates and
will appear as a fake state change. This is the same trap
documented in earlier cycle handoffs; flagging it again to
keep it visible.
