## Accomplished

Worked issue #6023 (Ch7 Exercise 7.8.4, headline claim). Proved
`Etingof.Exercise7_8_4` **sorry-free**: every acyclic (exact) cochain complex of
`k`-vector spaces over a field is contractible — its identity is null-homotopic
`Nonempty (Homotopy (𝟙 K) 0)`.

`#print axioms Etingof.Exercise7_8_4` shows only `[propext, Classical.choice,
Quot.sound]` — no `sorryAx`.

The proof is the elementary degreewise-splitting construction (valid for *unbounded*
complexes, so it avoids the bounded-below `IsStrictlyGE` route). Assembled in a helper
namespace `Etingof.Exercise7_8_4Aux`:

- `Zsub n = ker dⁿ`, chosen complement `Wsub n` via `Submodule.exists_isCompl`.
- `range_d_eq_Zsub`: acyclicity (`K.exactAt_iff'` at degree `n+1` +
  `ShortComplex.Exact.moduleCat_range_eq_ker`) gives `range dⁿ = ker dⁿ⁺¹ = Zⁿ⁺¹`.
- `dW n = dⁿ|_{Wⁿ}` is injective (`dW_injective`) with range `Zⁿ⁺¹` (`range_dW`), so
  `IsCompl (range dW) Wⁿ⁺¹` (`isCompl_range_dW`).
- `sMap` = the contracting homotopy `sⁿ⁺¹ : Kⁿ⁺¹ → Kⁿ`, built from
  `LinearMap.linearProjOfIsCompl` (inverse of `dW` on `Zⁿ⁺¹`, `0` on `Wⁿ⁺¹`).
- `sMap_homotopy`: the pointwise relation `sⁿ⁺¹(dⁿ x) + dⁿ⁻¹(sⁿ x) = x`, by splitting
  `x = z + w`.
- `htpy` assembles these into the `Homotopy.hom` family (`eqToHom`-guarded `dite`).

Key trick avoiding `eqToHom` bookkeeping in `comm`: substitute `i = m + 1` at the start
so every "successor" index is a literal `+1`, making both `htpy` accessor conditions
`rfl`-true.
