## The recorded weight condition (input for #7803)

```lean
def HasImaginaryWeight (c : loopPos k → loopPos k → k) : Prop :=
  ∀ I J : LoopIdx, (∀ m : ℕ, I.lbideg + J.lbideg ≠ (2 * m + 2, 4 * m + 4)) →
    c (loopFam k I) (loopFam k J) = 0
```

and the hypothesis #7803 must discharge is exactly

```lean
∀ c : loopPos k → loopPos k → k, IsTwoCocycle k c → HasImaginaryWeight c → IsTwoCoboundary k c
```

Two lemmas in the file document that this is the right restriction:
`serre_bideg_not_imaginary` (the Serre bidegrees `(2,1)` and `(1,5)`, where `H²(𝔫₊,k)` actually
lives, are not imaginary, so the restriction does not exclude them) and
`eq_zero_of_hasImaginaryWeight_base_odd` (the condition is not vacuous: it forces vanishing on
the pair `(base, odd 0 0)` of total bidegree `(1,5)`).

## Key design decision

The issue sketched correcting `loopSect` by a `K`-valued coboundary, which would need a basis of
`K = ker gbar` — and `K`'s dimension is exactly what is unknown, so that route is circular in
Lean. Instead the reduction runs through the **dual space**: it suffices to kill `topDefect k m`
against every `φ : Module.Dual k (g k 4)` (`Module.forall_dual_apply_eq_zero_iff`, from
`Mathlib.LinearAlgebra.Dual.Lemmas`, a new import). Applying the hypothesis to the *scalar*
cocycle `φ ∘ loopCocycle` yields `f`, and `ψ = φ ∘ loopSect + f` satisfies
`φ ⁅u, v⁆ = ψ ⁅gbar u, gbar v⁆` for all `u, v : g k 4`. Since `topDefect k m` is a `k`-combination
of two brackets and `gbar` kills it, `φ (topDefect k m) = ψ (gbar (topDefect k m)) = 0`. This is
why the hypothesis can be about `k`-valued cochains, as #7803 expects, with no `K`-valued
cohomology anywhere.

Practical note: `loopPos k` is a `LieSubalgebra` of the matrix algebra under the *local* instance
`LieRing.ofAssociativeRing`, so any file mentioning brackets of matrices needs
`attribute [local instance] LieRing.ofAssociativeRing`.
