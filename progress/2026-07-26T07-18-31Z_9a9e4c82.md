## Accomplished

Issue #7876 — the triangularization theorem that Mathlib lacks. New file
`EtingofRepresentationTheory/Infrastructure/Triangularization.lean`, no `sorry`, no extra axioms
(`propext`, `Classical.choice`, `Quot.sound` only):

* `blockTriangular_toMatrix_iff` — a basis triangularizes `A` iff each `A (b j)` lies in
  `span k (b '' Set.Iic j)`, i.e. iff the flag of the basis is `A`-invariant. Used in both
  directions by the induction.
* `exists_basis_blockTriangular_of_splits_minpoly` — the induction on `finrank`. A split minimal
  polynomial has a root, hence an eigenvector `v`; `A` descends to `V ⧸ k ∙ v`; the descended
  operator is annihilated by `minpoly k A`, so its own minimal polynomial divides that one and
  still splits; the quotient's triangularizing basis lifts along a section of `V ↠ V ⧸ k ∙ v`
  and, with `v` prepended (`LinearIndependent.finCons` +
  `basisOfLinearIndependentOfCardEqFinrank`), triangularizes `A`.
* `exists_basis_blockTriangular` — deliverable 1, characteristic-polynomial form, via
  `LinearMap.minpoly_dvd_charpoly`.
* `exists_basis_blockTriangular_charpoly` — the same packaged with the diagonal `lam` and
  `charpoly A = ∏ i, (X - C (lam i))`. This is `IsTriangularizedBy` (from PR #7877) unfolded.
* `exists_basis_blockTriangular_of_isAlgClosed` — the algebraically closed special case.
* `roots_prod_X_sub_C_comp`, `exists_perm_of_map_univ_eq`, `exists_perm_of_prod_X_sub_C_eq` — two
  families with the same `∏ (X - C ·)` differ by a permutation (fibrewise cardinality plus
  `Equiv.sigmaFiberEquiv`).
* `exists_basis_blockTriangular_diag_perm` — the bridge: from the book's literal hypothesis
  `charpoly A = ∏ i, (X - C (lam i))`, a triangularizing basis with diagonal `lam ∘ e`.
* `sum_powersetCard_prod_comp`, `sum_sym_prod_comp` — `e_n` and `h_n` (in exactly the shapes the
  #7877 trace formulas use) are invariant under reindexing, so the `e` above can be discarded.

### Design note

The induction carries the **minimal** polynomial, not the characteristic polynomial. "The minimal
polynomial of the operator induced on a quotient divides the minimal polynomial upstairs" is a
three-line argument; the corresponding `charpoly A = (X - μ) * charpoly Ā` multiplicativity is not
in Mathlib and would have been the whole job. The charpoly form is recovered at the end from
`minpoly_dvd_charpoly`.

Also note: this Mathlib version's `Polynomial.Splits` takes no ring hom (`f.Splits`, not
`Splits (RingHom.id k) f`), so the issue's statement of deliverable 1 needed rephrasing.

```lean
theorem trace_extPowMap_of_charpoly (hlam : LinearMap.charpoly A = ∏ i, (X - C (lam i))) (n : ℕ) :
    LinearMap.trace k (ExtPow k V n) (extPowMap A n)
      = ∑ s ∈ Finset.powersetCard n (Finset.univ : Finset (Fin N)), ∏ i ∈ s, lam i := by
  obtain ⟨b, e, hb, hdiag⟩ := Etingof.exists_basis_blockTriangular_diag_perm A hN lam hlam
  rw [trace_extPowMap ⟨hb, hdiag⟩ n]     -- diagonal is `lam ∘ e`
  exact Etingof.sum_powersetCard_prod_comp lam e n
```
