## Accomplished

Closed the finiteness coverage gap in Theorem 3.5.4 flagged by review #7124 / issue #7127.
`Etingof.structure_mod_radical` formalizes only the *isomorphism* clause, taking the finite
index type `ι` and completeness as hypotheses. This turn adds a new, additive file
`EtingofRepresentationTheory/Chapter3/Theorem3_5_4_Finiteness.lean` proving the book's
*finiteness* argument (Theorem 3.5.4, first two paragraphs):

- `Etingof.finiteDimensional_of_isSimpleModule` — every irreducible representation of a
  finite dimensional algebra is finite dimensional over `k`. Book proof: `A • v` is the image
  of the finite dimensional `A` under the `k`-linear map `a ↦ a • v`, and by irreducibility
  `Submodule.span A {v} = ⊤`, so `V` is a quotient of `A` hence finite dimensional.
- `Etingof.card_irreducibles_le_finrank` — any family of pairwise non-isomorphic irreducibles
  has `Fintype.card ι ≤ finrank k A`. Book proof: each `Vᵢ` is finite dimensional (previous
  lemma), the density map `⊕ᵢ ρᵢ : A → ∏ᵢ End(Vᵢ)` is surjective (`density_theorem_part2`), so
  `card ι = ∑ᵢ 1 ≤ ∑ᵢ dim End(Vᵢ) = dim(∏ᵢ End Vᵢ) ≤ dim A`.

`structure_mod_radical` was NOT modified — this is purely additive. The `[Fintype ι]` +
finite-dimensionality inputs are now derivable rather than merely assumed: there are at most
`dim A` irreducibles up to isomorphism, and each is finite dimensional.

Both new lemmas are axiom-clean: `#print axioms` reports exactly
`[propext, Classical.choice, Quot.sound]` (no `sorryAx`). New file builds; Chapter3
aggregator builds (added import line).
