New sorry-free results (all depend only on `[propext, Classical.choice, Quot.sound]`):

- `permRep_eq_toLin'` / `trace_permRep`: `permRep g` is the linear map of the
  permutation matrix of `g⁻¹` (`Matrix.permMatrix_mulVec` + `Matrix.toLin'`), so its
  trace is `(Function.fixedPoints g⁻¹).ncard` via `Matrix.trace_permutation`.
- `fixCard` / `perm_inv_fixed_iff` / `fixedPoints_inv_ncard` / `fixCard_inv`: bridge the
  set-theoretic fixed-point count to a decidable `Finset.filter` cardinality.
- `stdRep_character`: **general formula** `χ_stdRep(g) = #fix(g) − 1`. Proof routes
  through `LinearMap.trace_eq_sum_trace_restrict` over the internal direct sum
  `permRep = stdSub ⊕ constLine` (`DirectSum.isInternal_submodule_iff_isCompl` +
  `Submodule.isCompl_iff_disjoint`): the constant line contributes trace `1` (acted on
  trivially), so `χ_perm = χ_std + 1`.
- `stdRep_char_one = 2`, `stdRep_char_swap = 0`, `stdRep_char_cycle = -1`: the values
  `(2, 0, −1)` on identity / transposition / 3-cycle, each via `fixCard … = _` by `decide`.
- `stdRep_simple : Simple stdRep`: via `FDRep.simple_iff_char_is_norm_one`, reducing
  `∑_g χ(g)·χ(g⁻¹)` to the integer sum `∑_g ((fixCard g − 1)²) = 6 = |S₃|`, closed by
  `decide`.
