Content (over a finite-dimensional real normed algebra `A`; the docstring notes the complex case is
identical):

- **Forward direction** `hasDerivAt_leibniz`: if `g : ℝ → (A →L[ℝ] A)` is a differentiable family
  of algebra homomorphisms with `g 0 = 1` and derivative `D` at `0`, then `D` satisfies the Leibniz
  rule `D (x*y) = D x * y + x * D y` — i.e. `g'(0)` is a derivation. Proved by differentiating the
  multiplicativity relation at `0` (`HasDerivAt.clm_apply`, `HasDerivAt.mul`, `HasDerivAt.unique`).
- **Converse direction**: for a derivation `D`, `exp (t • D)` is a one-parameter family of algebra
  automorphisms:
  - `expDeriv_apply_apply` (pointwise group law), `expDeriv_add` (operator group law),
    `expDeriv_zero` (identity at `t = 0`);
  - `expDeriv_map_mul` (multiplicativity) and `expDeriv_map_one` (unitality) — the algebra-hom
    property;
  - `expDerivAut : A ≃ₐ[ℝ] A`, the automorphism with inverse `exp (-t • D)`.

Key technique: the operator identity `exp(x+y) = exp x * exp y` needs a `NormedAlgebra ℚ` structure
that is unavailable on `A →L[ℝ] A` (Mathlib's instance requires a division ring). So all converse
facts are instead obtained from ODE uniqueness (`ODE_solution_unique_univ`): each relevant curve
`s ↦ exp (s • D) x` solves `w' = D ∘ w` (derivative via `hasDerivAt_exp_smul_const'`), and comparing
two such curves with equal initial value proves each identity.
