- `orbitRel_quotient_finite_of_finite_reps` (core): given a finite set `reps` of
  indecomposable representatives covering every finite-dimensional indecomposable

  from `IsFiniteTypeQuiver n adj` at the ambient orientation.

Supporting lemmas (all sorry-free): `areIsomorphic_directSumList_forall₂`,
`areIsomorphic_directSumList_map`, `exists_point_areIsomorphic_of_obj_equiv`
(realisation of an abstract rep as a point of `W(m)`), finiteness bookkeeping

`one_le_finrank_sum_of_isIndecomposable`, `length_le_of_areIsomorphic_repOfPoint`

Proof shape: surject a finite index (bounded-length lists of representatives) onto the
orbit quotient via `exists_decomposition` (#4794) + `orbit_iff_isomorphic` (S0). The
length bound comes from each indecomposable summand contributing ≥1 to the total
dimension `∑ᵢ mᵢ`. Krull–Schmidt / uniqueness deliberately avoided.

Key patterns discovered:
- `QuiverRepresentation.obj` carries only `AddCommMonoid`; unlock `Module.Free` over a
  field via `letI : ∀ v, AddCommGroup (W.obj v) := fun _ => Etingof.addCommGroupOfRing
  (k := k)` (no diamond — it extends the existing `AddCommMonoid`). Needed for
  `Module.finrank_prod` and `Module.finrank_pos_iff_of_free`.
- `Module.finrank_prod` requires `[Module.Free]` (section variable), not just Finite.
- Pin the rep universe to `QuiverRepresentation.{0,0,0,0}` to match
  `exists_decomposition` / `IsFiniteTypeQuiver`.
- Build the representative list with `List.pmap` + `List.pmap_eq_map` / `List.map_pmap`
  / `List.length_pmap` to avoid `attach`-rewrite motive issues.
