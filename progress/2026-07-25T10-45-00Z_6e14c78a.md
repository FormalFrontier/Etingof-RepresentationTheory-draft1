The issue had been reopened because `su2_finite_subgroup_classification` stopped short of the

* `su2_sq_eq_one` — **`SU(2)` has a unique involution.** `A ∈ SU(2)` with `A² = 1` is `±1`.
  Elementary `2 × 2` argument: `A² = 1` plus `det A = 1` forces the trace `a + d ≠ 0` (else
  `1 = -1`), the off-diagonal equations `b(a+d) = c(a+d) = 0` kill `b, c`, and `a² = ad = 1`
  gives `d = a = ±1`. This single fact drives everything below.
* `su2_two_not_dvd_card_of_neg_one_not_mem` — `-1 ∉ H ⟹ 2 ∤ |H|` (Cauchy + the above).
* `su2_isCyclic_of_neg_one_not_mem` — **the `-1 ∉ H` branch is cyclic.** `|H| = |h(H)|` is odd,
  while `|Dₙ| = 2n`, `|A₄| = 12`, `|S₄| = 24`, `|A₅| = 60` are all even, so only the cyclic
  disjunct of part (a) survives.
* `su2_isCyclic_of_image_isCyclic` — **binary cyclic is cyclic.** With `n = |h(H)|`, `γ` a
  generator and `g` a lift, `gⁿ ∈ {1, -1}`. If `gⁿ = -1` then `orderOf g = 2n = |H|`. If
  `gⁿ = 1` then `orderOf g = n`, and `n` is odd (an even `n = 2m` would make `g^m` an
  involution, hence `-1`, hence in `ker h`, forcing `n ∣ m`); then `g` and the central `-1`
  have coprime orders `n` and `2`, so `g·(-1)` has order `2n = |H|`.
* `su2_finite_subgroup_binary_classification` — **the exact list.** Every finite `H ≤ SU(2)` is
  either cyclic, or the full binary preimage `h⁻¹(h(H))` of a noncyclic finite subgroup of
  `SO(3)`, with the order pinned: `4n` (binary dihedral `2·Dₙ`), `24` (`2·A₄`), `48` (`2·S₄`),
  `120` (`2·A₅`).
