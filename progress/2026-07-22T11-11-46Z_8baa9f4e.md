## Accomplished

Discharged the headline `Etingof.Problem4_12_10_symmetric` (issue #7290) — the book's
primary symmetric-power form of Problem 4.12.10: for a finite group `G` with a faithful
complex `ρ` on `V` and a simple `σ` on `W`, there is `n` and a nonzero `G`-equivariant
`φ : W → Sym[ℂ]^n V` intertwining `σ` with `symPowRep ρ n`. Sorry-free and axiom-clean
(`[propext, Classical.choice, Quot.sound]`).

Assembly (the Maschke-splitting plan from the issue):
1. `exists_injective_intertwiner_ofMulAction σ hσ` — the simple `W` embeds equivariantly
   in the regular representation `ℂ[G]`.
2. `Etingof.exists_orbitEval_surjection ρ hρ` (#7289) — the `G`-equivariant surjection
   `E : ⨁ₙ SⁿV ↠ ℂ[G]`.
3. Package `E` as a `ℂ[G]`-module hom of `asModule`s (`asModuleHomOfIntertwiner`) and split
   it with `IsSemisimpleModule.lifting_property` — the regular module is semisimple (Maschke,
   char 0), yielding a `ℂ[G]`-linear section `s`.
4. Repackage `s` as a `ℂ`-linear `G`-equivariant map (`intertwinerOfAsModuleHom`), compose
   with the embedding to place `W ↪ ⨁ₙ SⁿV` injectively (hence nonzero), then
   `exists_component_intertwiner_of_ne_zero` extracts the summand index `n`.

Key structural decision: the theorem could **not** stay in `Problem4_12_10_Symmetric.lean`
as the issue's file field suggested, because `Problem4_12_10_OrbitEval.lean` (which provides
the surjection) imports `Problem4_12_10_Symmetric.lean` — placing the theorem in Symmetric
would be a circular import. I moved the theorem (unchanged fully-qualified name
`Etingof.Problem4_12_10_symmetric`) into `Problem4_12_10_OrbitEval.lean`, added
`import EtingofRepresentationTheory.Chapter5.RepresentationAsModuleHom` there for
`asModuleHomOfIntertwiner`, and left a pointer comment + updated module doc in Symmetric.

Flipped `progress/items.json` `Chapter4/Problem4.12.10` `coverage` `covered_partial` →
`covered_full`, added the new decl/lean_file entries, and rewrote `fidelity_note` to record
