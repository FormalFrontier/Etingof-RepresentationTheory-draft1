## Key patterns discovered

- These `QuiverRepresentation` defs (`starRep_kQ := by letI := Q; exact {...}`)
  do **not** reduce `.mapLinear e` to the underlying match arm during
  unification. Use `change <reduced map> ∈ W b at h` (as the canonical proof
  does) to force the defeq.
- `hOrient.2.1 i 0 (by decide)` returns `Nonempty (Hom i 0) ∨ Nonempty (Hom 0 i)`.
  `rcases ... with ⟨e'⟩` does **not** unwrap the `Nonempty` (Prop→Type); extract
  the arrow witness with `obtain ⟨e'⟩ := h1` **inside** the Prop sub-goal.
- The `{a b}` implicits of the invariance hypothesis aren't inferred from the
  arrow witness here; pass them explicitly: `@hW_inv ⟨i,_⟩ ⟨0,_⟩ e' x hx`.
