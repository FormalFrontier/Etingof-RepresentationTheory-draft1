## Accomplished

Formalized issue #5778 (A5 icosahedral sub-issue #1): the third trace moment
`zEnd_cube_trace : LinearMap.trace ℂ (↥lam2Sub.toSubmodule) (zEnd * zEnd * zEnd) = 96000`
in `EtingofRepresentationTheory/Chapter4/Example4_8_1.lean` (A5 section), immediately after
`zEnd_sq_trace`.

Route (primary, as specified in the issue — the class-index fallback was unavailable):
- `z²` is central (`(zEnd_central g).mul_right (zEnd_central g)`), so each summand of
  `z³ = ∑_g z²·ρ(g·r·g⁻¹)` has the same trace as `z²·ρ(r)` by conjugation invariance of the
  trace (`LinearMap.trace_mul_comm`), giving `tr(z³) = 60·tr(z²·ρ(r))`. This mirrors
  `zEnd_sq_trace` one level up — the endomorphism rewrite is done in a separate `have hrw`
  so `map_mul` targets the representation, not the trace functional.
- Unfolding one `z`: `z²·ρ(r) = ∑_h z·ρ(h·r·h⁻¹·r)`, so via `zEnd_comp_char`,
  `tr(z²·ρ(r)) = ∑_h ∑_{h'} χ_{Λ²}(h'·r·h'⁻¹·h·r·h⁻¹·r)`, the honest 60×60 = 3600-term group
  double sum. Reducing `χ_{Λ²}` to the integer `fixCardM` formula, a single honest `decide`
  (no `native_decide`) evaluates the sum to `3200`, so `tr(z²·ρ(r)) = 2⁻¹·3200 = 1600` and
  `tr(z³) = 60·1600 = 96000`.

Constraints honoured: no `sorry`, no `native_decide`, no `decide` on Q5 (the decide is over
`A₅ = alternatingGroup (Fin 5)` fixed-point counts). The 3600-term `decide` needed
`maxHeartbeats 2000000000` / `maxRecDepth 100000`; it adds ~4 min to the file build (baseline
1:46 → 6:05). The `classIdxA5` fallback (sub-issue #5) would cut this decide to 60 terms but has
not landed; `fixCardM` alone cannot distinguish the two 5-cycle classes, so the cheap fallback
genuinely requires that work.
