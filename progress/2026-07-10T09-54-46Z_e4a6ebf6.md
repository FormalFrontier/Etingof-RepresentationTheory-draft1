## Current frontier

The bijection is built directly on iso-classes via `Quotient.map` in both directions (inflate =
restriction of scalars, demote = jacobson descent), reusing the existing private
`jacobsonModule`/`promoteEquiv` machinery. Well-definedness mirrors the existing `hresp` argument;
the two inverse laws use `idModuleIso` (the round-trip module structures agree, using surjectivity
of `mk` on the `R ⧸ rad` side). The object maps are marked `@[reducible]` so `ι.obj` unfolds for
`preimageIso`'s defeq check.
