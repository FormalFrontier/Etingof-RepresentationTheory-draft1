## Key patterns discovered

The planned proof route (eigenspace orbit decomposition `V = ⨁ E_j`, common dimension `d`,
`dim V = s·d`, bound `d ≤ ℓ/s`) is heavier than necessary. A lighter route reuses the existing
`f`-ladder template (`finrank_le_of_epow_orderOf_eq_zero`) almost verbatim:

- Pick a `K`-eigenvector `v` (eigenvalue `μ₀ ≠ 0`) that is *also* an eigenvector of the operator
  `f ∘ e` restricted to the `μ₀`-eigenspace. `f ∘ e` preserves that eigenspace (`e` raises the
  eigenvalue by `q²`, `f` lowers it by `q²`), and over `ℂ` a nonzero finite-dimensional space has
  an eigenvector (`Module.End.exists_eigenvalue` on `(smulEnd (f*e)).restrict`). This gives
  `f • (e • v) = ρ • v`.
- From `f • (e • v) = ρ • v` and `f^ℓ • (e•v) = b • (e•v)` (with `b ≠ 0`), deduce
  `e • v = (b⁻¹ρ) • f^{ℓ-1} v`, so `e • v` lies in the `f`-ladder span `W = span{fⁱv : i < ℓ}`.
- The `e`-closure of `W` then follows by induction from `e • v ∈ W` using the `ef_action`
  recursion `e • f^{k+1} v = f • (e • f^k v) + κ_k • f^k v` — **no highest-weight hypothesis
  `e • v = 0` needed**. `f`-, `K`-, `L`-closure are identical to the template.
- `W` is a `U_q`-submodule, `= V` by simplicity, spanned by `ℓ` vectors ⇒ `dim V ≤ ℓ`.

Notable: this argument uses only `hb0` (`f^ℓ` scalar nonzero ⇒ `f` bijective) and `hq2`; it does
**not** use `ha`/`ha0` (the `e^ℓ` scalar), so the cyclic lemma is in fact true whenever `f^ℓ` acts
as a nonzero scalar. The signature was kept exactly as specified in the issue (hence two harmless
`unused variable` linter warnings on `ha`, `ha0`); the file already ships with style warnings and
CI is not warnings-as-errors.
