### The general pattern worth keeping

Two PRs that are each green in isolation can still break `main`, because
per-chapter CI (`lake build EtingofRepresentationTheory.Chapter3`) never links
the two chapters and so never sees a duplicate declaration. Only a full
`lake build` catches it. This is a merge-order hazard, not a mathematical one,
and it will recur whenever two agents independently add the same piece of
missing API to different chapters — which is exactly what the worker skill's
"grep before implementing" rule is meant to prevent upstream.
