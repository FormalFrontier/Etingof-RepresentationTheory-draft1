- `conjRep_one`, `conjRep_transpose`, `conjRep_trace` — action compatibility lemmas.
- `scalarProj` / `skewProj` — genuine `ℝ`-linear projections of `End(V)` onto the scalar and
  skew summands, with `..._equivariant` and `..._mem` lemmas (real defs, no sorry).
- `equivMap_eq_zero_of_finrank_lt` — **Schur, dimension form**: an equivariant map sending an
  irreducible invariant `W` into a strictly-smaller invariant `Wsmall` vanishes on `W`
  (otherwise the restriction `W → Wsmall` is injective, forcing `finrank W ≤ finrank Wsmall`).
  This is the reusable Schur core; it needs only irreducibility of the *source* plus a
  dimension count, avoiding the non-isomorphic-target Schur argument.
- `invariant_matrix_scalar` — a matrix fixed by `Dz`, `Dy`, `Pc` is a scalar (entrywise).
- `exists_isRoot_of_odd_natDegree` — a real polynomial of odd degree has a root (IVT; ℝ has no
  `IsRealClosed` instance in Mathlib, so this is proved here via `tendsto_atTop`/`atBot` +
  `intermediate_value_Icc`).

`hooke_law` itself: (1) `f 1` is `conjRep`-invariant hence `K • 1`; (2) scalar/skew components
of `f|_W` vanish by `equivMap_eq_zero_of_finrank_lt` (1 < 5, 3 < 5), so `f(W) ⊆ W`; (3) `f|_W`
on odd-dim `W` has a real eigenvalue `μ` (charpoly natDegree = 5), whose eigenspace is a nonzero
invariant subspace, hence all of `W` by irreducibility, giving `f|_W = μ • id`; (4) symmetry
follows from `symSub = scalarSub ⊕ tracelessSymSub`.
