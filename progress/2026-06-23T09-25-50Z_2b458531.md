Proof mechanism (single generic diagonal element), all sorry-free helpers:
- `exists_separating_torus` — base-`B` torus `t i = 2^(B^i)` separates the characters
  `χ_μ(t) = ∏ t_i^{μ_i} = 2^(∑ μ_i B^i)` over the finite weight support; injectivity from
  base-`B` encoding (`sum_base_pow_injOn`) + infinite mult. order of `2` (CharZero).
- `glWeightSpace_le_genEigenspace_diagTorus` — each weight space ⊆ generalised eigenspace
  of `f := M.ρ(diag t)` at `χ_μ(t)`.
- `genEigenspace_diagTorus_eq_glWeightSpace` (H1) — the genEigenspace at a supported
  character equals the weight space, via a modular-lattice squeeze lemma
  `eq_of_le_of_iSupIndep_of_iSup_eq` (no finite-dimensionality needed) + eigenspace
  independence.
- `genEigenspace_diagTorus_eq_bot` (H2) — genEigenspaces off the character set vanish.
- Main: Mathlib's `Submodule.eq_iSup_inf_genEigenspace` decomposes `R = ⨆_λ (R ⊓ Gλ)`
  along `f`'s eigenvalues; H1/H2 match each piece to a weight piece.
