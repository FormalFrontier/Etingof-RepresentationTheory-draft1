## Accomplished

Proved `Etingof.Problem7_8_7_ii` (issue #6304) in
`EtingofRepresentationTheory/Chapter7/Problem7_8_7.lean` — over a field, if either factor of
a tensor product of complexes is acyclic then `C ⊗ D` is acyclic. Previously `sorry`.

Approach (the book's Exercise 7.8.4 hint):

- Added a private helper `acyclic_of_homotopy_id_zero : Homotopy (𝟙 X) 0 → X.Acyclic`.
  Homotopic chain maps induce equal homology maps (`Homotopy.homologyMap_eq`), so
  `𝟙 (Hⁱ X) = homologyMap (𝟙 X) i = homologyMap 0 i = 0`, giving `IsZero (Hⁱ X)` via
  `exactAt_iff_isZero_homology` + `IsZero.iff_id_eq_zero`.
- Over a field an acyclic complex is contractible: `Etingof.Exercise7_8_4` gives
  `Nonempty (Homotopy (𝟙 K) 0)`. Whiskered that contracting homotopy through the tensor
  bifunctor with Mathlib's `HomologicalComplex.mapBifunctorMapHomotopy₁` (for the `C`-acyclic
  case) / `mapBifunctorMapHomotopy₂` (for the `D`-acyclic case), which transport a homotopy
  through one argument of `mapBifunctorMap` (= `tensorHom`). `tensorObj/tensorHom` on
  `HomologicalComplex` unfold to `mapBifunctor/mapBifunctorMap` for `curriedTensor (ModuleCat k)`.
- Bridged endpoints: `mapBifunctorMap (𝟙 C) (𝟙 D) = 𝟙 (tensorComplex C D)` via
  `mapBifunctorMap` unfold + `Functor.map_id` (qualified as `CategoryTheory.Functor.map_id`
  to avoid the applicative `_root_.Functor.map_id`) + `HomologicalComplex₂.total.map_id`;
  and `mapBifunctorMap 0 (𝟙 D) = 0` (and the mirror) via `mapBifunctor.hom_ext` on the
  injections (`ι_mapBifunctorMap` simp lemma; the bifunctor kills `0`).
- Added `import EtingofRepresentationTheory.Chapter7.Exercise7_8_4` (was not imported).
