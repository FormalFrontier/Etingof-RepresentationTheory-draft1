## Accomplished

Closed the `sorry` in `twistedPolytabloid_pigeonhole_pair`
(`EtingofRepresentationTheory/Chapter5/SpechtModuleBasis.lean`), the
combinatorial core of the Wall-3 Support Bound (issue #2543). The lemma now
has a full machine-checked proof (no new sorries; `lake build
EtingofRepresentationTheory.Chapter5.SpechtModuleBasis` is green).

Proof structure (column decomposition + pigeonhole, as the issue prescribed):
- Two position sets `Bset = {p | σ⁻¹(q₀ p) ≤ k ∧ row(w p) < i}` and
  `Dset = {p | σ⁻¹ p ≤ k ∧ row p < i}`, whose cardinalities equal the two
  cumulative counts (`cumulCount (w q₀⁻¹ σ)` and `cumulCount σ`) via the
  bijections `e ↦ q₀⁻¹ σ e` and `e ↦ σ e`.
- By contradiction: if no collision pair `(a₁,a₂)` exists, then
  `g p = (col p, row(w p))` is injective on positions.
- Fiberwise over columns (`Finset.card_eq_sum_card_fiberwise`, mirroring
  `counting_gives_dominates` in Lemma5_13_2.lean), per column `c`:
  - `|B_c| ≤ |S_c|` via the column-preserving `q₀`,
  - `|B_c| ≤ i` via injectivity of `row∘w`,
  - `|D_c| = min(|S_c|, i)` from the **column-standard prefix property**: the
    rows occupied by `S_c = {col=c, σ⁻¹≤k}` form an initial segment
    `range |S_c|`. This is the crux, proved via a new helper
    `downward_closed_mem_iff_lt_card` (a downward-closed finite subset of ℕ
    is `range card`) applied to the row-image of `S_c`, with downward-closure
    coming from `isColumnStandard'` (σ⁻¹ strictly increasing down each column).
  - Hence `|B_c| ≤ min(|S_c|,i) = |D_c|`; summing gives `|Bset| ≤ |Dset|`,
    contradicting the hypothesis `|Dset| < |Bset|`.

New private helper added: `downward_closed_mem_iff_lt_card`.
