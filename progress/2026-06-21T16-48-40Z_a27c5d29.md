## Accomplished

Claimed and executed #4902 (feature): gave `AlgIrrepGL` a genuine
`GL_n(k)`-representation structure. New file
`EtingofRepresentationTheory/Chapter5/AlgIrrepGLRep.lean`, registered in
`Chapter5.lean`. Builds clean, no `sorry`.

Deliverables landed:

- `AlgIrrepGLRep n lam k : FDRep k (GL_n(k))` — the Schur module
  `SchurModule k n λ.toNatWeight` twisted by `det^{-λ.shift}` via `charTwistRep`.
  Its carrier is definitionally `AlgIrrepGL n lam k` (`@[simp] algIrrepGLRep_ρ`
  records the underlying rep).
- `formalCharacter_algIrrepGLRep_of_shift_zero` — for `λ.shift = 0` (already
  non-negative weight) the formal character equals `schurPoly n λ.toNatWeight`
  (Weyl character formula, reusing `formalCharacter_schurModule_eq_schurPoly`).
- `algIrrepGLRep_isSimple` — irreducibility over `ℂ` with `∑ λ.toNatWeight ≤ n`,
  reusing `schurModule_isSimple`.

Reusable infrastructure proved along the way:

- `Representation.stableSubmodule` — a `k`-submodule of `ρ.asModule` stable under
  every `ρ g` packages (same carrier) as a `k[G]`-submodule (via
  `MonoidAlgebra.induction_linear`).
- `isSimpleModule_charTwistRep` — **character-twist invariance of
  irreducibility**: `IsSimpleModule k[G] ρ.asModule → IsSimpleModule k[G]
  (charTwistRep c ρ).asModule`. Twisting by a 1-dimensional character rescales
  each `ρ g` by a unit, leaving the subrepresentation lattice unchanged. General
  (any `Monoid G`, `Field k`); useful well beyond this issue.
