## Accomplished
Closed both part-(a) general-family Cartan determinant sorries in
`EtingofRepresentationTheory/Chapter6/Problem6_1_3_continued_E7_E8.lean` (issue #6755):

- `det_cartan_A (n) (hn : 1 ≤ n) : (cartan (A n hn)).det = n + 1`
- `det_cartan_D (n) (hn : 4 ≤ n) : (cartan (D n hn)).det = 4`

Both are sorry-free (axioms: propext, Classical.choice, Quot.sound).

Approach (mirrors the book's "row decomposition + recursive equation"):
- Introduced bare matrices `pathCartan n` (tridiagonal 2/-1) and `dCartan n`
  (path + fork), decoupled from the `DynkinType` wrapper so the `1 ≤ n` / `4 ≤ n`
  obligations stay out of the index arithmetic; related back via
  `cartan_A_eq_pathCartan` / `cartan_D_eq_dCartan`.
- Proved the continuant recursion `det(C(n+2)) = 2 det(C(n+1)) - det(C(n))` by a
  double cofactor expansion (`Matrix.det_succ_row_zero` then
  `det_succ_column_zero`), identifying the two minors as smaller copies.
- Two-step induction: A base cases n=1,2 (2,3); D base cases D4,D5 (both 4) via the
  `cartan_det` macro (relocated before Part (a) so the base cases can use it).

Key Lean gotchas handled: `omega` cannot prove disjunctive (`∨`) or conjunctive
(`∧`) *goals* (must select the disjunct / split the conjunct), and `2 • (1:ℤ)`
needs `two_nsmul` + `Matrix.add_apply` to become omega-visible arithmetic.
