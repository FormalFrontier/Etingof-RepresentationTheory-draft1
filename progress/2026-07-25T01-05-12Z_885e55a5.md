## Accomplished

Issue #7705 (feature): the converse half of Problem 9.3.2's second question — every finite
dimensional indecomposable projective `A`-module is `P₊` or `P₋`, for
`A = ℂ⟨g, x⟩ / (gx + xg, x², g² - 1)`. With this, all three parts of Problem 9.3.2 are formalized
and `#7388` can close.

Housekeeping first: closed #7704, whose work landed in merged PR #7722 (commit `d39a0515`). The
PR body omitted a `Closes #7704` line, so the issue stayed open and was still being offered by
`coordination list-unclaimed`.

**Part 1 — the left regular decomposition `A ≅ P₊ ⊕ P₋`.** The issue suggested this as a
reusable result in its own right, and it is what makes `dim_ℂ A = 4` concrete.

The file already had `iPlus`/`rPlus` and `iMinus`/`rMinus` with `rPlus ∘ iPlus = id`,
`rMinus ∘ iMinus = id` (the splittings proving projectivity). Only one new ingredient was needed:
*each retraction kills the other summand*. `eminus_smul_Pplus_e0 : e₋ · e₀⁺ = 0` because `g` acts
as `+1` on `e₀⁺`, so `(1 - g)·e₀⁺ = 0`; and `xeminus_smul_Pplus_e0` follows from
`x·e₋ = x * e₋`. Dually on `P₋`. Given that, `rProd = (rPlus, rMinus)` and
`iProd = iPlus ∘ fst + iMinus ∘ snd` are mutually inverse: `rProd ∘ iProd = id` by the two
vanishing lemmas, and `iProd ∘ rProd = id` because it is multiplication by
`eplus_add_eminus : e₊ + e₋ = 1`.

This deliberately avoids proving `dim_ℂ A = 4` first (which would need the four elements
`e₊, x e₊, e₋, x e₋` to be linearly independent, i.e. that the relations do not collapse the
algebra further). Instead the *retractions* supply injectivity for free, and `finrank_A` then
falls out of the equivalence with `finrank ℂ Pplus = finrank ℂ Pminus = 2`. Also lands
`instance : FiniteDimensional ℂ A`, which is what makes `A` artinian downstream.

**Part 2 — the classification.** The heavy lifting was already in the project:
`Etingof.indecomposable_projective_iso_of_hom` (`Chapter9/Theorem9_2_1.lean`) says two
indecomposable f.g. projectives with nonzero `Hom` to the same simple are isomorphic, by
Fitting's lemma. Worth knowing: the issue proposed a Krull–Schmidt route (`P` is a summand of
`Aⁿ ≅ (P₊ ⊕ P₋)ⁿ`, then `krull_schmidt_uniqueness`). That route is correct but far more Lean
work — it needs an internal decomposition of `Aⁿ` into `2n` indecomposable submodules with
`iSup = ⊤` and `iSupIndep`. The projective-cover route needs none of that, and the project
already had it.

So this file only had to supply the inputs:

- `IsArtinianRing A`, from `FiniteDimensional ℂ A` via `isArtinian_of_tower`;
- `exists_nonzero_hom_to_simple`: a nonzero finite dimensional `Q` has a maximal submodule
  (`Etingof.Theorem921.exists_isCoatom_submodule`), and the simple quotient is `S₊` or `S₋` by
  the existing `nonempty_linearEquiv_splus_or_sminus`;
- `gSES_ne_zero` / `gSESm_ne_zero`, the matching nonzero maps `P₊ ↠ S₊`, `P₋ ↠ S₋`;
- `pplus_not_iso_pminus`, so the classification can be stated as `Xor` rather than `Or`. Proof:
  an `A`-linear `e : P₊ → P₋` sends `e₀` into the `+1`-eigenline `ℂ·e₁` of `g`, so
  `e e₁ = e (x · e₀) = x · e e₀ ∈ x · ℂ·e₁ = 0` — `e` kills the socle and is not injective.

Public endpoints: `indecomposable_projective_classification` (the `Or` form),
`indecomposable_projective_classification_xor` (mirrors `simple_module_classification`), and
`existsUnique_index_of_indecomposable_projective`, phrased over the same `Pfam = ![P₊, P₋]`
family the Cartan matrix is computed on, so parts 2 and 3 demonstrably speak about the same two
objects.

Two non-vacuity guards, in the spirit of the ones added for the Cartan matrix:
`indecomposable_projective_classification_Pplus` and `..._Pminus` instantiate the theorem at `P₊`
and `P₋` themselves. They force instance resolution to actually find `FiniteDimensional ℂ`,
`Module.Projective A` and `IsScalarTower ℂ A` for those carriers, so the hypothesis bundle is
demonstrably satisfiable and the theorem is not classifying an empty class.
