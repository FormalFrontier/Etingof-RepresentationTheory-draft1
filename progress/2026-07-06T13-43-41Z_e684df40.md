Statement pass for **Problem 5.11.1** (issue #5920), the last remaining

New file `EtingofRepresentationTheory/Chapter5/Problem5_11_1.lean` (added to the
`Chapter5.lean` aggregator) states the decomposition into irreducibles of every
representation of `A₅` induced from the irreducibles of the subgroups `ℤ₂, ℤ₃,
ℤ₅, A₄, ℤ₂×ℤ₂`. Eleven theorems, all `sorry` proofs; builds cleanly.

Key design choices:
- Reused the existing `A₅` irreducible catalogue `repTriv, repC3plus,
  repC3minus, repC4, repC5` from `Etingof.Example4_8_1.A5` (dims `1,3,3',4,5`).
- Induction via `Etingof.Definition5_8_1`; targets are `FDRep` biproducts (`⊞`),
  mirroring the `S₃`/`S₄` induced-decomposition files
  (`Discussion5_11_examples`, `Discussion5_11_S4S3`).
- Phrased each part for an **arbitrary** subgroup `H` of the relevant order plus
  an arbitrary irreducible inducing rep distinguished by `Nat.card H`,
  `Module.finrank ℂ σ`, and triviality of `σ.character`. This is faithful
  because all subgroups of each order in the list are conjugate in `A₅` (one
  involution class; Sylow-3/5 conjugate; order-4 = Klein Sylow-2 since `A₅` has
  no order-4 element; order-12 = point-stabiliser `A₄`), so the decomposition
  depends only on the order and the character class. Avoids constructing roots
  of unity and the `A₄` 3-dim irrep explicitly.
- All multiplicities computed via Frobenius reciprocity from the `A₅` character
  table (recorded in the file's module docstring). The `ℤ₅`-nontrivial case is
  stated as a disjunction over `repC3plus`/`repC3minus` (the `{ζ,ζ⁴}` vs
  `{ζ²,ζ³}` split matches the two `5`-cycle classes `5a,5b`).

Consistency check: the trivial-character inductions reproduce the vertex (`12`),
face (`20`), edge (`30`) permutation-representation decompositions of Problem
4.12.5 — as they must, since `Ind` of the trivial character is the coset
permutation representation.
