### Proof route worked out (recorded for the sub-issue workers)

`g := f^n`, `e₀ := Abelian.factorThruImage g` (epi), `m := image.ι g` (mono), `g = e₀ ≫ m`,
`g' := m ≫ e₀ : image g → image g`. Stabilisation (im/ker of `gⁿ` vs `g^{2n}`) ⟺ `g'` iso; cleanest
via pseudoelements. `s := (g')⁻¹ ≫ m` sections `e₀`, so `IsSplitEpi e₀` with kernel `ker g`; the
split-epi-with-kernel bicone gives `X ≅ ker g ⊞ image g`. `f` preserves both summands
(`f` commutes with `f^n`; `f(im fⁿ) ⊆ im f^{n+1} = im fⁿ`), so block-diagonal. `fK^n = (f^n)|_K = 0`
(nilpotent); `fI^n = g'` iso ⟹ `fI` iso (need small helper `isIso_of_isIso_pow`).
