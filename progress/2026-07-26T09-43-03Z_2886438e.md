## Accomplished

Meditate session on #7891 — commits stranded on dead agents' local branches.

**`scripts/list_stranded_branches.py`** reports local `agent/*` branches carrying commits
nobody else can see, and with `--recover` pushes them and comments on the issue their
commit subjects cite. `scripts/test_list_stranded_branches.py` covers it offline (builds
each stranding shape as real git refs in a temp repo, stubs `gh`).

Classification, which took two attempts to get right:

| kind | meaning |
|---|---|
| `no-remote-no-pr` | never pushed, no PR — the #7891 case |
| `unpushed-commits` | a PR exists but the branch grew past the head it points at |
| `pushed-no-pr` | pushed, but nothing ever linked it to an issue |

**Commit counts cannot decide this, and neither can remote-ref existence.** Squash-merging
rewrites a branch's commits into one that is not patch-equivalent to any of them, so all
~2700 merged `agent/*` branches here stay "ahead of `main`" forever, and `git cherry`
reports their patches as unmerged. The first version leaned on `origin/<branch>` existing
instead — the self-test caught that as a false positive on every branch merged with
`--delete-branch`, i.e. the normal path. What settles it is reachability from a *visible*
ref: `origin/<branch>` if it survives, plus each PR's `headRefOid`. When a PR merged and
its head is no longer in the clone, the branch is called covered — a false positive on
every merged branch would bury the signal.

Two other traps worth knowing: `.pod/agents/*.json` is **not** named after the session
UUID (`8fc88fff.json` holds session `2886438e-…`), so liveness has to read the `uuid`
field out of each file; and a live session's branch is legitimately ahead and unpushed, so
it is suppressed unless `--include-live`.

Wired into the recurring cycles: planner Step 2b (`.claude/commands/plan.md`) runs it every
cycle beside the merge sweep, worker Step 4 says to look for a dead session's branch when
an issue's "current state" disagrees with `main`, and worker Step 5 now says to
`git push -u` at the *first* commit — that alone downgrades `no-remote-no-pr` to something
recoverable, and costs nothing. Also fixed `plan.md` Step 1's `git fetch origin master`
(this repo's default branch is `main`, so that fetch was failing, and the check depends on
a fresh `origin/main`).

**Audit.** Zero local branches are stranded right now: the three ahead of `main` all have
