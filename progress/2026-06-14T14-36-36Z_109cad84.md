## Accomplished

Closed the single `sorry` in `scalarGL_acts_as_pow` (issue #4653, Piece 1 of the
`det⁻¹` elimination, `Chapter5/PolynomialRepEmbedding.lean`) — **sorry-free**.

While doing so I found that the planned statement was **mathematically false as
written**. The lemma (and the whole chain above it) carried only the hypothesis
`h_homog : ∀ μ : Fin N → ℕ, glWeightSpace μ ≠ ⊥ → ∑ μ = n`, which is too weak.

Counterexample: `M = det⁻¹` (the 1-dim rep `ρ(g) = det(g)⁻¹`). It *is* an
`IsAlgebraicRepresentation` (via the `D` variable). Every `glWeightSpace μ` with
`μ : Fin N → ℕ` is `⊥` (the weight is `-1` everywhere, never a natural number),
so `h_homog` holds vacuously for any `n`. But `ρ(scalarGL t) = (t^N)⁻¹ = t^{-N}`,
which is never `t^n • id` for `n : ℕ`. The target the issue wanted me to *prove*,
`⨆ μ, glWeightSpace = ⊤`, is exactly what fails here (it is `⊥`), and is **not
derivable** for a rational rep with negative weights.

Fix: the weight-span fact is the hypothesis that `M` is a *polynomial* rep, so I
added it explicitly as `hspan : (⨆ μ : Fin N →₀ ℕ, glWeightSpace k N M (fun i => μ i)) = ⊤`
and threaded it through the chain:
- `scalarGL_acts_as_pow` (now proved in full from `hspan`)
- `polynomialRep_homogeneous_hpoly'`
- `polynomial_homog_rep_equivariant_embedding`

The Piece 2 consumer signature (`hpoly'_of_scalarGL_action`, which takes the
*conclusion* `h_scalar`) is unchanged, so issue #4654 is unaffected.

New supporting lemma `scalarGL_eq_noncommProd`: `scalarGL t = ∏ᵢ diagUnit i t`
as a `Finset.noncommProd` (GL is noncommutative; the diagonal generators commute
via `diagUnit_comm`). The action proof is a `noncommProd` induction:
`scalarGL t` acts on a weight vector `w ∈ M_μ` by `∏ᵢ t^(μ i) = t^(∑ μ) = t^n`,
then the operator `ρ(scalarGL t) - t^n • id` vanishes on the spanning weight
spaces (`hspan`), hence is `0`.
