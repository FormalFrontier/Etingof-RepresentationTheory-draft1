## Key proof idea (Track B)

Right exactness is deduced from Mathlib's right exactness over `ℤ` rather than reproved.
Writing `u = lTensor X f`, `v = lTensor X g` and `S_M, S_N, S_P` for the balancing submodules:
a **surjective** `g` maps `S_N` *onto* `S_P` (`map_balancingSubmodule` — the only place
surjectivity is used, since each generator of `S_P` lifts along `g`). Then

    ker (mapQ v) = map mkQ (comap v S_P) = map mkQ (comap v (map v S_N))
                 = map mkQ (S_N ⊔ ker v) = map mkQ (S_N ⊔ range u) = map mkQ (range u)
                 = range (mapQ u),

using `Submodule.ker_mapQ`, `Submodule.range_mapQ`, and a small local
`comap_map_eq_sup_ker` (`(map f p).comap f = p ⊔ ker f`, absent from Mathlib for linear maps).
