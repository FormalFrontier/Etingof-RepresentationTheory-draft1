Executed feature issue #6499 (Ch5 Problem 5.24.2 steps 1-2: the coordinate ↔ tensor

Deliverables:
- **`endTensorEval` (deliverable 1, sorry-free def).** A `ℂ`-linear evaluation pairing
  `Module.End ℂ (V^⊗n) →ₗ[ℂ] MatrixTupleRing k N` (with `V = ℂ^N = Fin N → ℂ`, so
  `Module.End ℂ (V^⊗n) ≃ End(V)^⊗n`), sending `M` to
  `Tr((toMatrix M).map C · genericTensorMatrix slot)`, the complete contraction of `M`'s
  matrix (in the standard tensor basis) against the generic tensor `⨂ⱼ X_{slot j}`,
  where `slot : Fin n → Fin k` is the slot-to-letter assignment from the multidegree.
  Built as `evalMatrix slot ∘ₗ (LinearMap.toMatrix tensorBasis tensorBasis).toLinearMap`.
  Supporting defs `tensorBasis`, `genericTensorMatrix`, `evalMatrix` are all sorry-free,
  plus a sorry-free unfolding lemma `endTensorEval_apply` (by `rfl`).
- **`weightedHomogeneous_invariant_mem_range_endTensorEval` (deliverable 2, real
  statement, sorried proof).** States that every fixed-multidegree-`d`
  conjugation-invariant polynomial lies in the image under `endTensorEval slot` of
  `symGroupImage ℂ V n` (the `GL(V)`-invariant part of `End(V)^⊗n`), for any `slot`
  compatible with `d` (`|slot⁻¹ i| = d i`). The proof (First Fundamental Theorem via
  Schur–Weyl surjectivity) is the lone proof-level `sorry`.

Design choice: defined `endTensorEval` on `Module.End ℂ (TensorPower ℂ V n)` (not on
`TensorPower ℂ (End V) n`) because that is where the permutation operators
`symGroupAction σ` and the subalgebra `symGroupImage` actually live, making deliverable 2
reference `symGroupImage` directly and matching the sibling issue #6500's phrasing
(`P σ A = symGroupAction σ ∘ PiTensorProduct.map A`).

`lake build EtingofRepresentationTheory.Chapter5.Problem5_24_2_Bridge` compiles; the only
