## Accomplished

Fixed the fidelity gap in `Chapter8/Definition8.2.3` (issue #5628). The book's
`Torᵢᴬ(M, N)` is genuinely asymmetric: `M` is a **right** `A`-module, `N` a
**left** `A`-module, and `⊗_A` is over a possibly non-commutative ring `A`. The
old Lean abbrev aliased `CategoryTheory.Tor C n : C ⥤ C ⥤ C`, the derived tensor
of a *single* monoidal abelian category, where both arguments live in the same
category — it cannot model the general-ring setting.

Rebuilt the definition from scratch in `EtingofRepresentationTheory/Chapter8/Definition8_2_3.lean`:

- `balancedSubgroup` / `tensorOver`: the tensor product `M ⊗_A N` over a
  non-commutative ring `A`, which Mathlib lacks (`TensorProduct R` requires `R`
  commutative). Built as the quotient of the additive tensor `M ⊗_ℤ N` by the
  balancing relation `(m * a) ⊗ n = m ⊗ (a • n)`, with right `A`-modules realised
  as `ModuleCat Aᵐᵒᵖ`.
- `tensorRightMap` / `tensorRightFunctor : ModuleCat Aᵐᵒᵖ ⥤ AddCommGrpCat`: the
  functor `M ↦ M ⊗_A N`, with full functoriality proofs.
- `Additive` instance for the functor (fully proven).
- `TorFunctor A N n` (left derived functor) and `Tor A N M n` (its value at `M`).

The whole file is **sorry-free**: `#print axioms Etingof.Tor` reports only
`propext, Classical.choice, Quot.sound`.
