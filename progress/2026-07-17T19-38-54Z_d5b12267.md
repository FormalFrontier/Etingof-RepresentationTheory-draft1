## Accomplished

Proved `affine_one_branch_three_arms` (sorry-free) in
`EtingofRepresentationTheory/Chapter6/Problem6_1_3_continued_tildeE.lean`
(issue #6928, residual of #6918). This is the tree-partition graph-theory core of the
one-branch affine tree case (⟹ Ẽ₆/Ẽ₇/Ẽ₈): a connected acyclic affine Dynkin diagram with all
degrees ≤ 3 and a unique degree-3 vertex `v` decomposes, after deleting `v`, into exactly three
components, each linearised into a rooted arm by the landed `affine_arm_walk`.

Proof structure:
- Build `G : SimpleGraph (Fin n)` from `adj`, prove `G.IsTree`/`G.IsAcyclic` from the acyclicity
  bound `hacyc` (edge count = n-1), reusing the `affine_tree_branch_count` scaffolding pattern.
- Extract the 3 neighbours `nb : Fin 3 → Fin n` of `v` via `(G.neighborFinset v).orderIsoOfFin`.
- Define components `S t := {w | reachable from nb t avoiding v}` (a `Finset` filter, classical).
- Key lemma `neighbour_comp_eq`: a neighbour of `v` reachable-avoiding-`v` from `nb t` equals
  `nb t` (concat the avoiding path with the edge to `v`, compare against the single edge
  `nb t — v` via `isAcyclic_iff_path_unique`, force length 0). This gives disjointness (`Sdisj`),
  unique-neighbour (`hnb_uniq`), and no-cross-edge (`Comp_edge`).
- `hSconn`: internal connectivity in `List`-form (via `Walk.support` + `isChain_adj_support` +
  `List.isChain_iff_getElem`), routing `a → nb t → b` and pulling every support vertex back into
  `S t` with `takeUntil`.
- Cover via the second-vertex `q.snd` of a `v → w` path (`adj_snd`, `tail`, `support_tail`).
- Feed each `S t` to `affine_arm_walk`; assemble `n = 1 + L0 + L1 + L2` from the partition
  (`card_union_of_disjoint`), cross-arm distinctness/edges from disjointness.
