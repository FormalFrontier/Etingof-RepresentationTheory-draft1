## 2. What the book claims

> **Theorem 5.17.1 (The hook length formula).** One has
> `dim V_λ = n! / ∏_{(i,j): i ≤ λ_j} h(i,j)`.

The proof deletes the first row and inducts (Frame–Robinson–Thrall), using formula (5.17.1) to
identify `l₁! / ∏_{1<j≤N}(l₁ − l_j)` with the product of the first-column hook lengths `h(i,1)`.
The product `∏_{(i,j)} h(i,j)` ranges over **all cells of the diagram** of `λ ⊢ n`, and `h(i,j)`
is the hook length at cell `(i,j)`.

## 4. The nat-division-soundness question (the key trap)

The concern: `Theorem5_17_1` states an equation with **ℕ** division, which truncates
(`⌊n! / H⌋`). If the equation held only because of truncation, it would be a DEFECT (the true
rational identity `dim V_λ = n!/H` would not be captured). This is **not** what happens here:

1. `card_standardYoungTableau_mul` (`FRTHelpers.lean:1981`) proves the **exact** integer identity
   `Nat.card (StandardYoungTableau n la) * la.toYoungDiagram.hookLengthProduct = n.factorial`
   by induction on `n` (base case `n=0`, inductive step via the branching-rule/outer-corner
   recurrence). No division appears here — it is a genuine product identity.
2. `hookLengthProduct_dvd_factorial` (`FRTHelpers.lean:1990`) packages this as `H ∣ n!`, so the
   divisor genuinely divides the dividend and truncation is a no-op.
3. `card_standardYoungTableau_eq` (`FRTHelpers.lean:1996`) then derives
   `|SYT(λ)| = n! / H` by rewriting `n! = |SYT| * H` and applying `Nat.mul_div_cancel _ hpos`,
   where `hpos : 0 < H` comes from `YoungDiagram.hookLengthProduct_pos`. The cancellation is
   exact precisely because `H` divides `n!` **and** `H > 0`; the ℕ-division recovers `|SYT|`
   with no rounding.

So the equation is faithful for the right reason. It could **not** hold "accidentally" via
truncation: any partition satisfies the exact `|SYT| * H = n!`, so `n!/H = |SYT|` on the nose.
There is no partition for which the stated ℕ-equation holds while the true integer identity fails.
**No defect.**

## 5. `hookLengthProduct` is real, non-trivial content

`YoungDiagram.hookLengthProduct μ := μ.cells.prod (fun c => μ.hookLength c.1 c.2)`
(`FRTHelpers.lean:32`) — a genuine product over **all** cells of the diagram, not a placeholder
and not vacuously `1` for non-empty λ.

`YoungDiagram.hookLength μ i j := μ.rowLen i + μ.colLen j - i - j - 1` (`FRTHelpers.lean:28`).
With 0-indexed cells, `rowLen i = λ_i` and `colLen j = λ'_j` (conjugate), so this is
`(λ_i − j) + (λ'_j − i) − 1` = arm + leg + 1 = the standard hook length. This matches both the
def's own docstring (`h(i,j) = (rowLen i − j) + (colLen j − i) − 1`) and the file-header docstring
(`h(i,j) = λᵢ − j + λ'ⱼ − i − 1`). Convention is consistent. `hookLength_pos` /
`hookLengthProduct_pos` (`FRTHelpers.lean:38,47`) confirm each in-diagram hook length is `> 0`
(so the ℕ subtraction does not underflow at real cells) and the product is `> 0`.

The empty diagram (n=0) gives `hookLengthProduct = 1` (empty product) — the correct value, not a
degeneracy that trivializes the theorem: there `|SYT| = 1` and `0! = 1`, all consistent.
