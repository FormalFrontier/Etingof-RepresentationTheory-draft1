## Sources compared

- **Book statement** (`blobs/Chapter5/Theorem5.15.1.md`):
  > **Theorem 5.15.1.** *Let $N \geq p$. Then $\chi_{V_\lambda}(C_\mathbf{i})$ is the
  > coefficient of $x^{\lambda+\rho} := \prod x_j^{\lambda_j + N - j}$ in the polynomial
  > $\Delta(x) \prod_{m \geq 1} H_m(x)^{i_m}$.*
- **Book definitions** (`blobs/Chapter5/Introduction_5.15.md`,
  `blobs/Chapter5/Discussion_character_computation_setup.md`):
  - $\Delta(x) = \prod_{1 \le i < j \le N}(x_i - x_j) = \det(x_i^{N-j})$ (Vandermonde).
  - $\rho = (N-1, N-2, \ldots, 0) \in \mathbb{C}^N$.
  - $C_\mathbf{i}$ = the conjugacy class of $S_n$ with $i_m$ cycles of length $m$ for
    each $m \ge 1$ (the cycle type).
  - $H_m(x) = \sum_j x_j^m$ — the **power sum** (the book's non-standard use of the
    letter $H$; it is defined on p. 116 as the power sum, *not* the complete
    homogeneous symmetric polynomial).
- **Book proof** (`blobs/Chapter5/Discussion_proof_of_Theorem5.15.1.md`): defines
  $\theta_\lambda$ = the RHS class function, shows via Theorem 5.14.3 that
  $\theta_\lambda = \sum_{\mu \ge \lambda} L_{\mu\lambda}\chi_\mu$ with $L_{\lambda\lambda}=1$
  (upper-triangular in dominance order), then concludes $\theta_\lambda = \chi_\lambda$.
- **Lean statement** (`EtingofRepresentationTheory/Chapter5/Theorem5_15_1.lean:2824`):

```lean
theorem Theorem5_15_1
    (n : ℕ) (la : Nat.Partition n) (σ : Equiv.Perm (Fin n)) :
    (Equiv.Perm.sign (Fin.revPerm (n := n)) : ℤ) • spechtModuleCharacter n la σ =
      MvPolynomial.coeff (Nat.Partition.toFinsupp la + rhoShift n)
```

## Fidelity checks (per issue deliverable 1)

### 1. LHS: `spechtModuleCharacter n la σ` is the true irreducible character χ_{V_λ}(σ)

- `SpechtModule n la` (`Theorem5_12_2_Irreducible.lean:26`) is
  `Submodule.span (SymGroupAlgebra n) {YoungSymmetrizer n la}`, i.e. the left ideal
  $\mathbb{C}[S_n]\cdot c_\lambda$ generated by the Young symmetrizer — the genuine
  shape-λ Specht module $V_\lambda$, not a placeholder. ✓
- `spechtModuleAction n la σ` (`:76`) is left multiplication by `of σ` on this ideal,
  a genuine `ℂ`-linear endomorphism (submodule closure is proved via `smul_mem`), and
  `spechtModuleCharacter n la σ := LinearMap.trace ℂ _ (spechtModuleAction n la σ)`
  (`:85`) is its honest trace. ✓
- **Irreducibility certificate.** `spechtModuleFDRep_simple` (`:141`) is a genuine
  `Simple (spechtModuleFDRep n la)` instance, transferred from
  `Theorem5_12_2_irreducible` (`IsSimpleModule`) through
  `Rep.equivalenceModuleMonoidAlgebra` and a full-faithful-functor reflection lemma.
  So the LHS is the character of an *irreducible* representation — the book's χ_{V_λ}. ✓
- **FDRep bridge is a real `rfl`.** `spechtModuleFDRep_character` (`:114`) states
  `(spechtModuleFDRep n la).character σ = spechtModuleCharacter n la σ := rfl`. This is
  definitional: `spechtModuleFDRep := FDRep.of (spechtModuleRep n la)` and
  `spechtModuleRep.toFun = spechtModuleAction`, so `FDRep.character` unfolds to the same
  trace. It is a faithful bridge, **not** a redefinition that trivializes the claim. ✓

### 2. RHS Vandermonde factor: `vandermondePoly n` is Δ(x), with a documented sign fix

- `vandermondePoly n := ∏ i, ∏ j ∈ Finset.Ioi i, (X j - X i)` (`:66`) =
  $\prod_{i<j}(x_j - x_i)$ — the **Mathlib** Vandermonde orientation.
- The book's $\Delta(x) = \prod_{i<j}(x_i - x_j)$ has the *opposite* orientation. The two
  differ by the global sign $(-1)^{\#\{i<j\}} = (-1)^{n(n-1)/2}$, independent of σ and λ.
- The compensating `(Equiv.Perm.sign (Fin.revPerm) : ℤ) •` factor is **exactly** this
  global sign. Verified numerically in Lean:
  `sign(revPerm)` = `-1` at n=2, `-1` at n=3, `+1` at n=4 — matching
  $(-1)^{n(n-1)/2}$ = $(-1)^1, (-1)^3, (-1)^6$. Since `revPerm` (the order-reversal
  permutation of `Fin n`) has exactly $n(n-1)/2$ inversions, `sign(revPerm)` =
  $(-1)^{n(n-1)/2}$ in general.
- Reading the equation both ways: Lean asserts
  $s\cdot\chi_{V_\lambda}(\sigma) = \text{coeff}_{x^{\lambda+\rho}}(\Delta_{\text{Mathlib}}\cdot\prod p_m^{i_m})$
  with $s = (-1)^{n(n-1)/2}$, $s^2=1$; multiplying by $s$ gives
  $\chi_{V_\lambda}(\sigma) = (-1)^{n(n-1)/2}\,\text{coeff}(\Delta_{\text{Mathlib}}\cdot\ldots)
  = \text{coeff}(\Delta_{\text{book}}\cdot\ldots)$ — the book's formula on the nose.
  The sign is a **correct, documented normalization**, not a masked error. ✓

### 3. RHS exponent vector: `Nat.Partition.toFinsupp la + rhoShift n` is λ+ρ

- `rhoShift n := Finsupp.equivFunOnFinite.symm (fun i => n - 1 - i.val)` (`:71`), so
  component `i` (0-indexed) is `n-1-i`. This is ρ = (n-1, n-2, …, 1, 0). Verified in
  Lean: `rhoShift 3 = (2,1,0)`. ✓ (Book: $\rho_j = N-j$ for 1-indexed $j$, i.e.
  $N-1-i$ for 0-indexed $i$ — identical.)
- `Nat.Partition.toFinsupp la` (`Theorem5_14_3.lean:50`) maps position `i` to the
  `i`-th largest part `la.sortedParts.getD i 0` = $\lambda_{i+1}$. Hence
  `(toFinsupp la + rhoShift n) i = λ_{i+1} + (n-1-i)`, matching the book's exponent
  $\lambda_j + N - j$ (0-indexed). So `MvPolynomial.coeff (toFinsupp la + rhoShift n)`
  extracts the coefficient of $x^{\lambda+\rho}$. ✓

### 4. RHS power-sum factor: `cycleTypePsumProduct n σ` is ∏_{m≥1} p_m(x)^{i_m}

- `cycleTypePsumProduct n σ` (`Theorem5_14_3.lean:69`) =
  `(σ.cycleType.map (MvPolynomial.psum (Fin n) ℂ)).prod * MvPolynomial.psum (Fin n) ℂ 1 ^ (n - σ.support.card)`.
  - `MvPolynomial.psum (Fin n) ℂ m` = $\sum_i x_i^m$ = the honest power sum $p_m$ =
    book's $H_m$. ✓
  - `σ.cycleType` lists the lengths of cycles of length ≥ 2, and the `psum 1 ^
    (n - σ.support.card)` factor supplies one $p_1$ per fixed point. So the product is
    $\prod_{\text{cycles } c} p_{|c|} \cdot p_1^{\#\text{fixed}} = \prod_{m\ge1} p_m^{i_m}$
    where $i_m$ = number of $m$-cycles of σ = the cycle type. ✓
  - **Not the complete-homogeneous mistake.** The file docstring (`:64`) records that a
    previous version used `hsymm` (complete homogeneous), which is *incorrect*, and that
    the book's $H_m$ is the power sum. The current definition uses `psum`. ✓
- **Depends on σ only through its cycle type.** Supporting lemma
  `cycleTypePsumProduct_inv` (`Theorem5_14_3.lean:76`) proves
  `cycleTypePsumProduct n σ⁻¹ = cycleTypePsumProduct n σ` (via `cycleType_inv` /
  `support_inv`); more fundamentally the definition is a function of `σ.cycleType` and
  `σ.support.card` alone, which are conjugacy-invariant. So the RHS is genuinely a
  class function of σ, as the book's $C_\mathbf{i}$ requires. ✓
- **Symmetric.** `cycleTypePsumProduct_isSymmetric` (`Theorem5_15_1.lean:295`) proves the
  product is a symmetric polynomial, as needed for the coefficient-of-$x^{\lambda+\rho}$
  extraction to be well-posed. ✓

### 5. Hypotheses and the $N \ge p$ / degree condition

- Hypotheses `n : ℕ`, `la : Nat.Partition n`, `σ : Equiv.Perm (Fin n)`, base field ℂ,
  match the book. The number of variables is `Fin n` = `n`, so the book's $N$ is our `n`
  and the partition of $n$ has at most `n` parts — the book's `N ≥ p` (enough variables
  to hold the partition, here `p` = number of parts) is automatic since `n` variables
  suffice for any partition of `n`. No hidden restriction narrows the statement. ✓

## Non-vacuity

- **RHS is honest content, not trivially 0/1.** `vandermondePoly n` is a nonzero
  polynomial (a product of distinct linear forms), `cycleTypePsumProduct n σ` is a
  nonzero product of power sums, and `MvPolynomial.coeff` extracts a genuine coefficient
  of their product. The exponent `toFinsupp la + rhoShift n` is a real multidegree, so
  the RHS is a bona-fide integer coefficient, not vacuously constant.
- **LHS is not identically zero.** The Specht module is nontrivial (it is `Simple`, hence
  `Nontrivial`), so at σ = 1 its character is its dimension ≥ 1. The character therefore
  carries real content.
- **Orthonormality certificate.** `specht_char_inner` (`:2313`) gives
  $\sum_\sigma \chi_\mu(\sigma)\chi_\nu(\sigma^{-1}) = n!\,\delta_{\mu\nu}$, and
  `spechtModuleCharacter_injective` (`:2341`) uses it to prove that distinct partitions
  yield distinct character functions. A vacuous or constant character could not satisfy
  norm² = n! ≠ 0 nor separate partitions — this is a strong non-vacuity witness.
- **Concrete hand-check (n=3, λ=(2,1)).** The (2,1)-irrep of S₃ is the standard
  2-dimensional representation with character χ(e)=2, χ(transposition)=0, χ(3-cycle)=-1.
  Since `sign(revPerm (n:=3)) = -1`, the theorem reads
  $-\chi_{V_{(2,1)}}(\sigma) = \text{coeff}_{x^{(2,1,0)+(2,1,0)}=x^{(3,2,0)}}
  (\Delta_{\text{Mathlib}}\cdot\prod p_m^{i_m})$. Both sides are non-degenerate:
  the LHS ranges over {-2, 0, 1} across the three classes, and the exponent
  $(3,2,0)$ is a genuine multidegree present in $\Delta\cdot\prod p_m^{i_m}$, so no
  degenerate case collapses the identity. (The general theorem is proved for **all**
  n, λ, σ, so it is a genuine identity, not merely a witnessed instance.)
- **Degenerate cases do not trivialize.** For n=0 the statement is the empty-product
  identity `1•χ = coeff 0 (1·1) = 1` at the unique element — true and non-vacuous, and
  it is not the only content: the theorem quantifies over all n.
