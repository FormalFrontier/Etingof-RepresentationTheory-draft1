## Accomplished

Feature session on #6574 (`isSemisimpleRing_of_nondegenerate`, Ch3 Problem 3.9.5(i)
semisimplicity). Landed two reusable, sorry-free pieces in
`EtingofRepresentationTheory/Chapter3/Problem3_9_5.lean`:

- **`instance : Module.Finite ℂ (CliffAlg B)`** — finite-dimensionality of `Cl(V)`, which was
  missing from both Mathlib and this file yet is needed by *every* part of the problem (it makes
  `Cl(V)` Artinian). Proof transports the finite basis `Module.Basis.ExteriorAlgebra` across the
  characteristic-≠-2 linear equivalence `CliffordAlgebra.equivExterior` (`Invertible (2:ℂ)` via
  `invertibleOfNonzero two_ne_zero`).
- **`isSemisimpleRing_of_traceForm_nondegenerate`** — the general char-0 **Dickson criterion**: a
  finite-dimensional `ℂ`-algebra whose trace form `(x,y) ↦ tr(L_{x*y})` is nondegenerate is
  semisimple. Proof: Artinian ⇒ Jacobson radical `J` nilpotent; for `x ∈ J`, `y*x ∈ J` is
  nilpotent, so `L_{y*x}` is nilpotent with zero trace; `tr(L_{x*y}) = tr(L_{y*x})` by
  `trace_mul_comm`; nondegeneracy ⇒ `x = 0` ⇒ `J = ⊥`; `isSemisimpleRing_iff_jacobson`.

`isSemisimpleRing_of_nondegenerate` now `apply`s the Dickson criterion, reducing the target to a
single concrete `sorry`: the Clifford trace form is nondegenerate when `B` is. Sorry count 5 → 4
theorem-level (finiteness + Dickson added proven; target sorry made concrete). File builds.
