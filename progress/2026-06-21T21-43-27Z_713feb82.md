```
finrank_glWeightSpace_polyRightDegreeFDRep (d : ℕ) (μ : Fin N → ℕ) :
  finrank k (glWeightSpace k N (polyRightDegreeFDRep k N d) μ)
    = if (∑ j, μ j) = d then ∏ j, (μ j + N - 1).choose (N - 1) else 0
```

plus the `formalCharacter`-coefficient form `formalCharacter_polyRightDegreeFDRep_coeff`.

Structure of the proof (top-down):
1. **Eigenbasis (ambient).** `polyRightRep_diagUnit_monomial`: `diagUnit k N i t`
   scales `monomial s c` by `t ^ (∑_l s(l,i))` (the `i`-th column degree), built on
   the landed `rTransAlgHom_diagonal_monomial`. `coeff_polyRightRep_diagUnit`: the
   coefficient form, `coeff s (R_{diagUnit i t} x) = t^(col_i s) · coeff s x`.
2. **Membership.** `polyOf` = the `k`-linear inclusion of the `FDRep` carrier `A_d`
   into `k[Xᵢⱼ]` (the homogeneous-submodule subtype, accepted by defeq).
   `mem_glWeightSpace_polyRight_iff` reads weight-space membership as a torus
   eigen-equation on the underlying polynomial.
3. **Span = weight space.** `map_polyOf_glWeightSpace`: the pushforward of the
   `μ`-weight space is the span of the degree-`d`, column-degree-`μ` monomials
   (`Dset N d μ`). Forward inclusion uses coefficient extraction + distinct-power
   separation (`exists_unit_pow_ne`); backward uses the eigenvalue lemma.
4. **finrank = card.** `finrank_glWeightSpace_eq_card` via `equivMapOfInjective`
   (injective `polyOf`) + `finrank_span_eq_card` (monomials are a sub-basis of
   `basisMonomials`).
5. **Counting (stars and bars).** `card_Dset`: a column-by-column bijection
   `Dset ≃ Fintype.piFinset (fun j => piAntidiag univ (μ j))`, `Fintype.card_piFinset`,
   and `(piAntidiag univ m).card = multichoose N m` (`card_piAntidiag_univ`, via
   `map_sym_eq_piAntidiag` + `Finset.sym_univ` + `card_sym_fin_eq_multichoose`),
   then `multichoose N m = C(m+N-1, N-1)` for `N ≥ 1`.
