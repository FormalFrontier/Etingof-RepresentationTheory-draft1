## Decomposition rationale

The universal `non_adjacent_branches_infinite_type`
(`Chapter6/InfiniteTypeConstructions.lean:9682-10597`) is
~900 lines and factors into an internal `leaf_case` helper
(used three times) plus an inline all-deg-2 `Ẽ₆` embedding.
The universal `leaf_case` embeds `D̃_{k+5}` for arbitrary `k =
chain.length - 2`, but **no per-(F, Q) leaf for general `D̃_n`
exists on `main`** — only `d5tilde_not_finite_type_per_kQ` for
the fixed `k = 0` case (`Chapter6/FieldGenericD5Tilde.lean:999`).

This means the per-(F, Q) version cannot mechanically mirror
the universal proof; the `leaf_case` must be redesigned to use
only the per-(F, Q) leaves available on `main` (`d5tilde`,
`etilde6`, `etilde7`, `t125`, `subgraph_infinite_type_transfer_per_kQ`).
Single-branch precedent (`single_branch_leaf_case_per_kQ`,
`Chapter6/FieldGenericTpqr.lean:1306`) does exactly this for the
single-branch case via `T(p, q, r)` variants.

The all-deg-2 case (universal lines 10324-10597, ~270 lines) is
a mechanical mirror — it embeds `Ẽ₆` and uses the existing
`etilde6_not_finite_type_per_kQ`. Bundling it with the outer
dispatcher (Sub-A2) keeps neighbour extraction and the all-deg-2
embedding in one issue.
