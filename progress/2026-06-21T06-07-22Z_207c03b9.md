## Key findings / decisions

- The comorphism is parametrized over an **abstract** localization `B`
  (`[IsLocalization (Submonoid.powers (detProd m)) B]`), mirroring the bridge's
  abstract-`B` style; `Localization (Submonoid.powers (detProd m))` is one concrete
  instance. This keeps the def real (no sorry) and avoids the missing
  `Algebra k (Localization S)` instance friction.
- `detProd ≠ 0` is cleanest via evaluation at the identity matrix
  (`AlgHom.map_det` + `genMat_map_evalId` → `det 1 = 1`), not via Leibniz-expansion
  nonzero-coefficient arguments.
- `AlgHom.map_det f M` yields `(f.mapMatrix M).det`, **not** `(M.map ⇑f).det` —
  state the helper (`genMat_map_evalId`) with `AlgHom.mapMatrix` to match.
- Used the index types `GIdx`/`WIdx` (sigma types) directly as `MvPolynomial`
  indices rather than `Fin N`/`Fin M`; the `Fin`-conversion (`renameEquiv`) is
  deferred to the assembly sub-issue.
