## Accomplished

Feature session for issue #7258 — the capstone of the character-theoretic counting
bridge (parent #7254): assembling the two landed dimension bricks into the headline
result that a finite group has as many irreducible ℂ-representations as conjugacy classes.

New file `EtingofRepresentationTheory/Chapter5/IrrepCountConjClasses.lean`, imported into
`Chapter5.lean`. Sorry-free, axiom-clean (only `propext`, `Classical.choice`, `Quot.sound`).
Headline declarations:

- `Etingof.monoidAlgebra_algEquiv_pi_matrix_card_conjClasses` — for a finite group `G`,
  there is a nonzero block-size family `d : Fin (Nat.card (ConjClasses G)) → ℕ` and an
  algebra isomorphism `ℂ[G] ≃ₐ[ℂ] Π i, Matrix (Fin (d i)) (Fin (d i)) ℂ`. The Wedderburn
  decomposition of `ℂ[G]` therefore has exactly `#(ConjClasses G)` matrix factors — one per
  isomorphism class of irreducible representation.
- `Etingof.card_irrep_eq_card_conjClasses` — the same with an explicit index type `Irrep G`
  (`Nat.card (Irrep G) = Nat.card (ConjClasses G)`) enumerating the Wedderburn matrix blocks.

The proof simply chains the two bricks already on `main`:
- group-algebra half `Etingof.GroupAlgebra.finrank_center_eq_card_conjClasses`
  (`dim_ℂ Z(ℂ[G]) = #(ConjClasses G)`), and
- Wedderburn half `Etingof.finrank_center_monoidAlgebra_eq_wedderburn_factors`
  (`ℂ[G] ≃ₐ Π i : Fin (dim_ℂ Z(ℂ[G])), Matrix …`).
Rewriting the factor-index `Fin (dim_ℂ Z(ℂ[G]))` to `Fin (#ConjClasses G)` via the first
identity gives the result.

## Design note

The issue offered two counting types for "iso classes of irreducible ℂ-reps": a literal
count of simple ℂ[G]-modules, or the number of Wedderburn matrix factors "against the
decomposition". A literal simple-module count would need isotypic-component / simple-module
enumeration infrastructure not readily available in Mathlib v4.32.0-rc1, so I used the
decomposition form the issue explicitly sanctions. The factor count is faithful: each block
`Matrix (Fin dᵢ) (Fin dᵢ) ℂ` is the endomorphism algebra of exactly one irreducible
representation, so #blocks = #irreps.
