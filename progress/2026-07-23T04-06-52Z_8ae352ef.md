Two source-elaboration failures, both the same root cause:
`pow_eq_zero_of_le` (in `biprodMap_isNilpotent`) and the `IsNilpotent`
witness substitution (in `isNilpotent_conj`) produce the *ring* zero
`0 : End _`. In a preadditive category `AddCommGroup (End X)` is
`inferInstanceAs (AddCommGroup (X ⟶ X))`, so this zero is defeq to the
morphism zero `0 : X ⟶ X` but carries a syntactically distinct `Zero`
instance. Once it lands in a `biprod.map`/composition slot, simp's
`biprod.inl_map`, `zero_comp`, and `comp_zero` cannot fire (their
discrimination-tree key is the hom `Zero`).

  coercion re-elaborates the RHS with the hom `Zero` instance), rewrite
  them into `hpow` so the existing `hz`/`exact hpow` tail matches.

  the composite with `0 : X ⟶ X` so the final `simp` discharges it.
