## Accomplished

Formalized the general **character ⇒ multiplicity bridge** for `Sₙ`-representations
(issue #6356), in the new file
`EtingofRepresentationTheory/Chapter5/CharacterMultiplicityBridge.lean` (added to the
`Chapter5.lean` aggregator).  Sorry-free, `native_decide`-free, axiom-clean
(`propext`/`Classical.choice`/`Quot.sound` only).

The file lifts the concrete `PermutationModule` isotypic machinery of `Theorem5_15_1.lean`
to an **arbitrary** finite dimensional `SymGroupAlgebra n`-module `M` (`M : Type`), and adds
`Representation`-level wrappers.  Key declarations:

- `Etingof.moduleEnd` / `moduleCharacter` — the `σ`-action (mult. by `of σ`) and its trace.
- `Etingof.isotypicComp` / `isotypicMult` — the `V_ν`-isotypic component and its
  multiplicity `dim_ℂ(component) / dim_ℂ V_ν`.
- `Etingof.isotypicComp_isInternal` — `M = ⊕_ν (V_ν-isotypic component)` (general form of
  `permModule_isotypic_isInternal`), via generalized `gen_iSup_isotypicComponent_eq_top` and
  `gen_iSupIndep_isotypicComponent`.
- `Etingof.character_eq_sum_mult_spechtCharacter` — **deliverable 1**:
  `χ_M(σ) = Σ_ν (isotypicMult n M ν) · χ_{V_ν}(σ)`.
- `Etingof.specht_embeds_of_mult_pos` — **deliverable 2**: `isotypicMult ≠ 0` gives an
  injective `Sₙ`-embedding `V_ν ↪ M`.
- `Etingof.factorial_mul_isotypicMult` / `isotypicMult_eq_of_character_eq` — multiplicity
  recovered from the character (orthonormality), so equal character ⇒ equal multiplicities.
- `Representation` wrappers: `repIsotypicMult`, `repCharacter_eq_sum_mult_spechtCharacter`,
  `repSpecht_embeds_of_mult_pos`, `repIsotypicMult_eq_of_character_eq`,
  `moduleEnd_asModule_eq` / `repCharacter_eq_moduleCharacter`.

The only `M`-specific inputs are Maschke semisimplicity (`inferInstance`) and the ℂ
classification `Theorem5_12_2_classification` (which needs `M : Type`, matching all
downstream consumers: `Res V_λ`, `ρ.asModule` for `V : Type`).
