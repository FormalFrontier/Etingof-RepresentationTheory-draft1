## Deviation from spec

The issue body specified a **joint conclusion**
(`x ∈ Wmain ⟨0⟩ ∧ z ∈ Wmain ⟨1⟩`) for each proj-sibling, mirroring the
canonical `d5tilde_core_F` conjunction. After careful analysis, this
joint conclusion is **not derivable** from a "single reversed pull +
single canonical push" hypothesis set — the projection identity
recovers only the half tied to the reversed-direction projection
(`starFirst_F` recovers `x`; `starSecond_F` recovers `z`). The
other half would require either:

1. The companion reversed pull (i.e., the OTHER leaf is also
   reversed), in which case composing both proj-siblings recovers
   the full conjunction; or
2. The canonical-style `core_F` decomposition (which needs both
   leaves canonical).

A "single pull + single push" sub-case cannot conclude both halves
in general (verified by working through the canonical-style
decomposition: the constraint `u_other + starEmbed2_F d = 0` becomes
underdetermined without a `starSecond_F : Wother ⟨2⟩ → Wother ⟨1⟩`
hypothesis).

The lemmas land **single-half conclusions** instead:

- `proj1` returns `x ∈ W ⟨0⟩` (or `W ⟨4⟩`).
- `proj2` returns `z ∈ W ⟨1⟩` (or `W ⟨5⟩`).

The planner's "Notes for the worker" explicitly allows this
minimisation:

> If the four sibling lemmas can be cleanly unified into fewer
> theorems […], prefer the unified form. The decomposition above is
> a maximum — minimising is fine.

The half-conclusion lemmas are **strictly more flexible** than a
joint-conclusion lemma: a sub-case where both leaves are reversed
composes both proj-siblings; a sub-case where only one leaf is
reversed uses only that side's proj-sibling and derives the other
half via whatever local argument fits.

Each lemma takes a single submodule `W` (not the Wmain/Wother pair),
since complement uniqueness is not needed for the half-conclusion.
The caller applies each lemma separately to W₁ and W₂ as needed.
