## Accomplished

Worked #4870 (the ℂ-side Schur-Weyl counting step `|ι| = |P|`, i.e. surjectivity
of the isotypic matching `φ`). Rather than the double-centralizer route the issue
suggested (which needs Krull-Schmidt uniqueness, not in the project), I proved
`hφsurj` **sorry-free as a reduction** to a single, cleaner, classical fact:

- In `Chapter5/SchurWeylSimplesClassificationComplex.lean`,
  `schurWeyl_simples_formalCharacter_classification_core_complex` now discharges
  `hφsurj : Function.Surjective φ` with no `sorry`. The proof feeds the numerical
  identity `∑ᵢ dim(Sᵢ)·char(Lᵢ) = ∑_λ dim(Specht_λ)·schurPoly λ`
  (`schurWeyl_decomposition_numerical_identity`) and `char(L (φλ)) = schurPoly λ`
  into a single vanishing `ℚ`-combination of the characters; linear independence
  of those characters then forces every empty-`φ`-fibre coefficient `dim(Sᵢ)` to
  vanish, contradicting nonzero multiplicity.

- **Spec fix (genuine, not cosmetic):** added hypothesis
  `hSne : ∀ i, 0 < Module.finrank ℂ (S i)`. Without it the theorem is *false*: a
  degenerate decomposition with `S i₀ = 0` carries an unconstrained "ghost" simple
  `L i₀` for which `char(L i₀) = schurPoly N λ` fails. The source decomposition
  `glTensorRep_equivariant_schurWeyl_decomposition` has each `S i` a simple
  `Sₙ`-module (so `0 < dim`), so a future call site supplies `hSne` freely.
  `core_complex` has no consumers yet, so the signature change is safe.

- The remaining content is isolated as a new, clearly-scoped lemma
  `schurWeyl_simples_formalCharacter_linearIndependent_complex` (one `sorry`):
  "characters of pairwise non-isomorphic simples are `ℚ`-linearly independent"
  (Dedekind/Artin character independence). Crucially this is proved **directly**
  from `hLsimp`/`hLdist`, NOT via the still-sorried classification core — using the
  existing `glTensorRep_schurWeyl_simples_formalCharacter_linearIndependent` would
  be circular (it routes through the very sorry this file aims to discharge).
