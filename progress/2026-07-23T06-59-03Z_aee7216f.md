## Accomplished

Restored fresh-buildability of
`EtingofRepresentationTheory/Chapter6/DecompositionExistence.lean` (issue #7525).
`lake env lean` and the `lake build` target now succeed with no `sorry`, `admit`,
or replacement axiom (`#print axioms exists_decomposition` reports only
`propext, Classical.choice, Quot.sound`).

Root cause: a Mathlib bump made typeclass synthesis stricter about the
`AddCommMonoid → AddCommGroup` upgrade `Etingof.addCommGroupOfRing` performs. The
upgraded `AddCommGroup.toAddCommMonoid` is only defeq to the ambient
`AddCommMonoid` at `default` transparency, not the `instances`/reducible
transparency instance search and `rw`/`simp` motive checks use. This broke every
proof that either unfolded `QuiverRepresentation.directSum` under `simp` or put the
upgraded group instance in scope.

Fixes:
- Added `rfl` `@[simp]` lemmas `directSum_obj` / `directSum_mapLinear` so proofs
  never unfold `directSum` (which exposed the bad instance).
- `AreIsomorphic.directSum`: closed component-wise with `Prod.ext` and the
  `intertwine` lemma.
- `areIsomorphic_directSum_zeroRep` / `_zeroRep_directSum` / `_directSum_assoc` and
  the append-nil case: the intertwining is definitional, so `ext x <;> rfl`.
- `areIsomorphic_subRep_directSum`: rebuilt the vertex isomorphism as
  `LinearEquiv.ofBijective` on the structure-typed coproduct-of-subtypes map `sc`,
  so the additive-group instance only enters the *bijectivity proof* and never
  types any term the arrow maps act on. Intertwining follows from a naturality
  lemma for `sc`.
- `exists_decomposition`: removed the scope-wide `letI` group instance and supplied
  the group explicitly (`@`) to `finrank_add_eq_of_isCompl`,
  `finiteDimensional_submodule`, and a new standalone helper `finrank_pos_of_ne_bot`,
  so the ambient `Module` / `Module.Finite` instances stay resolvable.
