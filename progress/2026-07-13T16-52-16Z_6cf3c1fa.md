- `periodic_not_linearEquiv_antiperiodic` (`A ≇ M`): given `φ : A ≃ₗ M`, the section
  `u := φ 1` generates `M` (`m = (φ.symm m) • u`). As a continuous antiperiodic function
  `u(x+1) = -u(x)`, so `u 0` and `u 1 = -u 0` bracket `0`; the intermediate value theorem
  (`intermediate_value_Icc` / `_Icc'`) gives `u x₀ = 0` for some `x₀ ∈ [0,1]`. Then every
  element of `M` vanishes at `x₀`, contradicting the antiperiodic section
  `x ↦ cos(π(x - x₀))` which equals `1` at `x₀`.
- `periodic_sq_linearEquiv_antiperiodic_sq` (`A ⊕ A ≅ M ⊕ M`): built the concrete rotation
  `rotInv : M×M →ₗ[A] A×A`, `(f,g) ↦ (cos·f − sin·g, sin·f + cos·g)` and its transpose
  inverse `rotFwd : A×A →ₗ[A] M×M`, `(p,q) ↦ (cos·p + sin·q, −sin·p + cos·q)`. Both are
  genuine bundled linear maps (real, non-`sorry` data); `LinearEquiv.ofLinear` plus the two
  inverse identities (`rotInv_rotFwd`, `rotFwd_rotInv`, each closed by `cos² + sin² = 1`)
  yields the equivalence, and `.symm` gives the stated `A×A ≃ₗ M×M`.
