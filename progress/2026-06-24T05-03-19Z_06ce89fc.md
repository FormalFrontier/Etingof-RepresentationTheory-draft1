## Accomplished

Formalized the faithful Weyl-algebra module `E = tᵃ k[a][t, t⁻¹]` from the discussion after
Proposition 2.7.1 (issue #5134, `Chapter2/Discussion_faithful_example`), and proved it is
**faithful in any characteristic** — sorry-free.

New file `EtingofRepresentationTheory/Chapter2/FaithfulWeylModule.lean`:

- `WeylE k := ℤ →₀ Polynomial k` models `E = tᵃ k[a][t, t⁻¹]`, with `Finsupp.single n c`
  standing for `c · t^{a+n}` (a is the formal parameter, t invertible, tᵃ a formal symbol).
- `mulX` (action of `x` = mult by `t`) and `weylD` (action of `y` = twisted derivative
  `d(t^{a+n})/dt = (a+n) t^{a+n-1}`) as `Module.End k (WeylE k)`, both via `Finsupp.lsum`.
- `weylD_mulX`: the Weyl relation `D ∘ mulX = mulX ∘ D + 1`.
- `repE : WeylAlgebra k →ₐ[k] Module.End k (WeylE k)` (the module structure), via
  `FreeAlgebra.lift` + `RingQuot.liftAlgHom`.
- `descPoly k j = a(a-1)⋯(a-j+1) = ∏_{l<j}(X - C l)` with `descPoly_monic`,
  `descPoly_natDegree = j`, `descPoly_coeff_self = 1` — monic of degree j in any characteristic.
- `repE_monomial_apply_t0`: `ρ(xⁱyʲ) tᵃ = descPoly j · t^{a+i-j}` (key evaluation).
- `evalImage_linearIndependent`: the images are linearly independent (separated by the t-power
  i-j, then within a power by the degree j of `descPoly j` — char-free maximal-degree argument).
- `repE_injective`: char-free faithfulness, assembled from `WeylAlgebra.monomials_span` (the
  span is surjective via `Finsupp.linearCombination`) + the independence of the images.

Also exposed `WeylAlgebra.monomials_span` in `Proposition2_7_1.lean` (was the `private spanning`
lemma; renamed to a public char-free theorem and its one call site updated). Added the new file
