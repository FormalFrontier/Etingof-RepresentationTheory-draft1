### New definitions and lemmas

- **`perQTau σ w q := γ_q · w · q⁻¹ · σ`** — the canonical column-standard
  representative, where `γ_q := garnirColReindex σ w q ∈ Q_λ`.
- **`perQTau_colStandard`** — `perQTau` is column-standard
  (one-line wrapper around `garnirColReindex_colStandard`).
- **`perQ_low`** — `{ q ∈ Q_λ | tabloidStrictDominates la σ τ_q }`.
- **`perQ_eq`** — `{ q ∈ Q_λ | toTabloid τ_q = toTabloid σ ∧ rowInv τ_q < rowInv σ }`.
- **`perQ_eqHi`** — `{ q ∈ Q_λ | toTabloid τ_q = toTabloid σ ∧ ¬ rowInv τ_q < rowInv σ }`.
- **`perQ_high`** — `{ q ∈ Q_λ | ¬ tabloidStrictDominates la σ τ_q ∧ toTabloid τ_q ≠ toTabloid σ }`.
- **`perQ_partition`** — every `q ∈ Q_λ` lies in exactly one of the four regions
  (membership form, avoiding `Fintype` synth on `Finset.univ : Finset ↥(ColumnSubgroup n la)`).
- **`twistedIHPart σ w`** — the IH-killable part `Σ_{q ∈ Q_low ∪ Q_eq} sign(q)·sign(γ_q)·ψ_{τ_q}`.
- **`twistedIHPart_mem_span`** — `(★) ∈ V` from the outer/inner IH on
  `(srRank, rowInvCount')`, via `srRank_lt_of_tabloidStrictDominates` (Q_low
  branch) and `srRank_eq_of_toTabloid_eq` (Q_eq branch).
- **`twistedPolytabloid_per_q_decomp`** — the main lemma. Returns
  `∃ Δ, f_w(σ) = (★) + Δ ∧ (★) ∈ V ∧ supp(Δ) ⪯ [σ]`. Δ is defined as the
  difference `f_w - (★)`; the support bound uses
  `twistedPolytabloid_support_bound` for the `f_w` half and
  `generalizedPolytabloidTab_coeff_dominance` + `tabloidDominates_trans`/`_congr`
  for the `(★)` half.

### Deviations from the issue's literal API

The issue body proposed `reindexer` and `tauQ` as new names; I used
`garnirColReindex` (existing) and `perQTau` (new) instead. The four
Q-regions are `perQ_low/eq/eqHi/high` (instead of `Q_low/eq/eq'/high`,
since unprefixed `Q_*` would clash with combinatorial naming).

The partition lemma is in **membership form**
(`q ∈ perQ_low ∨ q ∈ perQ_eq ∨ q ∈ perQ_eqHi ∨ q ∈ perQ_high`)
rather than the proposed `Finset.univ = Q_low ∪ Q_eq ∪ Q_eqHi ∪ Q_high`.
The reason: `Finset.univ : Finset ↥(ColumnSubgroup n la)` requires a
`Fintype ↥(ColumnSubgroup n la)` instance, which is not available without
introducing a `DecidablePred (· ∈ ColumnSubgroup n la)` synth path. The
membership form is logically equivalent and avoids the synth gymnastics.
R2.b can derive the Finset.univ form locally if needed via
`Classical.decPred` + Finset.disjUnion.

The decomposition lemma's `Δ` is given as `f_w - (★)` rather than
exposing the explicit `(★★) + (★★★)` aggregation from §3.1 of the
meditate. This is sufficient for R2.b's `Δ ∈ V` analysis (R2.b can
expand the difference using the existing definitions of
`twistedPolytabloid` and `twistedIHPart`).
