### Key design decision

The deliverable framed the moment-curve `c_k = P + Λ^k Q + Λ^{2k} R`
disentangling as needing the Vandermonde distinctness `t125TubeLam_distinct`
to invert the full 3-input block system. **That inversion is not needed for
this lemma.** Feeding the arm-1 leaf the Q-concentrated input `(0, x, 0)`
collapses the moment curve to `c_k = Λ^k x`, so block `1` of the center
readout is exactly `Λ x`. This produces the `(λ•id + J)`-invariant deposit
directly — the precise hypothesis `eigenvalue_jordan_invariant_compl_trivial_gen`
consumes — with only the same-offset / disjoint-offset block retractions. The
Vandermonde distinctness is still needed elsewhere in the sub-C assembly
(forcing all six center blocks onto a common site / the leaf-collapse
surjectivity), not in the eigenvalue deposit step. This mirrors `leaf4_sub`
inside `starTubeRepGen_isIndecomposable` (`FieldGenericTube.lean`), where the
single arm-4 leaf carries `x` in and deposits `Λ x`.

`t125_arm1_sub` is stated over explicit center/arm/site submodule carriers
(matching the established sub-B1 helper style `t125_prefix_sub` /
`t125_suffix_sub`), so it elaborates without unfolding `(t125Rep_kQ …).obj`.
Sub-C (#4613) supplies the four collapse hypotheses from the flag spine and
invokes `t125_arm1_sub` to discharge the eigenvalue-site pair.
