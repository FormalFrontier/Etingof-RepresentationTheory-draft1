## Key pattern

The exhaustiveness route is *not* the character/decomposition route used elsewhere in
Chapter 5. It is the book's own `ξ : Y → Y ⊗ R` embedding, specialized to a single
functional: for a simple `ρ`, `mc` is injective (its kernel is a subrepresentation, and
`evalGLAway (mc v₀) 1 = u v₀ ≠ 0` for a basis coordinate functional), so `Y` is realized as
a simple finite-dimensional `localRightRep`-subrepresentation of `R`, which the existing
Peter-Weyl realization core `exists_dominantWeight_equivariant_realization` already names.
That core was built for the Cauchy spanning argument; reusing it here avoided rebuilding the
highest-weight machinery.
