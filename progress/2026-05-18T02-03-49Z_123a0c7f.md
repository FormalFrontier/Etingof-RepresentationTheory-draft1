## Key patterns discovered

The cycle-pattern for orientation-generic `mapLinear` reduction:
```lean
rcases hOrient_edge a b h_adj with hQab | hQba
· obtain ⟨e⟩ := hQab
  ...
  have h := hW_inv e x hx
  simp only [d5tildeRep_kQ, d5tildeRepMap_kQ] at h
  exact h
```

The 2-step destructure (rcases the Or, then obtain the Nonempty) is
necessary because `obtain ⟨a⟩ | ⟨a⟩ := ...` does not recursively
destructure `Nonempty` in this context. Source: `FieldGenericCycle.lean`
(`cycleRep_kQ_isIndecomposable`, lines 210-235).

Also: per-edge invariance helpers must explicitly bind `x` with its
ambient type before the membership predicate to avoid
`Membership` instance-synthesis failures:
```lean
have hW_e (x : Fin (m + 1) → F) (hx : x ∈ W ⟨source, _⟩) :
    target_map x ∈ W ⟨target, _⟩ := by ...
```

(The `∀ x ∈ W ⟨source, _⟩, ...` binder syntax fails because Lean
can't determine `x`'s type before the membership predicate is
elaborated.)
