## Accomplished

Proved `Etingof.character_inv_eq_conj` (issue #5235) in
`Chapter5/FrobeniusSchurRealType.lean`, closing the last gap in the L2
Frobenius–Schur lemma `character_im_eq_zero_of_ambivalent`. For a finite group
`G` and a finite-dimensional complex representation `ρ`,
`Representation.character ρ g⁻¹ = conj (Representation.character ρ g)`.

Proof route (fully constructive, no new `sorry`):

- Pass to a matrix `A := [ρ g]` via `LinearMap.toMatrixAlgEquiv b`; then
  `[ρ g⁻¹] = A⁻¹` (`Matrix.inv_eq_left_inv`) and `A ^ orderOf g = 1`.
- Reduce to a standalone matrix lemma `matrix_trace_inv_eq_conj`:
  for `A ^ n = 1` (`n > 0`), `tr(A⁻¹) = conj(tr A)`.
- `tr A = ∑ roots(charpoly A)` (`Matrix.trace_eq_sum_roots_charpoly`); each root
  `μ` is an eigenvalue of `toLin' A`, and `(toLin' A)^n = id`, so `μ^n = 1`,
  giving `‖μ‖ = 1` and `conj μ = μ⁻¹` (`Complex.inv_eq_conj`).
- `tr(A⁻¹) = ∑ roots(charpoly A⁻¹).map inv`: via `Matrix.charpoly_inv` +
  `Matrix.reverse_charpoly`, `charpoly A⁻¹` is a nonzero scalar times
  `(charpoly A).reverse`, and a new helper `roots_reverse_eq_map_inv` proves
  `(reverse p).roots = p.roots.map (·⁻¹)` for a monic split `p` with no zero
  root (factor `p = ∏(X - λ)`, `reverse` is multiplicative over the domain
  `ℂ[X]`, and `reverse (X - C λ)` has the single root `λ⁻¹`).

Two reusable polynomial helpers landed: `reverse_multiset_prod`
(reverse multiplicative over a `Multiset` in a domain) and
`roots_reverse_X_sub_C`.
