## Accomplished

Closed the `sorry` in `FDRep.isIntegral_classSum_scalar`
(`EtingofRepresentationTheory/Chapter6/DimDvdCard.lean`), issue #6723 (A2 of
#6714). The central-character value `ω = |C|·χ_V(g₀)/d` on a conjugacy-class sum
is now proved to be an algebraic integer, sorry-free.

Proof route (cleaner than the class-sum-basis-of-center plan in the issue):
- Class sum `z = ∑_{x ∼ g₀} single x 1` in `ℤ[G]`. Since `G` is finite, `ℤ[G]`
  is `Module.Finite ℤ` (basis `Finsupp.basisSingleOne`), so `z` is integral over
  `ℤ` directly via `IsIntegral.of_finite` — no center machinery needed.
- `Φ = MonoidAlgebra.lift ℤ (End ℂ V) G V.ρ : ℤ[G] →ₐ[ℤ] End ℂ V`.
  `Φ z = ∑_{x ∼ g₀} ρ x` commutes with every `ρ g` (conjugation permutes the
  class; proved with `Finset.sum_nbij'` and `isConj_iff`).
- Package `Φ z` as an FDRep endomorphism `φ : V ⟶ V`
  (`{ hom := FGModuleCat.ofHom (Φ z), comm := ... }`), apply
  `CategoryTheory.endomorphism_simple_eq_smul_id ℂ φ` (Schur) to get `Φ z = c • id`.
- Trace: `c·d = tr(Φ z) = ∑_{x ∼ g₀} χ_V(x) = |C|·χ_V(g₀)` (via `FDRep.char_conj`),
  so `c = ω`.
- `Φ z` integral over `ℤ` (`IsIntegral.map Φ`), `Φ z = c•id = algebraMap ℂ ω`,
  descend to `ω` integral via `isIntegral_algebraMap_iff` (algebraMap injective
  on nonzero `V`).

`#print axioms FDRep.isIntegral_classSum_scalar` = `[propext, Classical.choice,
Quot.sound]`. `lake build EtingofRepresentationTheory.Chapter6.DimDvdCard`
succeeds. Updated the file/theorem docstrings to reflect the completed proof.

Key plumbing note (recorded for successors): to extract the underlying linear
map of a `c • 𝟙 V = φ` equation in `FDRep`, use three `.hom`s
(`ψ.hom.hom.hom : V.V →ₗ V.V`); `(FGModuleCat.ofHom f).hom.hom = f` is `rfl`,
`(c • g).hom.hom = c • g.hom.hom` for FGModuleCat `g` is `rfl`, and after
`rw [Action.smul_hom, Action.id_hom]` the residual `(c • 𝟙 V.V).hom.hom = c • id`
closes by `rfl` (uses `FGModuleCat.hom_hom_id`).
