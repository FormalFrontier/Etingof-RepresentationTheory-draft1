## Key patterns discovered

- **Universe**: `PathAlgebra k Q : Type (u+1)` (not `Type u`) because `Quiver.Path` lands in
  `Type (max u v)` with `Quiver.{u+1}`. So the induced module lives at carrier universe
  `u+1`; the whole functor/adjunction is stated at `ModuleCat.{u+1}` on both sides. The
  issue's aspirational `ModuleCat.{u} A` is universe-impossible.
- Maps **into** a `restrictScalars` object need `ModuleCat.ofHom (X := …) (Y := …)` with
  explicit type params (as Mathlib's own `RestrictScalars.map'` does), else the bundled
  `S`-module instance is lost and `Module (Q → k) ↑N` fails to synthesize.
- Factor the `liftAddHom` bilinear map and its balancing proof into named defs
  (`symmBilin`, `symmBilin_balanced`) — inlining them caused `isDefEq`/`whnf` heartbeat
  timeouts from the two-module-structure coercion churn.
