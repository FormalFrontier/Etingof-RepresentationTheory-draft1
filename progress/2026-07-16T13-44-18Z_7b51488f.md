Completed issue #6833 (feat Ch4 #Problem4.12.8-a-i): the **rotation-axis milestone lemma**
`exists_fixed_vector` — every element `g` of `SO(3)` fixes a nonzero vector (`1` is an
eigenvalue), the geometric input to the pole-counting classification of finite `SO(3)` subgroups.

Added and proved sorry-free in `EtingofRepresentationTheory/Chapter4/Problem4_12_8.lean`, statement
exactly as specified in the issue. Route: the elementary `det(g - 1) = 0` computation.

- From `mem_specialOrthogonalGroup_iff`: `g` is orthogonal (`gᵀ g = 1`) with `det g = 1`.
- `det(g-1) = det gᵀ · det(g-1) = det(gᵀ(g-1)) = det(1 - gᵀ) = det((1-g)ᵀ) = det(1-g)
  = (-1)³ det(g-1) = -det(g-1)`, so `det(g-1) = 0` (via `det_mul`, `det_transpose`, `det_neg`).
- `Matrix.exists_mulVec_eq_zero_iff` then yields a nonzero `v` with `(g-1) *ᵥ v = 0`, i.e.
  `g *ᵥ v = v`.
