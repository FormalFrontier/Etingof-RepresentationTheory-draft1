written before that file landed and assumed it was missing from both Mathlib and the repo. So the
work collapsed from "build Krull–Schmidt / isotypic-multiplicity infrastructure" to "bridge the
existing FDRep-level theorem to `Representation.Equiv` and assemble the specific isomorphism".
