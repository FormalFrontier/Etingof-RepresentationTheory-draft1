## Accomplished

Closed the fidelity gap of issue #7408: `Etingof.Theorem_2_1_2` (Gabriel's theorem) was
proved only under three standing typeclass/hypothesis restrictions — every arrow type a
`Subsingleton`, no loops, and no edge oriented both ways (the last two packaged as
`IsOrientationOf ‹Quiver (Fin n)› (quiverUndirectedAdj n)`). The book's Definition 2.8.1
allows loops and parallel arrows, so those quivers were silently outside the statement
instead of being proved to have infinite representation type.

New file `EtingofRepresentationTheory/Chapter2/Theorem2_1_2_General.lean` (~500 lines,
sorry-free; `#print axioms` on every public result gives only
`propext, Classical.choice, Quot.sound`):

* `suppRep S c` — one construction covering all the counterexample families: a
  one-dimensional space `Fin (if S j then 1 else 0) → k` at each vertex of the support `S`,
  the zero space elsewhere, and each arrow `e : a ⟶ b` acting by the scalar `c a b e`
  composed with a `truncMap`. The `truncMap` trick keeps `mapLinear` a single uniform
  expression, so no dependent case split on types is ever needed.
* `suppRep_isIndecomposable_single` / `suppRep_isIndecomposable_pair` — indecomposability
  for one- and two-vertex support (the pair case needs one arrow acting invertibly).
* `suppScal` / `suppScal_relation` — the scalar an isomorphism induces at a supported
  vertex, and the relation `g_b * c e = c' e * g_a` it satisfies on every arrow. This one
  relation drives all three separation arguments.
* `not_hasFiniteRepresentationType_of_family` — pigeonhole: a `k`-indexed family of
  pairwise non-isomorphic f.d. indecomposables contradicts finite type, since an
  algebraically closed field is infinite.
* Negative branches: `not_hasFiniteRepresentationType_of_loop` (Jordan/loop family
  `(k, lam)`), `not_hasFiniteRepresentationType_of_two_arrows` and its two readable
  corollaries `_of_parallel` and `_of_opposite` (Kronecker family `(k, k, 1, lam)`).
* `isOrientationOf_quiverUndirectedAdj_iff` — for the quiver's own undirected adjacency
  matrix, `IsOrientationOf` says exactly "no loops and no two-way edge". This is what turns
  the old hypothesis into a classification condition.
* `Theorem_2_1_2_general` — for **any** connected quiver on `Fin n`, no typeclass
  restrictions: finite representation type ↔ no loops ∧ no two-way edge ∧ all arrow types
  subsingleton ∧ underlying graph Dynkin. `Theorem_2_1_2_general_orientation` states the
  same with the first two conditions repackaged as `IsOrientationOf`.

The original `Theorem_2_1_2` is untouched and is used verbatim for the remaining
(loopless, simple) case, so it survives as the convenient special case.
