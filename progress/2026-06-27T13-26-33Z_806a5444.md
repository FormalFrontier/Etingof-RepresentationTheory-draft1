## Accomplished

Landed the **Schur-module half** of issue #5543 (sub-issue of #5535): a new leaf
file `Chapter5/SchurModuleContragredientHalf.lean` proving, sorry-free, that the
`det^{t+sh}`-twisted Schur-module contragredient is `GL_n`-equivariantly isomorphic
to a bare Schur module.

Main result `schurModule_half_detTwist_contragredient`: with `w₀ := lam.w0Twist`,
`μ := w₀.toNatWeight`, `sh := w₀.shift`, for every `t : ℕ`,

```
Nonempty { e : AlgIrrepGLDual n lam k ≃ₗ[k] SchurModuleSubmodule k n (fun i => μ i + t) //
  ∀ g v, e (charTwistRep (detChar k n ^ (t + sh)) (algIrrepGLRepDualρ n lam k) g v)
    = schurModuleRep k n (fun i => μ i + t) g (e v) }
```

Supporting pieces in the same file:
- `Intertwines` (reducible def) plus combinators `.trans`, `.symm`, `.charTwist`,
  and `intertwines_of_fdRepIso` (extracting an equivariant `≃ₗ` from an FDRep iso
  via `FDRep.isoToLinearEquiv` + `FDRep.Iso.conj_ρ`, mirroring the
  `Theorem5_15_1.lean:459` pattern).
- `charTwistRep_one` (`charTwistRep 1 ρ = ρ`).
- `charTwist_detPow_iso_schurShift`: induction on `t` iterating Prop 5.22.2
  (`schurModule_shift_iso_detTwist`); base case is the trivial twist, each step
  twists the IH by `det` and composes with the determinant-shift iso.

The main theorem collapses the stacked `det^{t+sh} ∘ det^{-(sh:ℤ)}` twist on
`algIrrepGLRepDualρ` to a single `det^t`-twist using `charTwistRep_charTwistRep`
and the character identity `det^{t+sh} · det^{-(sh:ℤ)} = det^t` (npow/zpow
reconciliation via `zpow_natCast`/`zpow_add`).
