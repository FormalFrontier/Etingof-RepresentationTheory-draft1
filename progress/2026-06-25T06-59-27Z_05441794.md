`Etingof.frobeniusSchurIndicator_eq_pm_one_of_self_dual_simple`:
for a simple complex `Representation ℂ G V` with self-dual character
(`χ(g⁻¹) = χ(g)`), `FS(ρ) = |G|⁻¹ ∑_g χ(g²) ∈ {±1}`.

Proof (the trace identity, on `V ⊗ V` rather than bilinear forms):

- `matrix_trace_swap_kronecker`: `tr(Pσ · (A ⊗ₖ A)) = tr(A·A)`, where `Pσ` is the
  swap permutation matrix — a pure `Matrix.trace`/`Fintype.sum_prod_type` computation.
- `trace_comm_comp_map`: `trace (comm ∘ map A A) = trace (A ∘ A)` on `V ⊗ V`, via
  `TensorProduct.toMatrix_comm` + `TensorProduct.toMatrix_map`. With `A = ρ g` this is
  `trace(comm ∘ T g) = χ(g²)` for `T = tprod ρ ρ`.
- Projector form: `FS(ρ) = trace(comm ∘ averageMap T)` (`averageMap = ⅟|G| • ∑ T g`,
  `asAlgebraHom_of`), since `comp` and `trace` are linear.
- `comm` is `G`-equivariant and an involution, so it preserves the invariants
  `I = T.invariants` and `averageMap` is the identity there; thus
  `trace(comm ∘ averageMap) = trace(comm|_I)` via
  `LinearMap.trace_restrict_eq_of_forall_mem`.
- `dim I = |G|⁻¹ ∑_g χ(g)² = |G|⁻¹ ∑_g χ(g)χ(g⁻¹) = 1` (self-duality +
  `card_inv_mul_sum_char_eq_finrank` + `char_orthonormal`).
- `trace_involution_eq_pm_one`: a linear involution on a 1-dim space has trace `±1`
  (1×1 matrix, `mul_self_eq_one_iff`).
