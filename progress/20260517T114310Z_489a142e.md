1. **`compl_le_forces_eq`** (Section 4) — given two complementary pairs
   `(W₁_a, W₂_a)` and `(W₁_b, W₂_b)` in a finite-dimensional space with
   `W₁_a ≤ W₁_b` and `W₂_a ≤ W₂_b`, both inclusions are equalities. Proof
   via `Submodule.finrank_add_eq_of_isCompl` + `Submodule.finrank_mono` +
   `omega` + `Submodule.eq_of_le_of_finrank_eq`.

   Submodule args are **explicit** (not implicit as initially sketched in
   the issue body). When the carrier `V` arises as
   `(cycleRepGen_kQ …).obj a`, implicit-argument inference cannot align
   the four submodules across the two `IsCompl` hypotheses because the
   `obj` projection does not always reduce syntactically; explicit args
   sidestep this. Documented in the docstring.

2. **`cycleRepGen_kQ`** (Section 5, noncomputable def) — the
   orientation-generic cycle representation. `obj v := Fin (m+1) → F` at
   every vertex; `mapLinear e := nilpotentShiftLinGen F m` if the
   underlying pair `{a.val, b.val} = {0, k-1}` (closing edge), else
   `LinearMap.id`. Detection from the unordered pair, not the arrow
   direction, makes the construction Q-agnostic.

3. **`cycleRepGen_kQ_isIndecomposable`** — indecomposability for any
   orientation `Q` of `cycleAdj k hk`. Three-step proof:
   - **Adjacent-vertex equality**: for each `i` with `i + 1 < k`, the
     orientation gives an arrow `a ⟶ b` or `b ⟶ a` (where `a, b` have
     values `i, i+1`). The arrow carries `LinearMap.id`, so we get one of
     `W₁ a ≤ W₁ b` or `W₁ b ≤ W₁ a` (and the same for W₂). Either way,
     `compl_le_forces_eq` collapses to equality.
   - **Constancy across all vertices**: induction over the natural-number
     index, chaining the adjacent-vertex equalities.
   - **Nilpotent invariance at the closing edge**: the orientation gives
     an arrow between `0` and `k-1` in some direction; its `mapLinear` is
     `nilpotentShiftLinGen F m`. Using constancy, the shift preserves the
     vertex-0 submodule. Apply `nilpotent_invariant_compl_trivial_gen` to
     get `W₁ = ⊥` or `W₂ = ⊥` at vertex 0; constancy propagates.

4. **`cycleRepGen_kQ_dimVec`** — trivial dimension-vector witness.

5. **`cycle_not_finite_type_per_kQ`** — the deliverable. Same
   construction as `cycle_not_finite_type_gen` (line 298) but skipping the
   `letI := cycleQuiver k hk` step: the supplied `Q` is used directly.
   Infinitely-many indecomposables indexed by `m : ℕ`.
