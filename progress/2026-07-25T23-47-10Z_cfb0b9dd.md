## Decisions made / key patterns

* **Vanishing branch.** `c_λ = b_λ · a_λ`, so `range c_λ ≤ range b_λ` and it suffices to
  kill the column antisymmetrizer. Fix a standard tensor basis vector `b_f`
  (`tensorStdBasis`, public in `Theorem5_22_1.lean`). The first column of the diagram has
  one cell per row, obtained from the public `exists_pos_of_cell` at `(r, 0)` and separated
  by `rowOfPos_colOfPos_injective`; pigeonhole over `Fin N` with `N < p` yields `i ≠ j` in
  the first column with `f i = f j`. Then `τ = swap i j ∈ ColumnSubgroup`
  (`swap_mem_ColumnSubgroup`), right translation by `τ` is an involution of the column
  subgroup, `sign` flips, and `f ∘ τ⁻¹ = f`, so `S = -S` and `CharZero` finishes.
  This avoids decomposing the column subgroup as a product over columns.
* **Nonvanishing branch.** No new representation theory: `partWeight N la` (sorted parts
  padded with zeros) is antitone, sums to `n`, and `weightToPartition` inverts it, so the
  module is literally `SchurModule k N (partWeight N la)` and `Theorem5_22_1_dim` applies.
  `weylDimension_pos` (every factor `(λ_i − λ_j + j − i)/(j − i) > 0` for antitone λ) then
  rules out `⊥`.
* **Dependent-type transport.** `Nat.Partition n` and `TensorPower … n` both depend on `n`,
  so relating `la` to `weightToPartition N (partWeight N la)` needs `n := ∑ i, lam i`
  substituted. `subst` refuses while `lam` is still spelled `partWeight N la` (the RHS `n`
  occurs in the LHS). The working idiom is to `obtain` an *opaque* `lam` from an existential
  bundling `Antitone lam ∧ ∑ i, lam i = n ∧ (weightToPartition N lam).parts = la.parts`,
  then `subst` the sum equation and `Nat.Partition.ext`/`subst` the partition. Every
  statement stays `▸`-free.
* Instance detail: `YoungSymmetrizerK`'s sums are indexed by `Fintype ↥(RowSubgroup …)` /
  `↥(ColumnSubgroup …)` coming from `haveI : DecidablePred (· ∈ …) := Classical.decPred _`
  inside the `def`. The split into `colAntiEnd`/`rowSymEnd` has to repeat that exact
  `haveI` or `map_mul` will not line up.
