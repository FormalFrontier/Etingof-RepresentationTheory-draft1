- `sumZeroLattice n` — the sum-zero sublattice `{x : Fin (n+1) → ℤ | ∑ i, x i = 0}` of `ℤ^{n+1}`.
- `simpleRoot n i = e_i - e_{i+1}` and `basis n : Basis (Fin n) ℤ (sumZeroLattice n)`, with
  `coe_basis : (basis n i : _) = simpleRoot n i` (the consecutive-difference basis).
- `dotProduct_simpleRoot` (Gram matrix = `A_n` Cartan form) and `dotProduct_toLat`
  (the standard inner product restricted to `L`, in these coordinates, is `xᵀ(2·1 - adj)y`).
- `mem_latticeRoots_iff` — all roots of `L` are exactly `±(e_i - e_j)`, `i ≠ j`.
- `isRoot_iff_toLat_mem` — abstract `Etingof.IsRoot` (Cartan coords) ↔ membership in the
  explicit lattice roots, tying the two encodings together.
- `ncard_positiveLatticeRoots : Set.ncard (positiveLatticeRoots n) = n(n+1)/2` — the
  positive-root count re-derived in the explicit model.

Key coordinate maps: `toLat` (`c ↦ ∑ c_i α_i`) and `fromLat` (prefix sums), with the two
round-trips `fromLat_toLat` / `toLat_fromLat` (the latter using the sum-zero condition)
packaged as `latticeEquiv : (Fin n → ℤ) ≃ₗ[ℤ] sumZeroLattice n`.
