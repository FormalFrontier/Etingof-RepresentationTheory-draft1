Supporting results added along the way (all with docstrings):

* `Ylin_zero_pow_max` — if `m` is the largest index at which `f` is nonzero, then
  `(Ylin 0 ^ m) f = (m! · f m) • e₀`. The two off-diagonal cases are handled separately: without
  wraparound `f (j + m) = 0` by maximality of `m`, and with wraparound the vanishing weight
  `wY (-1) = 0` appears in the accumulated product.
* `Xlin_pow_single` — `(Xlin α ^ i) e₀ = eᵢ` for `i < p`; the twisting scalar `α` is only picked
  up after `p` steps, so this holds for `α = 0` too.
* `famRep_y_sub` — `famRep (y - c·1) = Ylin 0`, so the book's `d/dt` is realized by an actual
  element of `WeylAlgebra k`.
* `famModule_smulCommClass` — the `WeylAlgebra k`-action commutes with the ambient `k`-action
  (needed to move `k`-scalars past `x^i`).
* private helpers `exists_top_index` and `smul_single_one`.

The statement is proved through `isSimpleModule_iff_toSpanSingleton_surjective`, i.e. by
assembling an explicit algebra element
`∑ⱼ (s⁻¹ zⱼ) • (xʲ · (y - c)ᵐ)` carrying any nonzero `f` to any target `z`, where
`s = m! · f m`. This form is convenient because it avoids reasoning about submodule lattices.

Verified with a use-site check that `famModule_isSimpleModule` installs cleanly as an instance
via `haveI` under `letI := famModule k p α c`, including at `α = c = 0`.

## Notes for successors

Two Lean gotchas cost time in this file and are worth remembering:

* `Nat.factorial` postfix notation does not parse inside a type ascription
  (`((m : ℕ)! : k)` is a syntax error). Write `Nat.factorial (m : ℕ)` instead.
* `Pi.single j (1 : k)` needs its function type pinned (`(Pi.single j (1 : k) : Fin p → k)`)
  whenever the surrounding expression does not already determine it — otherwise the dependent
  `f : I → Type` argument stays a metavariable and elaboration fails with an "application type
  mismatch" on the `1`.
* `rw [smul_assoc]` / `rw [mul_smul]` happily match the *field* multiplication `s⁻¹ * z j`
  before the intended module action. Passing the equations as explicit `have`s with all
  arguments spelled out is much more robust than bare rewrites.
