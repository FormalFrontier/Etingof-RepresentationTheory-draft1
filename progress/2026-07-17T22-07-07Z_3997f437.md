## Accomplished

Landed `affine_two_branch_pinch` (sorry-free) in
`EtingofRepresentationTheory/Chapter6/Problem6_1_3_continued_tildeE.lean` (partial of #6926): the
arithmetic core of the two-branch `D̃ₙ` fork discriminator, the analogue of `reciprocal_of_arm_data`.

Given the positive null vector's values `Ww, Wv` at the two branch vertices `w, v`, the four outer-arm
factorisations `Ww = (L+1)a₁ = (M+1)a₂`, `Wv = (P+1)b₁ = (Q+1)b₂`, hub-harmonicity at each branch
vertex (`2Ww = L·a₁ + M·a₂ + sw`, `2Wv = P·b₁ + Q·b₂ + sv`), and the spine identity
`sw + sv = Ww + Wv`, a single `linear_combination` collapses everything to
`(L-1)a₁ + (M-1)a₂ + (P-1)b₁ + (Q-1)b₂ = 0` — a vanishing sum of four non-negative terms — forcing
`L = M = P = Q = 1`. This is the affine degeneracy that rules out the E-types (arms `(1,2,·)`, one
leaf-neighbour) and pins the shape to `D̃ₙ` (two-leaf fork at each end).

Key mathematical observation (new): the spine identity `sw + sv = Ww + Wv` holds because the null
vector is affine along the `v–w` spine, so the end-increments agree (`sw − Ww = Wv − sv`); and the two
hub equations simplify with `L·a₁ = Ww − a₁` etc. so `sw = a₁ + a₂` (tip sum). This is what makes the
pinch a clean sum-of-non-negatives.
