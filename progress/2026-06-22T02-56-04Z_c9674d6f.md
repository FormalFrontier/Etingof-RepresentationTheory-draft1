## The precise gap (why this is not a one-session fill)

Target (`:2326`): for col-std `σ` with `rowInvCount' σ > 0`, any `w`, any
`M ∈ V` (SYT-polytabloid span), `X := f_w(σ) − M` with `supp(X) ≼ [σ]`, and a
**dominance-maximal** support tabloid `t₁`, produce a column-standard `β'` with
`[β'] = t₁` that is IH-available (`srRank β' < srRank σ`, or equal `srRank`
with strictly fewer row inversions).

**Sorry-free reduction (validated, but only one-directional):**
let `α := Quotient.out t₁`. Then
`exists_column_standard_mul α` (`:269`) gives `q₀ ∈ ColumnSubgroup` with
`β' := q₀·α` column-standard, and `colStd_column_perm_dominance` (`:1143`,
`q := q₀`, using `α = q₀⁻¹·β'`) gives `tabloidDominates β' α`, i.e.
`[β'] ⪰ t₁`. This is sorry-free.

**The irreducible gap.** The reduction yields only `[β'] ⪰ t₁`, never equality.
Closing it needs **(C)** `[β'] = t₁` (the column sort does not strictly raise)
and **(I)** the rank disjunction. The natural way to get (C) from `hmax`
(dominance-maximality) is to show `[β'] ∈ supp(X)` and then apply `hmax`. But:

> `X([β']) ≠ 0` is **not derivable** from the present API. `hM : M ∈ V` gives no
> pointwise coefficient formula for `M`; the leading-term lemmas
> (`generalizedPolytabloidTab_coeff_dominance` `:1265`,
> `..._leading_tabloid` `:1285`) only bound each polytabloid's support
> *downward* and say nothing about an *upward*-sorted tabloid remaining in the
> support, nor do they preclude cancellation at `[β']`.
> `tabloidSupport_straightening` (`:1302`) would extract leading terms, but it
> **requires `X ∈ V`**, which is exactly the goal — circular.

So `hmax` is usable only *after* a support fact is proved; it cannot *create*
that fact. The statement `[β'] ∈ supp(X)` for the dominance-maximal residual
tabloid **is itself a form of the James/Fulton column-straightening invariant**,
not a consequence of the existing dominance/leading-term lemmas.

Independent confirmation (Codex, this session, verbatim verdict):

> API**. If true for this residual, it is already a form of the James/Fulton
