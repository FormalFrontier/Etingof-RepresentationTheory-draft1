## Accomplished

One-shot dispatch on issue #5679 (Stage 3.7 COVERAGE arm): formalize the
"number of conjugacy classes per type" claim from `Chapter5/Discussion_5.25.1`.

Re-confirmed the claim was genuinely missing before formalizing: the existing
`GL2.card_is*` theorems in `GL2ConjugacyClasses.lean` count *elements* per type,
and `ConjClasses` was only ever instantiated for `Sₙ` (`Theorem5_12_2_Distinct`),
never for GL₂.

Added `EtingofRepresentationTheory/Chapter5/GL2ConjugacyClassCount.lean`
(imported into `Chapter5.lean`), the first instantiation of `ConjClasses` for
GL₂. It defines the four per-type class counts (and reads the total off
`Nat.card (ConjClasses (GL2' p n))`) as `Set.ncard` of the `ConjClasses.mk`-image
of each type's element set — genuine constructed definitions, no decidability
instances needed.

Proved fully:
- `GL2.isScalar_conj_iff`, `isParabolic_conj_iff`, `isSplitSemisimple_conj_iff`,
  `isElliptic_conj_iff` — the four type predicates are conjugation-invariant
  (from `Etingof.disc_conj_eq` plus scalar centrality). This is what makes "the
  type of a conjugacy class" well defined.
- `GL2.val_mul_comm_of_isScalar` / `val_conj_of_isScalar` / `eq_of_isConj_of_isScalar`
  — scalar matrices are central, so each scalar class is a singleton.
- `GL2.numScalarClasses_eq : numScalarClasses = q − 1` — full proof: `ConjClasses.mk`
  is injective on the scalar set, so the count equals the scalar-element count
  (`GL2.card_isScalar`).

Stated with `sorry` proofs (top-down; the book's class-size argument is recorded
in each docstring):
- `numParabolicClasses_eq` (= q − 1)
- `numSplitSemisimpleClasses_eq` (= (q−1)(q−2)/2)
- `numEllipticClasses_eq` (= q(q−1)/2)
- `card_conjClasses_eq` (total = q² − 1)

`lake build EtingofRepresentationTheory.Chapter5.GL2ConjugacyClassCount` succeeds
(exit 0); the only diagnostics on the new file are the 4 intended `sorry`
warnings and benign "instance used only in proof" lints.

## Current frontier

The four deferred counts. Each reduces, per the book, to dividing a type's
element count by the constant size of a class of that type:
- parabolic class size q²−1, hyperbolic q²+q = q(q+1), elliptic q²−q = q(q−1).
