## Accomplished

Closed the fidelity gap flagged in issue #5634 (Wave-2 sweep) for
`Chapter4/Example4.3_S4`. Previously the file only had two vacuous `decide`
theorems (5 conjugacy classes; `1²+1²+2²+3²+3²=24`) and constructed no
representations. It now builds the **five genuine irreducible representations
of `S₄`** as `FDRep ℂ S₄` and proves each simple:

- `trivRep`, `signRep` (1-dim) via the generic `charRep`/`charRep_simple`.
- `stdRep` — the standard 3-dim `ℂ³₋`, the sum-zero subrep of the permutation
  rep on `Fin 4 → ℂ` (book: "functions on four elements with zero sum").
- `rotRep` — the 3-dim `ℂ³₊ = ℂ₋ ⊗ ℂ³₋`, built via a reusable `twistRep`
  (twist a rep by a 1-dim character; character = χ · χ_ρ), avoiding the
  monoidal tensor product.
- `twoDimRep` — the 2-dim `ℂ²`, the sum-zero subrep of the permutation rep of
  `S₄` on the three pair-partitions of `{0,1,2,3}` (the pullback of the `S₃`
  standard rep along `S₄ ↠ S₄/V₄ ≅ S₃`). The partition action `actHom : S₄ →*
  Perm (Fin 3)` is defined via `pairIdx`/`actFun` and its hom law proved by
  `decide` (~16s, `maxRecDepth 10000`).

All simplicity proofs use `FDRep.simple_iff_char_is_norm_one` with the
character computed from a direct-sum (sum-zero ⊕ constant-line) trace
argument; each norm-one sum is `24 = |S₄|` by `decide`. Also recorded:
dimensions `1,1,2,3,3`, the sum-of-squares theorem `irreps_dim_sum_of_squares`,
and `ℂ³₊ ≇ ℂ³₋` via differing character on a transposition. No sorries.
