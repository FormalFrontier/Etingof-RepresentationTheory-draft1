The proof consumes `affine_one_branch_three_arms` (landed on `main` via #6928/PR #6932)
and is pure finite index bookkeeping:
- Sort the three arm lengths with `Tuple.sort L` (via `Tuple.monotone_sort`), giving
  `1 ≤ p ≤ q ≤ r` and `n = 1 + p + q + r` (`Equiv.sum_comp` + `Fin.sum_univ_three`).
- Build the layout function `b : Fin n → Fin n` in the `armAdjIdx` convention:
  `p`-arm **reversed** on `[0,p)`, hub `v` at index `p`, `q`-arm forward on `(p,p+q]`,
  `r`-arm forward on `(p+q, p+q+r]`. Four region-evaluation lemmas (`hbP/hbH/hbQ/hbR`)
  unfold the `dite`.
- Injectivity of `b` by a 16-case region split: same-arm cases use `hgdist`'s position
  equality + `omega`; cross-arm cases contradict via the arm-index distinctness
  (`π i ≠ π j`, from `π.injective`); arm-vs-hub cases contradict via `hgv`.
- The `armAdjIdx` adjacency iff by the same 16-case split: same-arm edges via `hgedge`,
  hub edges via `hghub` (+ `hsymm'` for the reversed orientation), cross-arm and
  hub-diagonal non-edges ruled out arithmetically (`omega` after `simp only [armAdjIdx]`).
- Bijective via `Fintype.bijective_iff_injective_and_card`; `σ := Equiv.ofBijective b`;
  the hub sits at index `p` so `(σ.symm v).val = p`.
