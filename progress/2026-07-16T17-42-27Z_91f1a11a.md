Worker session (`/work` → `/feature`) on issue #6851
(Ch9 #Problem9.5.3-iii, `Chapter9/Problem9_5_3_S3Char2.lean`). Proved **two of the
three** target simple-module theorems, both sorry-free and axiom-clean
(`propext, Classical.choice, Quot.sound` only):

- `trivMod_isSimpleModule` — the trivial (`= sign` in char 2) 1-dimensional module
  is simple. One-liner via `is_simple_module_of_finrank_eq_one` (finrank over `k`
  is 1, transported through `asModuleEquiv`).
- `stdMod_isSimpleModule` — the 2-dimensional standard representation stays
  irreducible in char 2. Reduced to `IsSimpleOrder (stdRepr k).invtSubmodule` via
  `Representation.mapSubmodule.isSimpleOrder_iff`, then the eigenline argument: for
  a nonzero invariant `w`, either a transposition moves it off its line (two
  independent sum-zero vectors span the 2-dim carrier, so the submodule is `⊤`), or
  `w` is a common eigenvector — its transposition eigenvalues satisfy `μ² = 1`, hence
  `μ = 1` in char 2, so `w` is a nonzero constant sum-zero vector, impossible because
  `3 = 1 ≠ 0`.

Added two private helpers: `stdRepr_val` (underlying vector of the action) and
`finrank_stdSub` (`finrank = 2` via rank–nullity of `sumLM`).
