Closed #4616 (Ch5 #4609 sub-A): the Young-diagram bookkeeping bridge for the
Frame–Robinson–Thrall hook/beta cancellation. Added five sorry-free lemmas to
`EtingofRepresentationTheory/Chapter5/CharValueHookFormula.lean`, expressing the
hook lengths of `(weightToPartition N lam.parts).toYoungDiagram` directly in
terms of `lam.parts : Fin N → ℕ`:

1. `Nat.Partition.toYoungDiagram_rowLen_eq_getD` (general): `rowLen i = sortedParts.getD i 0`,
   via `mem_iff_lt_rowLen` + `mem_ofRowLens`, antisymmetry by `omega`.
2. `weightToPartition_rowLen`: `Y.rowLen i = lam.parts i` for `i : Fin N`.
3. `weightToPartition_colLen`: `Y.colLen c = #{i : Fin N | c < lam.parts i}`,
   via an `image Fin.val = range (colLen c)` identity.
4. `hookLength_eq_arm_add_leg`: `Y.hookLength i c = lam.parts i - c + #(leg)`,
   splitting `colLen c` into rows `≤ i` (count `i+1`, antitone fills the column)
   and rows `> i`, then `omega`.
5. `hookLengthProduct_eq_prod_rows`: `Y.hookLengthProduct = ∏ i, ∏ c ∈ range (lam.parts i), Y.hookLength i c`,
   via `Finset.prod_sigma'` + `Finset.prod_bij'` between cells and the sigma type.
