## Next step (recommended decomposition for the planner)

The issue forbids the still-`sorry` induced-character formula `Theorem5_9_1`, so the
proofs must go via the **Frobenius-reciprocity multiplicity route**. That route needs three
reusable pieces, each a good standalone sub-issue:

1. **Biproduct character additivity** `character_biprod : (A ⊞ B).character = A.character + B.character`
   for `FDRep ℂ G` (additive analogue of `FDRep.char_tensor`). Needed only if finishing via
   `charEq_iso`; not needed for the `iso_of_forall_finrank_hom_eq` route, which already has
   `Etingof.finrank_hom_biprod`.
2. **`S₃` irrep completeness** `∀ S simple, Nonempty (S ≅ trivRep) ∨ … ∨ Nonempty (S ≅ stdRep)`.
   Provable from `exists_simples_sum_finrank_sq_eq_card ℂ S3` (in
   `Infrastructure/IrreducibleEnumeration.lean`): the three are simple, pairwise non-iso
   (distinct characters/dims), and `1²+1²+2² = 6 = |S₃|`, so no fourth simple can exist.
3. **The Frobenius LHS hom-dimension** `finrank ℂ (T ⟶ FDRep.of (Definition5_8_1 H ρ))`
   for `T ∈ {trivRep, signRep, stdRep}`, via `Etingof.Theorem5_10_1`
   (`Rep.indResHomEquiv`) + character-symmetry of `finrank`, reduced to a scalar product
   over the small subgroup `H` using `FDRep.scalar_product_char_eq_finrank_equivariant` and
   the restriction characters. This step carries the FDRep↔Rep bridge for `ind`
   (`FDRep.of (Representation.ind …)` vs `Rep.ind …`) — the riskiest plumbing.

Then each theorem: `iso_of_forall_finrank_hom_eq (LHS) (RHS) rfl (fun S hS => …)`, casing on
completeness (2) and matching multiplicities from (3) against the RHS Schur multiplicities
(`FDRep.finrank_hom_simple_simple`).
