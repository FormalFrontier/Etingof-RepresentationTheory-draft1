New supporting lemma in the same file:

- `FDRep.character_isIntegral (V : FDRep ℂ G) (g) : IsIntegral ℤ (V.character g)` — a
  character value of a finite-group representation is an algebraic integer. Proof:
  `V.character g = trace (V.ρ g)`, which over `ℂ` (alg. closed) equals the sum of the
  roots of the charpoly (`Module.End.trace_eq_sum_roots_charpoly_of_splits`); each root
  is an eigenvalue (`hasEigenvalue_iff_isRoot_charpoly`), and since `(V.ρ g)^|G| = 1`
  (`pow_card_eq_one`), `HasEigenvalue.pow` forces every root to satisfy `r^|G| = 1`,
  hence to be integral over `ℤ` (root of `X^|G| - 1`). The sum lands in
  `integralClosure ℤ ℂ`.

## Key decisions / proof structure

Followed Etingof's book proof faithfully (summing over the whole group):

1. `∑_{g∈G} χ(g)χ(g⁻¹) = |G|` from `FDRep.char_orthonormal V V` (irreducible ⇒ the
   Schur factor is `1`).
2. `dim V > 0`: derived, not assumed — if `dim V = 0` then `↥V` is subsingleton, all
   characters vanish, and the sum would be `0 ≠ |G|`.
3. The integral combination `T = ∑_{C : ConjClasses G} λ_C · χ(g_C⁻¹)` with
   `λ_C = |C|·χ(g_C)/dim V`. Each `λ_C` is integral by **Proposition 5.3.2** and each
   `χ(g_C⁻¹)` by the new `character_isIntegral`, so `T` is an algebraic integer.
4. `dim V · T = |G|` by regrouping `∑_{g∈G}` over conjugacy classes
   (`Finset.sum_fiberwise_of_maps_to` along `ConjClasses.mk`, with `χ` constant on
   classes via `char_conj`) and step 1.
5. `T = |G|/dim V` is rational and an algebraic integer, hence an integer by
   **Proposition 5.2.5**, giving `dim V ∣ |G|`.

Dropped the stub's unused `[DecidableEq G]` (proof uses `classical`). The proof relies

`hasEigenvalue_iff_isRoot_charpoly`), which the lean-training-data Mathlib lacks — check
