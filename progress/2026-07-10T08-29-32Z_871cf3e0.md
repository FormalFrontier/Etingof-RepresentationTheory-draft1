## Key patterns / decisions

- **Universe handling for external finite groups.** `hP` quantifies `Q₁ Q₂ : Type u` but
  `ZMod n : Type 0`; transported via `AddEquiv.ulift : ULift.{u} (ZMod n) ≃+ ZMod n`
  (import `Mathlib.Algebra.Group.ULift`; `Finite (ULift _)` is an instance). The polynomial
  case avoids this because `k : Type u` makes `k[x]/(p^N) : Type u` directly.
- **Nonzero character from a killed quotient.** `QuotientAddGroup.zmodModule` gives the
  `ZMod q`-module structure on `P/qP`; a nonzero coordinate functional comes from
  `Module.Basis.ofVectorSpace` + `Module.Basis.forall_coord_eq_zero_iff` (contrapositive).
  This sidesteps `Module.Projective.exists_dual_ne_zero`, whose instance resolution got
  stuck. Note: bare `LinearMap` coercion `⇑(b.coord i) x` failed to elaborate in this file;
  routing through `(b.coord i).toAddMonoidHom` and relying on defeq worked.
- **Import gotchas:** `Field (ZMod p)` lives in `Mathlib.Algebra.Field.ZMod` (not
  `Data.ZMod.Basic`); `Module.Free.of_divisionRing` needs `Mathlib.LinearAlgebra.Basis.VectorSpace`;
  `Module.Basis.ofVectorSpace` is under namespace `Module.Basis` in this toolchain.
