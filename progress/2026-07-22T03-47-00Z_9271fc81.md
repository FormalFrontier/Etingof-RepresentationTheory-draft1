## Accomplished
Implemented **deliverable 1** of #7225 (dihedral irrep classification): the one-dimensional
character count of `DihedralGroup N`.

- `charOfData u w huN hu2 hw2` : builds a character `DihedralGroup N →* ℂˣ` from generator data
  `u = χ(r 1)`, `w = χ(sr 0)` with `u^N=1`, `u^2=1`, `w^2=1` (multiplicativity via the 4-case
  `r/sr` product rules; `u^2=1` is what makes the reflection cases go through).
- `charEquiv N` : `(DihedralGroup N →* ℂˣ) ≃ {(u,w) // (u^N=1 ∧ u^2=1) ∧ w^2=1}` — the map
  `χ ↦ (χ(r 1), χ(sr 0))`. The `u^2=1` constraint comes from the dihedral relation
  `(r 1)⁻¹ = sr 0 · r 1 · sr 0`, forcing `χ(r 1) = χ(r 1)⁻¹`.
- Counting via `Complex.card_rootsOfUnity`: `card_sqrtOne = 2`, `card_u_odd = 1`,
  `card_u_even = 2`, giving headline theorems `one_dim_reps_card_odd = 2` and
  `one_dim_reps_card_even = 4`.
