## Accomplished

Completed issue #7411 — Example 2.9.13: identify `U(H)/(c-1)` with the existing Weyl algebra.

Previously `Example2_9_13.lean` only formed the enveloping-algebra quotient and gave it a fresh
local abbreviation `WeylAlgebra`, never relating it to the project's actual
`Etingof.WeylAlgebra k` (the free algebra on `x, y` modulo `yx = xy + 1`, from Proposition 2.7.1).
The rename alone did not prove the claimed identification.

Now the file constructs an explicit `k`-algebra isomorphism:

- `heisenbergToWeyl : Heisenberg k →ₗ⁅k⁆ Etingof.WeylAlgebra k`, the Lie hom `x↦x, y↦y, c↦1`
  (the bracket relation `⁅y,x⁆ = c` maps to `⁅y,x⁆ = 1`, i.e. the Weyl relation).
- `envToWeyl` = its lift to `U(ℋ)` via the universal property; `weylCon_le_ker` shows it kills
  `C - 1`, so `toWeyl : HeisenbergWeylQuot k →ₐ[k] Etingof.WeylAlgebra k` descends through the
  `RingCon` quotient (`RingCon.liftₐ`).
- `ofWeyl : Etingof.WeylAlgebra k →ₐ[k] HeisenbergWeylQuot k`, from the free-algebra universal
  property (`x↦Xbar, y↦Ybar`), using `Ybar_mul_Xbar` (the Weyl relation holds in the quotient
  because `YX - XY = C = 1`).
- `toWeyl_comp_ofWeyl` and `ofWeyl_comp_toWeyl` prove both composites are the identity
  (generator extensionality via `RingQuot.ringQuot_ext'`/`FreeAlgebra.hom_ext` on one side,
  `UniversalEnvelopingAlgebra.hom_ext` + surjectivity of `mkₐ` on the other).
- `heisenbergWeylEquiv : HeisenbergWeylQuot k ≃ₐ[k] Etingof.WeylAlgebra k` packages it, with
  simp lemmas `heisenbergWeylEquiv_X/_Y` (and `_symm_x/_symm_y`) for the generators.
