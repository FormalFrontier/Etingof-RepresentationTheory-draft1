## Key patterns discovered

- `set s := …` makes `s` an **opaque** fvar, so a term like `Finset.le_sup` whose result
  type is `… ≤ Finset.univ.sup f` does not unify with `… ≤ s` and Lean whnf-loops to
  exhaustion. Fix: `rw [hs_def]` to unfold `s` before applying the bound.
- A pair-indexed `Finset.sup (fun p => … P p.1 p.2 …)` then forces `isDefEq` to compare
  `P (a,c).1 (a,c).2` with `P a c`, and that comparison whnf-reduces the heavy
  `glCoordToPoly` AlgEquiv into a timeout. Use a **nested** `sup (fun a => sup (fun c => … P a c …))`
  so each `P a c` appears literally — no projection, no whnf.
- For the final per-term field arithmetic `A * D^(s-j) = D^s * (A * D⁻¹^j)`, prove it over
  **abstract scalars** `A D : k` (a `have key : ∀ A D, …`) so `ring`/`rw` never whnf the
  heavy `MvPolynomial.eval`/`Matrix.det` atoms; then `exact key _ _ hD`.
- Bridge equalities involving the heavy `glCoordToPoly` term with `congrArg` + explicit
  motive lambdas rather than `rw`, so kabstract never searches (and whnf-reduces) the
  AlgEquiv term while looking for the rewrite pattern.
