  `d_M = dim_k (A ⧸ M) ≥ 1`. Proof: compose `Etingof.exists_structure_mod_radical`
  (`A / Rad(A) ≃ₐ[k] ∏ End_k (A ⧸ M)`) with `LinearMap.toMatrixAlgEquiv (Module.finBasis …)`

* `Etingof.isBasicAlgebra_iff_of_matrixForm` — any presentation of the *genuine* `A / Rad(A)`
  as `∏_i Mat_{d_i}(k)` with `d_i ≥ 1` is commutative iff every `d_i = 1`; this is
  `semisimpleQuotient_comm_iff` transported off the model.
* `Etingof.exists_matrix_structure_isBasicAlgebra_iff` — the two combined.
* `Etingof.finiteDimensional_endOp`, `Etingof.exists_matrix_structure_cartanAlgebra` — the

  the matrix sizes are `1`.

## Current frontier

The last step of Etingof's sentence is the *indexing*: he writes
`B_𝐧 / Rad(B_𝐧) = ⊕_i Mat_{n_i}(k)`, with the matrix sizes being the multiplicities `n_i`
themselves. `exists_matrix_structure_cartanAlgebra` produces the sizes abstractly, so
"commutative iff every `n_i = 1`" is still not available in terms of `𝐧`.

Filed as #7921. It needs the simples of `B_𝐧` indexed by `ι` (Morita transport through
Theorem 9.6.4) plus `dim_k Hom(P_i, S_j) = δ_{ij}`, i.e. projective covers in a general finite
abelian category. The project has the delta-Hom property only for module categories
(`Chapter9/Theorem9_2_1.lean`, `Chapter9/Proposition9_2_3.lean`), so that is genuinely new
infrastructure and did not fit this session.
