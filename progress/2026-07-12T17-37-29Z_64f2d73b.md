Proved `Etingof.Problem2_7_5.center_of_isOfFinOrder` (issue #6437), discharging the last
genuine `sorry` in `EtingofRepresentationTheory/Chapter2/Problem2_7_5.lean`. The file now

root of unity of order `n = orderOf q` as `Algebra.adjoin ℂ {xⁿ, x⁻ⁿ, yⁿ, y⁻ⁿ}`.

Proof structure (added four private helpers next to the existing monomial machinery):
- `gMono_mem_center_of`: a monomial `gMono (a,b)` with `qᵃ = qᵇ = 1` is central (both reordering
  scalars `q^{b·p.1}`, `q^{p.2·a}` collapse to `1`), via `mem_center_of_comm_qMono`.
- `gMono_natpow_x` / `gMono_natpow_y`: `(xᵐ)^k = x^{m·k}`, `(yᵐ)^k = y^{m·k}` (reordering
  scalars vanish since one exponent is `0`).
- `eq_finsupp_sum_gMono`: every algebra element is the finsupp linear combination of its
  monomials weighted by the `kappa` coefficient function.
- `⊇`: `Algebra.adjoin_le` + each generator central.
- `⊆`: centrality gives `x z x⁻¹ = z`, `y z y⁻¹ = z`; the `kappa_conjX/Y` conjugation lemmas
  force `q^{-r.2}·c(r) = c(r)` and `q^{r.1}·c(r) = c(r)`, so on the support `qᵖ¹ = qᵖ² = 1`,
  i.e. `n ∣ p.1` and `n ∣ p.2` (`orderOf_dvd_iff_zpow_eq_one`); each such monomial is a product
  of generator powers, hence in the adjoin.

The theorem was relocated below `mem_center_of_comm_qMono`/`gMono_mul'` (it depends on the
subtype-level monomial arithmetic defined there); a `/-!` breadcrumb marks the original spot.
