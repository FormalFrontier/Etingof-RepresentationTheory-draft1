## Accomplished

Feature session on issue #7294 (Problem 4.12.6 — character of `V` and tensor products of
irreducibles). Extended `EtingofRepresentationTheory/Chapter4/Problem4_12_6.lean` (sorry-free):

- **Character of `V`.** `Vrep_character`: the character of the `(q-1)`-dimensional irreducible
  `V` (zero-sum functions) is the permutation character minus one,
  `χ_V(g) = affineFixCard g − 1`, where `affineFixCard g = #{x : g·x = x}`. Proof: internal
  direct sum `K → ℂ = zeroSum K ⊕ (constants)` with `LinearMap.trace_eq_sum_trace_restrict`;
  the permutation character `trace_permRep = affineFixCard` via `Equiv.Perm.permMatrix` and
  `Matrix.trace_permutation` (mirrors the `stdRep_character` pattern in `Example4_9_1.lean`).
- **Explicit fixed-point counts.** `affineFixCard_one = q`, `affineFixCard_translation = 0`
  (`⟨1,b⟩`, `b ≠ 0`), `affineFixCard_of_ne_one = 1` (`a ≠ 1`), giving `Vrep_character_one = q−1`,
  `Vrep_character_translation = −1`, `Vrep_character_of_ne_one = 0`.
- **Tensor products (character level)** via `Representation.char_tensor`:
  `charRep_tprod_charRep_character` (`χ ⊗ χ' = charRep (χ·χ')`),
  `charRep_tprod_Vrep_character` (`χ ⊗ V` has character `χ·χ_V`),
  `Vrep_tprod_Vrep_character` (`V ⊗ V` has character `χ_V²`).

Used `Representation.character`/`Representation.tprod` (universe-general) rather than
`FDRep.of V`, because `FDRep.of` needs a `Type 0` carrier and `K : Type*`; this is the same
reason the existing classification transports `V` via `exists_simpleFDRep`. `Representation.character`
is the same object (`trace (ρ g)`).

Axiom check: all new theorems depend only on `[propext, Classical.choice, Quot.sound]`.
