## Key decisions / patterns

- **Explicit map, not abstract idempotent quotients.** `k[S₃]` is non-commutative (the `M₂`
  factor), so Mathlib's `AlgEquiv.prodQuotientOfIsIdempotentElem` (CommRing only) does not apply,
  and there is no Jacobson-density/Burnside in Mathlib. Instead I built the forward algebra map
  `φ = (rhoStd, psi)` explicitly and proved it bijective by a `6 = 6` dimension count.
  - `psi : k[S₃] →ₐ[k] k[t]/(t²)` = the sign character `g ↦ 1 + sgn(g)·t` (via
    `ℤˣ →* kt2` sending `-1 ↦ 1+t`, `u² = 1`). Surjective because `k[t]/(t²) = AdjoinRoot (X²)`
    is generated by `t`.
  - `rhoStd : k[S₃] →ₐ[k] M₂(k)` = the standard rep in the coordinate basis `V ≅ k²`,
    `v ↦ (v 0, v 2)` (the middle coord is forced: `v 1 = v 0 + v 2` in char 2). Surjective by
    **explicit matrix computation**: the six `ρ(g)` span `M₂(k)`; the four matrix units are
    char-2 sums of `ρ(1), ρ((123)), ρ((01)), ρ((02))` (computed via `rhoStd_thc` etc.).
- **Surjectivity of the product** via the central idempotent: `φ(e) = (1,0)`, `φ(1-e) = (0,1)`
  (`rhoStd_eStd`, `psi_eStd`), so `x = e·a + (1-e)·b` hits any `(m,y)`.
- **Bijectivity from surjectivity** via `LinearMap.injective_iff_surjective_of_finrank_eq_finrank`
  with `finrank = 6` on both sides (`finrank_finsupp_self`, `Module.finrank_matrix`,
  `finrank_quotient_span_eq_natDegree`).
- **Gotchas.** `Basis` is now `Module.Basis` in this Mathlib. `simp`'s `map_pow` breaks
  `stdRepr (thc^2)` — pass `-map_pow`. `map_sub`/`map_add` coerce to `.toRingHom`; use `simp only`
  or subalgebra closure (`sub_mem`/`add_mem`) rather than `rw` with an AlgHom-coe lemma.
