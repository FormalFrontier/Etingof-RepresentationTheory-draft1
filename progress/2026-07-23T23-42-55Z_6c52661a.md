## Accomplished

Claimed and fixed issue #7546 — `fix(Ch5): restore Schur-polynomial Proposition 5.21.1`.

`EtingofRepresentationTheory/Chapter5/Proposition5_21_1.lean` no longer elaborated:
four sites failed (`alternant_coeff_kronecker`, `alternant_isHomogeneous`, the
antisymmetry step inside `Proposition5_21_1`, and `degLex_degree_alternantMatrix_det`).

Root cause (single Mathlib drift): `Matrix.det_apply` produces the `ℤˣ` sign scalar
`Equiv.Perm.sign σ • …` as the **zsmul / module action** on `MvPolynomial`, which is
propositionally but not syntactically the coefficient-scalar action that
`MvPolynomial.coeff_smul`, `smul_sub`, and `smul_monomial` are stated for. So `rw`/`simp`
with those lemmas no longer unify (a zsmul instance diamond).

Fix: added three `private` helper lemmas that bridge the two instances once each, using
`defeq`-tolerant `exact` / coefficient-wise arguments:
- `coeff_sign_smul` — `coeff m (sign σ • p) = (sign σ : ℤ) • coeff m p` (via `map_zsmul` on `lcoeff`)
- `sign_smul_sub` — distributes the sign action over subtraction (via `exact smul_sub`)
- `sign_smul_monomial` — `sign σ • monomial d 1 = monomial d ((sign σ : ℤ) : ℚ)` (coefficient-wise)

Routed the four failing sites through these helpers. No new `sorry`/`admit`/axiom.
