## Accomplished

Feature session on **#6239** (Problem 3.9.2(a): `Ext¹` for `ℂ[x₁,…,xₙ]` + 2-dim classification).
Landed **2 of the 3** target theorems in `Chapter3/Problem3_9_2.lean`, both axiom-clean
(`propext, Classical.choice, Quot.sound`):

- **`ext1_self`** — `Ext¹(Vₐ, Vₐ) ≅ ℂⁿ`. Modelled cocycles (source = target = `Vₐ`) as
  `ℂ`-derivations `A → Vₐ` (`cocyclesEquivDer`), used Mathlib's `mkDerivationEquiv`
  (`Der ℂ A Vₐ ≅ (Fin n → Vₐ)`), and `coboundaries = ⊥`, giving `Ext¹ ≅ cocycles ≅ ℂⁿ`.
- **`ext1_subsingleton_of_ne`** — `Ext¹(Vₐ, V_b) = 0` for `a ≠ b`. Every cocycle is a coboundary:
  the generator-values of the associated `(aeval a, aeval b)`-twisted derivation are forced
  proportional to `b − a` by commutativity of `A`, discharged by a twisted-derivation rigidity
  lemma (`twisted_deriv_eq_zero`).

Shared infrastructure added (reused by the remaining theorem too): `sub_C_aeval_mem` (Taylor
`p − p(a) ∈ 𝔪ₐ`), `Vrep_smul_eq` (`p • v = p(a) • v` on `Vₐ`), `VrepEquivC` (`Vₐ ≃ₗ[ℂ] ℂ`,
marked `irreducible` to avoid heartbeat blowups), `mk_eq_aeval_smul_mk_one`.

### Key gotcha discovered
The `ext` tactic **loops** (whnf timeout even at 1M heartbeats) on equations of linear maps over
the quotient module `Vrep a`. Fix: use `refine LinearMap.ext fun w => ?_` instead of `ext w`.
Also `LinearMap.smulRight (VrepEquivC a).toLinearMap _` triggered an instance-synthesis timeout;
reformulating `derToCocycleMap p` as `VrepEquivC a (D p) • LinearMap.id` avoided it.

## Next step

Prove `two_dim_is_extension` (the sub-issue). Design worked out this session:
1. **Common eigenvector** `∃ (b : Fin n → ℂ) (v ≠ 0), ∀ i, xᵢ • v = bᵢ • v`. Over `ℂ` (alg
   closed), 2-dim `U`: if all `xᵢ•·` are scalar pick any `v`; else some `T_j = Algebra.lsmul ℂ (polyAlg n) U (X j)`
   is non-scalar, take an eigenvalue `λ` (`Module.End.exists_eigenvalue`), its eigenspace `E` is
   proper (`≠⊤`, else `T_j` scalar) and nonzero, so `finrank E = 1`; the commuting `T_i` preserve
   `E` (1-dim) so any `v ∈ E \ {0}` is a common eigenvector.
2. **`eigen_smul_eq`**: `(∀ i, xᵢ•m₀ = cᵢ•m₀) → ∀ p, p•m₀ = aeval c p • m₀` (MvPolynomial
   `induction_on`, mirrors `Vrep_smul_eq`).
3. **`oneDim_iso_Vrep`**: a 1-dim `A`-module `M` with `m₀≠0`, `xᵢ•m₀ = cᵢ•m₀` is `≃ₗ[A] Vrep c`,
   via `φ = toSpanSingleton (polyAlg n) M m₀`, `ker φ = 𝔪_c` (using `eigen_smul_eq` +
   `sub_C_aeval_mem` + `aeval_eq_zero_of_mem_maxIdeal`), `φ` surjective (`finrank_eq_one_iff'`),
   then `LinearMap.quotKerEquivOfSurjective` ∘ `Submodule.quotEquivOfEq`.
4. `S := Submodule.span (polyAlg n) {v}` gives `S ≅ Vrep b` (its `restrictScalars ℂ` is
   `span ℂ {v}`, finrank 1); `U ⧸ S` is 1-dim with `xᵢ` acting by some `aᵢ`, giving `≅ Vrep a`.
   Both via `oneDim_iso_Vrep`.
