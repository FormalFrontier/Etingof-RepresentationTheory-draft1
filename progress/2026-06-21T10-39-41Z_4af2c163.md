## Accomplished

Closed #4756 (Ch5 #4745 sub-A): proved **det-twist algebraicity** sorry-free in
a new file `EtingofRepresentationTheory/Chapter5/DetTwistAlgebraic.lean`.

Main deliverable:
```lean
theorem detTwistedSchurModuleRep_isAlgebraic (k) [Field k] [IsAlgClosed k] [CharZero k]
    (N : ℕ) (lam : Fin N → ℕ) :
    Etingof.IsAlgebraicRepresentation N (FDRep.of (detTwistedSchurModuleRep k N lam)).ρ
```
in exactly the `.ρ` form `decompose_polynomial_gl_rep` (and the call site
`schurModule_shift_iso_detTwist`) consumes.

This is the first `IsAlgebraicRepresentation` proof for any concrete rep in the
repo. It was built from three **reusable** lemmas about the predicate:

* `glTensorRep_isAlgebraic` — the diagonal action `g ↦ g^{⊗n}` on `(k^N)^{⊗n}`
  is algebraic. Matrix coefficient in the standard tensor basis (`tBasisAlg`) is
  the monomial `∏ₘ X_{(h m, f m)}` (proved via
  `Basis.piTensorProduct_repr_tprod_apply` + `mulVec_single_one`). The basis is
  reindexed to `Fin (card (Fin n → Fin N))` to fit the `Fin m`-indexed predicate.
* `IsAlgebraicRepresentation.restrict` — restriction to a `ρ`-invariant submodule
  `W` stays algebraic. New coefficients are `k`-linear combinations of the old
  `evalAtGL g (P e d)`, with constant weights from `B.repr (W.subtype (b' c))`
  and `b'.repr (π (B e))`, where `π : Y → W` is a linear projection (from
  `exists_isCompl` / `linearProjOfIsCompl_apply_left`). Key trick: the linear
  functional `φ y = b'.repr (π y) a` lets all sums push cleanly.
* `IsAlgebraicRepresentation.detTwist` — twisting by `det` multiplies each
  coefficient polynomial by `detPolyGL` (the determinant of the generic matrix
  `(Xᵢⱼ)`); `evalAtGL g detPolyGL = det g` via `RingHom.map_det`.

`detTwistedSchurModuleRep = detTwist (restrict glTensorRep)`, so the assembly is
`(glTensorRep_isAlgebraic …).restrict (SchurModuleSubmodule …) …` then `.detTwist`.

Also added helper lemmas `evalAtGL_mul/sum/prod/C/X_inl` (ring-hom behaviour of
`evalAtGL`), reusable for any future algebraicity proofs.
