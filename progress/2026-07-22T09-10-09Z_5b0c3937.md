## Accomplished

Built the crux of Problem 4.12.10 (symmetric-power form) — issue #7289 — in a new file
`EtingofRepresentationTheory/Chapter4/Problem4_12_10_OrbitEval.lean`: the **`G`-equivariant
orbit-evaluation surjection** `⨁ₙ SⁿV ↠ ℂ[G]`, sorry-free and axiom-clean
(`[propext, Classical.choice, Quot.sound]`).

Headline: `Etingof.exists_orbitEval_surjection` — for a finite group `G` with faithful `ρ` on `V`,
there is a surjective `G`-map `φ : (⨁ n, Sym[ℂ]^n V) →ₗ[ℂ] MonoidAlgebra ℂ G` intertwining
`Representation.directSum (fun n => symPowRep ρ n)` with `Representation.ofMulAction ℂ G G` (the
same regular-rep object the sibling assembly issue #7290 consumes).

Supporting pieces (all reusable):
- `evalTensor` / `evalAt` — evaluation of a (symmetric) tensor at a covector `p`, `⨂ₛ vᵢ ↦ ∏ᵢ p vᵢ`.
  `evalAt` is built by descending `PiTensorProduct.dualDistrib` through the `SymmetricPower.mk`
  symmetrization quotient (`AddCon.lift`), so `evalAt_mk_tprod` computes it directly with no
  symmetrization normalization factor.
- `evalAt_symmetricPowerMap` — naturality: `evalAt p n (Sⁿf x) = evalAt (p ∘ₗ f) n x`.
- `orbitCovector` (`p g = (dual ρ) g u`), `orbitCovector_comp`, `orbitCovector_injective`
  (orbit points distinct, from the trivial-stabilizer covector).
- `evalDsum` / `orbitEval` — the assembled map into `G → ℂ`; `evalDsum_directSum` gives its
  left-translation equivariance.
- `subalgebra_eq_top_of_separatesPoints_of_finite` — an elementary algebraic finite
  Stone-Weierstrass (point-separating unital subalgebra of `α → 𝕜`, `α` finite, is `⊤`), via
  Lagrange-indicator `Finset.prod`. This drives surjectivity: the range contains every monomial
  `g ↦ ∏ᵢ (p g) vᵢ`, whose span is a point-separating subalgebra (`Algebra.adjoin_eq_span` +
  `Submonoid.closure_induction`), hence everything.

Wired the new module into `EtingofRepresentationTheory/Chapter4.lean`.
