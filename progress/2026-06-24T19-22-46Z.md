## Accomplished

Closed both documented sorries in
`EtingofRepresentationTheory/Chapter4/Discussion_4_4.lean` (issue #5180).

- **`char_inv_eq_conj`** (`χ_V(g⁻¹) = conj χ_V(g)`): proved via the
  unitarization route (Theorem 4.6.2 made concrete on matrices). In a
  chosen basis `b`, set `M h := toMatrix b b (V.ρ h)`. The averaged
  Hermitian form `H = Σ_h (M h)ᴴ (M h)` is positive definite
  (`Matrix.posDef_sum` + `Matrix.IsUnit.posDef_star_left_conjugate_iff` +
  `Matrix.PosDef.one`), hence invertible, and `G`-invariant:
  `(M g)ᴴ H (M g) = H` (reindex `h ↦ h*g`). Solving gives
  `(M g)ᴴ = H (M g)⁻¹ H⁻¹`, so
  `conj χ(g) = trace (M g)ᴴ = trace (M g)⁻¹ = χ(g⁻¹)` via
  `Matrix.trace_conjTranspose` and `trace_mul_cycle`.
- **Reverse of `self_dual_iff_char_real`**: a real character makes
  `χ_{V*} = χ_V` (using `char_inv_eq_conj`), and over `ℂ` equal characters
  force an isomorphism — exactly the already-proved
  `Etingof.Corollary4_2_4` (characters determine the representation).

`Etingof.Corollary4_2_4` is fixed at `G : Type` (Type 0); generalizing it
to `Type u` makes the Maschke `Injective` instance search blow up, so
instead `self_dual_iff_char_real` is now stated with an explicit
`{G : Type}` binder (it only needs Type 0 to invoke the corollary).
`char_inv_eq_conj` stays universe-polymorphic.
