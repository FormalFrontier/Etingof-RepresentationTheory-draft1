## Accomplished

Proved milestone (ii) of Problem 4.12.8 part (a), issue #6834:
`isCyclic_of_common_fixed_vector` — a finite subgroup `H ≤ SO(3)` all of whose
elements fix a common nonzero vector `v` is cyclic. Statement unchanged; proof
is sorry-free (axioms: `propext`, `Classical.choice`, `Quot.sound`).

Construction (in `EtingofRepresentationTheory/Chapter4/Problem4_12_8.lean`,
new `section CommonAxis` with private helper lemmas):

1. Bridge `SO(3)` matrices to isometries of `EuclideanSpace ℝ (Fin 3)`:
   `toEuclideanLin_inner_eq` (orthogonal ⟹ inner-preserving),
   `toEuclideanLin_comp`, `det_toEuclideanLin`, `toEuclideanLin_one`, and the
   packaged `euclideanIso : SO(3) → (E ≃ₗᵢ[ℝ] E)` with `_apply/_fix/_mul/_det`
   lemmas.
2. Restrict each `euclideanIso g` to the plane `W = (ℝ ∙ v)ᗮ` (dimension 2 via
   `finrank_orthogonal_span_singleton`) using `LinearIsometryEquiv.submoduleMap`
   + `map_orthogonal_equiv` + `ofEq`, giving `ρ : H → (W ≃ₗᵢ W)`, a
   multiplicative, injective assignment.
3. Prove `det (ρ g) = 1` via `LinearMap.det_eq_det_mul_det` on the invariant
   plane: the 1-dimensional quotient map is the identity (it fixes `[v]`, which
   spans `E ⧸ W`), and `det (euclideanIso g) = 1`.
4. Send `g` to its oriented rotation angle
   `φ g = (o.oangle x (ρ g x)).toCircle ∈ Circle`. Multiplicativity from
   `exists_linearIsometryEquiv_eq_of_det_pos` + `rotation_rotation` +
   `Real.Angle.toCircle_add`; injectivity from `arg_toCircle` and agreement of
   the two isometries on `W ⊔ ℝ∙v = ⊤`. Conclude with
   `isCyclic_of_injective_ringHom` composed with `Circle.coeHom`.
