## Key findings

- **`kernelLemmaK'` (#4832) as stated is false** and needs a GL-stability
  hypothesis. Concrete counterexample (`N=2, r=1`): `v = ⟦X₀₀X₁₁⟧ ∈ A/det` is a
  nonzero torus weight vector of weight `(0,0)` for `quotDetTwistRep 1`, so
  `⨆ glWeightSpaceℤ … = ⊥` is false. The route-doc `ν_N = 0` argument is about the
  **highest weights of irreducible GL-constituents**, not raw torus weights; the
  true statement quantifies over **GL-stable** submodules (a nonzero GL-subrep
  contains a full `V_ν`, whose lowest weight forces `ν_N ≥ r ≥ 1`). Posted the
  counterexample + suggested fix (add GL-stability to `kernelLemmaK'_submodule`,
  drop/restate the raw `kernelLemmaK'`) to #4832.
- Consequently (K)'s GL-stability hypothesis `hstable` is currently **unused**
  (the too-strong (K′) does the work); it is carried so the exported (K)
  statement is the genuine book lemma and becomes load-bearing once (K′) is
  corrected. This is the one linter warning on the new file.
- Lean detail: rewriting a weight relation inside a `⟨val, proof⟩` Subtype fails
  (motive depends on the proof); do `Subtype.ext; rw [SetLike.val_smul]; exact …`
  so the rewrite/`exact` runs past the dependent proof via defeq.
