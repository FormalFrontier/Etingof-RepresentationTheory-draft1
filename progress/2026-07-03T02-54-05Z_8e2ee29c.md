## Key patterns / decisions

- Characters are class functions: `irrepA5_char_eq` reduces `χ_i(g)` to the tabulated value
  `chiA5 i (classIdxA5 g)` via `classIdxA5_spec` + `FDRep.char_conj`. Note `FDRep.char_conj V g h
  : V.character (h*g*h⁻¹) = V.character g` — rewrite the character *argument* only (a bare
  `rw [← hc]` also rewrites the `g` inside `classIdxA5 g`, breaking the RHS).
- **Do the golden-ratio arithmetic in `ℚ(√5)`, not `ℂ`.** A first attempt closed the `5·5·5`
  case split directly over `ℂ` with `push_cast <;> (first | ring | linear_combination …·√5² )`;
  it ran for **44 minutes** (the `first` backtracking runs `ring` over `ℂ`-with-`√5` under a
  huge heartbeat budget, ×125). The fix: prove `nA5_char_Q5` in `Q5` where the `√5²=5` relation
  is baked into `Q5.mul`, so each case is pure rational `norm_num` on `re`/`im` (no `√5`), then
  transport to `ℂ` once via a hand-proved `Q5toC_mul` (+ existing `Q5toC_add`, and
  `Q5toC_q5Nat`). Whole file now builds in ~4 min.
