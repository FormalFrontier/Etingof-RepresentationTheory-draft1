## Decisions and patterns

- **`abbrev`, not `def`, for the quotient carrier.** A `def` would need every instance
  restated via `inferInstanceAs`; `abbrev` lets unification find `RingCon.instRing` and
  `RingCon.instAlgebra` directly. This follows `Example2_9_13.lean`'s `HeisenbergWeylQuot`.
- **Deliberately *not* `@[ext]` on `hom_ext`.** Since `PresentedAlgebra` is a reducible
  `abbrev`, the attribute would key on `RingCon.Quotient` and fire on unrelated
  `AlgHom`-out-of-a-ring-congruence goals project-wide. Left as a plain theorem.
- The whole `TwoSidedIdeal.span_le` → `TwoSidedIdeal.mem_ker` → `RingCon.ker_apply` →
  `liftₐ` descent chain is lifted verbatim from `Example2_9_13.weylCon_le_ker`; that file
  is the reference implementation for noncommutative quotients in this project.
- `RingCon.mkₐ_surjective` takes its scalar ring as an *implicit* `α`
  (`variable (α) in` applies only to `mkₐ`), so it needs `(α := k)`, not a positional `k`.
