## Current frontier

Route taken, in case a successor needs the same pattern. The issue suggested a reusable
"quotient of a free module by the span of orbit-differences is free on the orbits" lemma. I
built the equivalent by hand as an explicit `LinearEquiv.ofLinear` pair rather than as a
general lemma, because the book's `symRelSubmodule` is spanned by `T - s(T)` for *arbitrary*
`T`, not just basis vectors, so the generic orbit-difference statement does not apply
verbatim. The two maps are

* `symPowToFinsupp = Submodule.liftQ _ (Finsupp.lmapDomain k k tupleSym ∘ₗ (tensorPowBasis b n).repr)`,
  descending because `tensorPowToSymFinsupp ∘ₗ permAct σ = tensorPowToSymFinsupp` (checked on
  the tensor basis via `Module.Basis.ext`, which handles arbitrary `T` for free);
* `finsuppToSymPow = Finsupp.linearCombination k (fun s => symTprod (b ∘ symIndexRep n s))`,
  using `symIndexRep = Function.surjInv tupleSym_surjective`.

The combinatorial core is `exists_perm_of_map_univ_val_eq`: two families `f g : ι → I` on a
finite `ι` with the same multiset of values differ by a permutation of `ι`. This is not in
Mathlib; the short proof is to compare fibre cardinalities (`Multiset.count_map` +
`Fintype.card_subtype`) and glue the fibrewise equivs with `Equiv.ofFiberEquiv`. It is stated
for a general `Fintype ι`, so it is reusable.

Useful names discovered: `Basis.piTensorProduct` lives in the **root** namespace (not
`Module.Basis`, despite `Module.Basis` being the structure); `Multiset.map_univ_val_equiv`;
`Fin.univ_val_map`; `List.ofFn_congr`; `Sym.card_sym_eq_choose`.
