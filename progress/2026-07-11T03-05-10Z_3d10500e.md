## Key patterns

- Subalgebra-on-ambient scalar action: `Algebra.smul_def` rewrites `c • f` to
  `algebraMap ↥S A c * f`; `algebraMap ↥periodicSubalg C(ℝ,ℝ) c` is *defeq* to `↑c`, so
  `rw [Algebra.smul_def]; rfl` closes `(c • f) y = (↑c) y * f y` (mul is pointwise/defeq).
  A single `rw [Algebra.smul_def]` already rewrites both occurrences (they are syntactically
  identical), so don't double it.
