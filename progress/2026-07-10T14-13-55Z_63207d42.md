- Added `[IsAlgClosed k]` and restated the RHS as a **nonzero-ratio** proportionality:
  `∃ c : k, c ≠ 0 ∧ f − c • f' ∈ coboundaries`. This is the faithful form of the book's part (d)
  (`ℙ Ext¹(W, V)` plus the split class). I found the issue's disjunctive form
  `([f]=0 ∧ [f']=0) ∨ (∃ c≠0, [f]=c[f'])` is redundant: the both-trivial case already satisfies
  `∃ c≠0, f − c•f' ∈ B¹` (coboundaries is a subspace), so the single clause suffices and is
  cleaner.
- Proved `⇐` in one line via the pre-existing helper `ext_iso_of_sub_smul_mem_coboundaries`.
- Proved `⇒` by block-decomposing the intertwiner `φ = [[α,β],[γ,δ]]`, deriving the four block
  equations, and casing on the lower-left block `γ : V → W` (Schur, `bijective_or_eq_zero`):
  - `γ = 0`: `α, δ` are `A`-linear, hence scalars `s, t` (Schur over alg-closed,
    `Etingof.Corollary_2_3_10`), both nonzero because `φ` is invertible (`map_eq_zero_iff` /
    surjectivity + `IsSimpleModule.nontrivial`). The `(1,2)` block gives `s•f − t•f' = dβ`, so
    `f − (t/s)•f' ∈ B¹` with `t/s ≠ 0`.
  - `γ` iso (only when `V ≅ W`): the `(2,2)` and `(1,1)` blocks force **both** `f` and `f'` to be
    coboundaries (via `γ⁻¹` from `LinearEquiv.ofBijective`), so `f − 1•f' ∈ B¹`.
