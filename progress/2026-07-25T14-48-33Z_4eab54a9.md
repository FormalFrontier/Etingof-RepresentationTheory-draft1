Key infrastructure that made the induction two lines each:

* `lie_smul_emb_smul_emb` — `⁅c • emb m A, d • emb n B⁆ = (c*d) • emb (m+n) ⁅A, B⁆`;

  whole `ad(ȳ)`-string is one lemma;

**4. Full fidelity + linear independence** (deliverable 4 did fall out of the same induction, so it
was not split off):

```lean
theorem gbar_loopFam₄ (I : LoopIdx) : gbar k (loopFam₄ k I) = loopCoef k I • loopVec k (loopRev I)
theorem linearIndependent_loopFam₄ (h2 : (2 : k) ≠ 0) (h3 : (3 : k) ≠ 0) :
    LinearIndependent k (loopFam₄ k)
```

**The index is reversed, and the issue's guessed statement `gbar (loopFam₄ I) = coef I • loopVec I`
is false as written.** `ad(ȳ)` walks each graded string *down* from its top vector (`gone 4`,
`gzero 2`) while `gone` / `gzero` are enumerated *up* from `gone 0` / `gzero 0`. Hence the new
involution `loopRev : LoopIdx → LoopIdx` (identity on `base`, `Fin.rev` on the index inside each
degree) and `loopCoef` carrying the string coefficients `![1, -1, -1, 3, 6]` (odd) and `![1, 1, -1]`
(even) times `6ᵐ` resp. `3·6ᵐ`. Linear independence is then
`(linearIndependent_loopVec).comp loopRev loopRev_injective |>.units_smul _`, pulled back through
`LinearIndependent.of_comp (gbar k)`.
