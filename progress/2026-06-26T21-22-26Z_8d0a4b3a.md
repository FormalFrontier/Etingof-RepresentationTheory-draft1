## Accomplished

Discharged the `sorry` in `Etingof.krullSchmidt_unique`
(`Chapter9/KrullSchmidt/Exchange.lean`, issue #5480) — the uniqueness half of
Krull–Schmidt. Two finite biproducts of indecomposables that are isomorphic now
provably have the same factors up to a reindexing bijection.

Supporting work added in the same file (all axiom-clean except for the
pre-existing upstream `clength` sorries in `Length.lean`):

- **`exists_isIso_component`** — a strengthening of the existing Azumaya exchange
  lemma that returns the *component* `s ≫ biproduct.π Y k` as the iso (not just
  "some iso exists"). This explicit component is what makes the top-left entry of
  the peeled binary biproduct invertible. `indecomposable_summand_iso_factor` was
  refactored to derive from it (no behavioural change; the `Introduction_9_7.lean`
  consumer still builds).
- **`peelIso`** — `⨁ g ≅ g i₀ ⊞ ⨁ Subtype.restrict (· ≠ i₀) g`, built on Mathlib's
  `biproduct.toSubtype`/`fromSubtype` (so the iso laws fall out of
  `fromSubtype_toSubtype`/`ι_toSubtype`/`fromSubtype_π`). Fully axiom-clean.
  `@[reassoc (attr := simp)]` projection lemmas `peelIso_inv_inl`, `peelIso_hom_fst`.
- **`krullSchmidt_unique`** — strong induction on `Fintype.card κ`. Base case
  (κ empty ⇒ ⨁Y zero ⇒ ⨁Z zero ⇒ μ empty). Inductive step: pick `k₀`, find the
  matching `m₀` via `exists_isIso_component`, peel both sides with `peelIso`, and
  cancel the matched summand with Mathlib's Gaussian elimination
  `Biprod.isoElim` (the cancellation theorem — the heavy categorical content was
  already in Mathlib). The reindexing bijection is assembled from
  `Equiv.sumCompl`/`sumCongr` on the singleton-complement split.

Key reuse discovery: Mathlib already provides the matrix Schur-complement
cancellation (`CategoryTheory.Biprod.isoElim`) and the subtype-biproduct splitting
API (`biproduct.toSubtype`/`fromSubtype` with `fromSubtype_toSubtype = 𝟙`), which
turned a feared ~hundreds-of-lines proof into a clean assembly.
