Key new declarations:
- `invol_isCommutator_A4std` (decide): every involution of the concrete `A₄` (`A4std`) is a
  single commutator of two of its elements.
- `nontriv_linear_one_on_invol` (**P1**): a one-dimensional character of an order-12 `H ≅ A₄` is
  `1` on every element of order dividing 2. Transports an involution of `H` to `A4std`, writes it
  as a commutator there, pulls the commutator back into `H`, and kills it with the
  abelian-valued character.
- `A4std_sq_or_cube`, `A4std_invol_count` (decide helpers).
- `indA4_nontriv_linear_value` / `_char_all` / `_target_value` / `_target_char_all` + main theorem.

Proof structure of the value lemma (induced character `(5,-1,1,0,0)` on the five classes):
- `1a`,`2a`: the summand `σ(x g x⁻¹)` equals `1` when in `H` (identity / P1 on involutions), so
  the sum is the plain conjugator count — reuses `countH_eq12` + `twisted_A4std` exactly like the
  trivial character.
- `5a`,`5b`: no conjugate of a 5-cycle lands in `H` (order 5 ∤ 12), sum is empty.
- `3a` (the crux): reindex the twisted sum over `↥H` weighted by conjugator counts
  (`hkey`), show the count is `3` on 3-cycles and `0` on order-≤2 elements (`hN`, via
  `conjCount_shift` + `twisted_eq_cr1`), then combine with the nontrivial-character
  sum-to-zero identity (`hF1`) and the involution-count `= 4` (`hAsum`) to get `3·(0−4) = −12`,
  hence character value `−1`.
