Proof strategy (direct free-basis sandwich):
- Added generic helpers in a new `FreeCaseAux` section:
  - `piProdEquiv` — uncurry `(Fin n → Fin m → X) ≃ₗ[k] (Fin n × Fin m → X)`.
  - `finTensorPiEquiv` — `(Fin n → M₁) ⊗ₖ (Fin m → M₂) ≃ₗ[k] (Fin n × Fin m → M₁ ⊗ₖ M₂)` for any
    `k`-modules, built from `TensorProduct.piLeft`/`piRight`, with an on-tmul simp lemma.
  - `precompEquiv` — precomposition by an `R`-linear equivalence as a `k`-linear equivalence of
    Hom-spaces.
- In the theorem: upgraded `finTensorPiEquiv k A₁ A₂ n m` to an `A₁ ⊗ A₂`-linear equivalence `B`
  (external free-basis iso) using `hF` for the `smul` compatibility, then `ofBijective`.
- Identified source `(Aᵢ^{nᵢ} →ₗ Nᵢ) ⊗ₖ …` with the matrix space `Fin n × Fin m → N₁ ⊗ N₂` via
  `Basis.constr k` (needs `SMulCommClass Aᵢ k Nᵢ`, auto from `IsScalarTower.to_smulCommClass'`),
  the target via `precompEquiv B` + `constr`, and the middle via `finTensorPiEquiv N₁ N₂`.
- Showed `homTensorHom` equals the resulting composite equivalence `E` by checking the forward
  identity `tgtE (F (f₁ ⊗ f₂)) = midE (srcE (f₁ ⊗ f₂))` pointwise on `(i, j)` (avoids any
  `Finsupp` sum), concluding `Function.Bijective` from `E.bijective`.

`#print axioms` for both `homTensorHom_bijective` and `homTensorHom_bijective_free` is limited to
`propext, Classical.choice, Quot.sound`.
