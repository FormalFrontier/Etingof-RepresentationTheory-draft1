- **`isDynkinDiagram_degree_le_three`** — no vertex of a Dynkin diagram has four or
  more incident edges. Proof: if `v` had degree ≥ 4, pick a 4-element subset `S` of
  its neighbours (`Finset.exists_subset_card_eq`) and test positive definiteness
  against the affine-star vector `x = 2·e_v + ∑_{j∈S} e_j`. The key observation is
  that `xᵢ·(A x)ᵢ ≤ 0` for **every** vertex `i` (it is `0` at the centre `v` where
  the row sum is `2·2 − 4 = 0`, `≤ 0` at each neighbour where it is
  `1·(2 − 2 − ∑adj) = −∑adj ≤ 0`, and `0` off the support), so
  `xᵀ A x = ∑ xᵢ(A x)ᵢ ≤ 0` by `Finset.sum_nonpos`, contradicting `0 < xᵀ A x`.
  The bound needs only that off-diagonal Cartan entries `−adj ≤ 0`, so no
  tree/no-cycle input is required — fully local and self-contained.
