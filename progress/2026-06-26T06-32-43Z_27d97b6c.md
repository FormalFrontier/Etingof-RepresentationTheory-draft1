The proof rests on a single private **absorption lemma**
`renormCharElt_mul_classFunction`: for a simple `V : FDRep ℂ G` and any class
function `z`, the convolution `χ̃_V ⋆ z` is a scalar multiple of `χ̃_V`. This
is the "central element acts as a scalar" Schur argument: the equivariant
operator `S_z = Σ_y z(y)·ρ(y⁻¹)` lies in `(linHom V.ρ V.ρ).invariants`, which
is 1-dimensional for simple `V` (Schur), so `S_z = σ • id`
(`exists_scalar_of_invariant`, mirroring the scalar-extraction pattern of
`Proposition4_7_1_ii`); the convolution coefficient identity then follows by a
reindex + trace computation `∑_x χ(x) z(x⁻¹w) = tr(ρ(w) ∘ S_z) = σ·χ(w)`.

From absorption:
- **idempotency** is the case `z = χ̃_V`; the scalar is pinned to `1` by
  evaluating at `g = 1` and using `FDRep.char_orthonormal`.
- `χ̃_V ≠ 0` since `χ̃_V(1) = (dim V)²/|G| ≠ 0`.
- **primitivity** is the standard minimal-idempotent argument: if
  `χ̃_V = a + b` with `a,b` nonzero idempotents in the centre, then `ab = 0`
  (char 0, `2` is a unit), so `a = χ̃_V·a = σ_a • χ̃_V` is forced to equal
  `χ̃_V` (and likewise `b`), giving `χ̃_V = 2χ̃_V`, contradiction.

Notably this needed **no** explicit Wedderburn `∏ℂ` decomposition of the
centre — the absorption lemma supplies exactly the "`e·z` is a scalar multiple
of `e`" fact that earlier notes (#5349) expected to require that
infrastructure.
