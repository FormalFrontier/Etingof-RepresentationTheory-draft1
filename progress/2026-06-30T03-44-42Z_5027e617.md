## Accomplished

Fixed the fidelity gap in Corollary 6.8.2 (issue #5624).

The book states: "Let Q be a quiver, and let V be any indecomposable representation.
Then d(V) is a positive root." The previous `Etingof.Corollary6_8_2` instead took a bare
integer vector `d : Fin n → ℤ` plus an explicit hypothesis `hreflect : ∃ vertices p,
iteratedSimpleReflection … d = simpleRoot n p`. That hypothesis *is* the hard
representation-theoretic content (the conclusion of Theorem 6.8.1), so requiring it as an
input made the theorem strictly weaker than the book's claim, with no connection to actual
quiver representations.

Changes:
- Renamed the purely combinatorial implication in `Corollary6_8_2.lean` to
  `Etingof.isPositiveRoot_of_iteratedReflection_eq_simpleRoot` (a nonneg nonzero vector
  reducible to a simple root is a positive root). Its statement and proof are unchanged;
  only the name and docstring were updated to mark it as the combinatorial core.
- Defined the faithful `Etingof.Corollary6_8_2` in `CoxeterInfrastructure.lean`: it
  quantifies over an arbitrary indecomposable representation `ρ` of an orientation `Q` of
  the Dynkin diagram `adj` and concludes `IsPositiveRoot n adj d(V)`. The reflection
  sequence is *produced* from the representation via the representation-level Theorem 6.8.1
  (`indecomposable_reduces_to_simpleRoot`), not assumed.
- Reduced `indecomposable_bilinearForm_eq_two` to a thin wrapper
  `(Corollary6_8_2 …).1.2`, removing the duplicated nonneg/nonzero derivation.

The faithful theorem placement (in `CoxeterInfrastructure.lean` rather than
`Corollary6_8_2.lean`) is forced by the import DAG: `indecomposable_reduces_to_simpleRoot`
lives in `CoxeterInfrastructure`, which imports `Corollary6_8_2`, so the representation-level
corollary cannot sit upstream in `Corollary6_8_2.lean`. The combinatorial core remains there.

`#print axioms Etingof.Corollary6_8_2` reports only `[propext, Classical.choice, Quot.sound]`
— no `sorryAx`. The faithful corollary is genuinely proven.
