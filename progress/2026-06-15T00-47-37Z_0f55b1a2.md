## Accomplished

Claimed #4723 (close the four reversed-leaf branches of
`starRep_kQ_leaf_equalities`, `Chapter6/FieldGenericStar.lean:839`). During
scope analysis I **refuted the theorem**: it is false for every orientation
in which leaf edge `{0,4}` is reversed.

- **Counterexample (m = 1).** Orientation: leaves 1,2,3 forward, leaf 4
  reversed (`0→4`, map `starProj4_F = starFirst_F`). Take `S = span{e₁}`
  (not `N`-invariant, since `N e₁ = e₀`). Set center `U₁ = S×S`, `U₂ = Sᶜ×Sᶜ`,
  every leaf `W₁ i = S`, `W₂ i = Sᶜ`. This satisfies all hypotheses
  (invariance under `starEmbed1/2/Diag` and `starFirst`, complementarity) but
  conjunct 4 (`jordanShiftLinGen`-invariance of `W₁ 1 = S`) fails.
- **Bigger finding.** The same `U₁ = S×S` / `U₂ = Sᶜ×Sᶜ` is a genuine
  invariant complementary decomposition, so `starRep_kQ` is **decomposable**
  in reversed-leaf-4 orientations. Root cause: `starProj4_F = starFirst_F`
  has kernel `= range starEmbed2_F`, degenerate with leaf 2; the `λ·id+J`
  correction only protects the *forward* leaf-4 datum.
- Confirmed `starRep_kQ_leaf_equalities` has **no consumers** (orphan lemma).
- Filed **#4728** (full write-up + counterexample + recommendations).
- Commented on **#4703** (its center-crux goal is unprovable as stated for
  reversed-leaf orientations).

No code changed — there is nothing honest to land against a false statement.
