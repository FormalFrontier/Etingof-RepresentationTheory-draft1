### jq-tally caveat (re-flagged from cycle 988)

The `from_entries` jq pattern used in earlier cycle
handoffs and re-tried this cycle silently produces
`null`-valued counts because the keys come from a
projection, not `group_by` output. The reliable shape
for label tallies is:

```bash
gh issue list --label agent-plan --state open --limit 100 \
    --json number,labels \
    --jq '.[] | (.labels | map(.name) | sort | join(","))' \
  | sort | uniq -c | sort -rn
```

That shell-side tally is what produced the composition
above. Recording it again here so future planner cycles
can copy the working incantation verbatim instead of
re-deriving (and re-tripping over) the jq form.
