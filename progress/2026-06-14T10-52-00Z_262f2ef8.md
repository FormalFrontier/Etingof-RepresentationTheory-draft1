   over-strong.** The internal edge `3-4` carries `LinearMap.id` in both

   `hOrient`-supplied orientation of the edge, derives the one-sided
   containment `W_i⟨3⟩ ≤ W_i⟨4⟩` (or reverse) from invariance through that
   identity arrow, then upgrades both inclusions to equalities via
   `compl_le_forces_eq` (finrank-monotone + IsCompl-finrank-sum, genuine
   linear algebra — `FieldGenericInfiniteType.lean:296`). Carriers align:
   `obj⟨3⟩ = obj⟨4⟩ = Fin (2*(m+1)) → F`, passed explicitly as `V`. The
   equality genuinely requires the identity-edge hypothesis (the two
   vertex slots are independent submodules of complementary pairs); it is
   not trivially true. Hypotheses are satisfiable (trivial decomposition
   `W₁=⊤, W₂=⊥`), so non-vacuous.

2. **`d6tilde_core_F` / `d6tilde_core4_F` / `d8tilde_core_F` /

### Portability caveats for porters (deliverable 4)

- **D̃₆ has no `proj` siblings yet.** D̃₈ front-loaded
  `core{,6}_F_proj{1,2}` for the reversed leaf orientations; D̃₆ did not.
  The D̃₆ non-canonical branches (#4541) will need reverse-pull lemmas
  analogous to D̃₈'s (port `d5tilde_core_F_proj{1,2}` /
  `d5tilde_core3_F_proj{1,2}` with the `5,6` relabelling), or inline the
  projection argument.
- **`gamma_containment_F` does not port verbatim to D̃₈.** D̃₆ couples its
  two centers across a *single* identity edge `3-4`, so the lemma takes
  one collapse hypothesis `Wmain⟨3⟩=Wmain⟨4⟩`. D̃₈ couples across the
  chain `2-3-(id)-4-(id)-5-(id)-6`: the γ image lands at vertex 3 and must
  transport to vertex 6 through *three* identity collapses. #4546's D̃₈
  chain-propagation + gamma-containment is genuinely more work and must
  collapse `⟨3⟩=⟨4⟩=⟨5⟩=⟨6⟩`. D̃₈ sub-A correctly ships **no** chain_collapse
  / gamma_containment (deferred to #4546) — consistent with scope.
- **Naming convention is consistent and should be followed.** Left branch
  core is always `core_F` (vertex 2); right branch core is named by its
  branch-vertex index: `core3_F` (D̃₅ v=3), `core4_F` (D̃₆ v=4),
  `core6_F` (D̃₈ v=6). D̃₇ porters (#4533) should expect `core5_F` for the
  D̃₇ right branch (vertex 5).
- **Preserve the 4th-conjunct nilpotent twist** in any parametric core
  (#4535): the `1→6` leg is `N y ∈ ⟨6⟩`, not `y ∈ ⟨6⟩`.
