## Key finding: the theorem statement is FALSE at q = ±1

`finrank_irreducible_le_of_isOfFinOrder` as stated assumes only `IsOfFinOrder q`. At `q = 1`
(`orderOf q = 1`) the relation `(q-q⁻¹)(ef-fe) = K-L` degenerates to `K = L`, `e, f` become free, and
2-dimensional simple modules exist — so `dim V ≤ 1` is false. Same at `q = -1`. The book assumes
`q ≠ ±1` throughout; the successor must add `(hq2 : (q : ℂ)^2 ≠ 1)`. Documented in sub-issue #6613.
