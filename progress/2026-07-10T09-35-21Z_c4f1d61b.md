## Accomplished

Claimed the field-general base-change monotonicity issue **#6127**
(`#(simple k[G]-modules) ≤ #(simple K[G]-modules)` for a field extension `K ⊇ k`), found the
original issue's proof route (semisimplicity of `K ⊗_k M` + Hom-adjunction disjointness) to be
**separability-obstructed** — the call site uses `K = AlgebraicClosure k`, which can be inseparable
over `k`, so `K ⊗_k M` need not be semisimple — and **decomposed it** into a clean,
separability-free route:

```
#simple(k[G]) = #simple(k[G]/rad)            -- #6135 (radical-quotient invariance)
             ≤ #simple(K ⊗_k (k[G]/rad))     -- #6136 (semisimple base-change count; the math crux)
             ≤ #simple(K[G])                 -- #6134 (surjection K[G] ↠ K⊗(k[G]/rad) decreases count)
```

Only base change of the *already semisimple* `k[G]/rad` is used, so no separability is required.
Created sub-issues **#6134, #6135, #6136**, left a `Decomposed into …` breadcrumb with the full
assembly recipe on #6127, and `coordination skip`ped #6127 to `replan`.

Then **proved #6134** in a new file `Chapter4/SimpleModuleClassesBaseChange.lean` (registered in
`Chapter4.lean`), sorry-free:

* `ModuleCat.restrictScalars_full_of_surjective` — restriction of scalars along a surjective ring
  hom is a **full** functor (new; every `R`-linear map between `T`-modules is `T`-linear because
  every `T`-scalar is `f` of an `R`-scalar). Combined with the existing `Faithful` instance this is
  fully faithful.
* `Etingof.isoClassesMap` / `Etingof.isoClassesMap_injective` — a fully faithful functor injects on
  isomorphism classes of objects (reusable; complements `isoClassesEquivOfEquivalence`).
* `Etingof.natCard_simpleModuleClasses_le_of_surjective (k) (f : R →+* T) (hf : Surjective f) :
  Nat.card (SimpleModuleClasses T) ≤ Nat.card (SimpleModuleClasses R)` for finite-dimensional
  `k`-algebras — the deliverable.

`#print axioms` on all three shows only `propext, Classical.choice, Quot.sound` (no `sorryAx`).
