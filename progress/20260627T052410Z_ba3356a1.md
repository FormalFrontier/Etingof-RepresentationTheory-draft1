One-shot dispatch on **#5487** (Schur-Weyl #5, steps 2-4: a *general* polynomial
`GL_N`-representation is semisimple, beyond the weight-homogeneous case handled by

```
theorem polynomialRep_isSemisimple
    (M : FDRep k (Matrix.GeneralLinearGroup (Fin N) k))
    (hpoly : IsPolynomialRepresentation N M.ρ) :
    IsSemisimpleModule (GLAlg k N) (Representation.asModule M.ρ)
```

(`k : Type`, `[Field k] [IsAlgClosed k] [CharZero k]`, `N : ℕ`.)
`#print axioms` → only `propext, Classical.choice, Quot.sound`. No `native_decide`.

Proof architecture (total-degree grading via the central scalar):
- `eq_of_le_iSupIndep_iSup_top` — generic modular-lattice lemma: `T i ≤ E i`,
  `iSupIndep E`, `⨆ T = ⊤` ⟹ `T i = E i`.
- `polynomialHomogRep_isSemisimple` — the homogeneous case: `decompose_polynomial_gl_rep`
  gives `M.asModule ≃ₗ[GLAlg] ⨁ⱼ (Lⱼ).asModule` with each `Lⱼ` simple, and a finite
  direct sum of simples is semisimple (`IsSemisimpleModule.congr`).
- central scalar `t₀ = (2 : k)` of infinite order (`t0_pow_injective`);
  `scalarGL_central` (scalar matrices are central, via `Matrix.scalar_commute`);
  `glWeightSpace_le_scalar_eigenspace` (the weight space for `μ` lies in the
  `t₀^(∑μ)`-eigenspace of `M.ρ (scalarGL t₀)` — reproduces the private
  `scalarGL_eq_noncommProd` locally as `scalarGL_eq_noncommProd'`).
- `degComponent d := ⨆_{∑μ=d} glWeightSpace μ`; `scalarEigenComp d := eigenspace(Φ, t₀^d)`.
  `degComponent_eq_scalarEigen` (the two coincide; `Φ`-eigenspaces are `iSupIndep`,
  `degComponent`s span by regrouping `h_span`), hence `degComponent_stable`
  (`GL`-stability, as eigenspaces of a central operator).
- `glWeightSpace_restrict` (weight space of a sub-rep = `comap subtype` of `M`'s),
  feeding `degSubrep_h_span` / `degSubrep_h_homog` / `degSubrep_isAlgebraic` so each
  `degSubrep d` satisfies the homogeneous hypotheses.
- `asSubmodule_semisimple_of_toRep` — bridges `↥(asSubmodule σ)` to
  `σ.toRepresentation.asModule` via `Representation.asModuleHomOfIntertwiner` of the
  inclusion (the `LinearEquiv.refl` route fails: the two `GLAlg`-module instances are
  not defeq).
- assembly: `isSemisimpleModule_of_isSemisimpleModule_submodule'` over `d : ℕ` with
  `p d := asSubmodule (degSubrep d)`, `⨆ p = ⊤` from `iSup_degComponent` via
  `restrictScalars`.

Wired into `EtingofRepresentationTheory/Chapter5.lean` (aggregator) so CI builds it.
