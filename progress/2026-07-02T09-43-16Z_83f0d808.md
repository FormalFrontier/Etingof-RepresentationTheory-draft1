The key new infrastructure is a **uniform centralizer-order computation** that
avoids per-type canonical forms entirely. For a non-scalar `g`, the commutant of
`g` in the 2×2 matrix ring is the 2-dimensional algebra `{α • 1 + β • g}`
(`exists_smul_add_smul_of_commute` + `smul_one_add_smul_injective`), so the group
centralizer `C_G(g)` is exactly the invertible combinations, counted by the pairs
`(α, β)` with `det(α • 1 + β • g) ≠ 0`. That determinant is the quadratic form
`α² + tr·αβ + det·β²`, whose discriminant is `disc g`; the number of vanishing
pairs is `1 + (q−1)·r`, where `r ∈ {1, 2, 0}` is the per-`β` root count governed by
`disc g = 0` / nonzero-square / non-square (parabolic / split / elliptic). This
gives centralizer orders `q(q−1)`, `(q−1)²`, `q²−1` uniformly, reusing the existing
`Etingof.quadratic_one_root_zero_disc` / `quadratic_two_roots` / `quadratic_no_roots`.

Each per-type count then divides the type's element count by the class size
`|G|/d` via the class-count bridge `ncard_conjClasses_image_mul_centralizerCard`
(landed earlier for this issue), packaged in the new helper `count_from_bridge`.

New declarations: `exists_smul_add_smul_of_commute`, `smul_one_add_smul_injective`,
`det_smul_one_add_smul`, `card_detZero_pairs`, `centralizerCard_eq_card_units`,
