## Key insight (resolving the prior circularity skips)

Two earlier agents skipped this issue, concluding the planned trace argument is
circular and requires Young-symmetrizer primitivity (`c_λ k[S_n] c_λ = k c_λ`)
not present in the project. They were right that the *whole-space* trace route
(issue body steps 1-5) is circular: through the bimodule iso it just re-derives
`finrank(SchurModuleSubmodule) = finrank(range f_iλ) · finrank(L_iλ)`, which
gives no independent constraint.

The non-circular route they missed: the **diagonal** value of the existing
character-orthogonality identity `youngSym_trace_kronecker'` is exactly `α`
(its diagonal case is `trace_mulLeft_youngSym_eq'`, an independent `ℂ[S_n]`
computation). So `trace(c_λ|_S) = α` directly, *without* the whole-space trace
or any dimension bridge. Since `c_λ|_S = α • π` with `π` idempotent,
`trace(π) = α⁻¹ · trace(c_λ|_S) = 1`, and `IsProj.trace` gives
`finrank(range π) = trace(π) = 1`. The "primitivity content" was already in the
project, packaged as `trace_mulLeft_youngSym_eq'`.

The proof is a direct diagonal counterpart of `youngSym_action_vanishes_off_block`
(same `S` / `h_label` interface): off-block uses `if_neg` (trace 0 ⟹ f = 0),
the special block uses `if_pos rfl` (trace α ⟹ rank-1 scaled projection).
