## Deliverables

Add four top-level theorems to
`EtingofRepresentationTheory/Chapter6/FieldGenericD5Tilde.lean`
(immediately after the existing `d5tilde_core_F` / `d5tilde_core3_F`
trio at lines 482–590), one per reversed leaf edge:

1. `d5tilde_core_F_proj1` — `core_F` analogue for the `e02 = 2→0`
   reversed orientation. Instead of the canonical push
   `hMain_02 : starEmbed1_F x ∈ Wmain ⟨2⟩` for `x ∈ Wmain ⟨0⟩`,
   takes the reversed pull
   `hMain_20 : ∀ w ∈ Wmain ⟨2⟩, starFirst_F F m w ∈ Wmain ⟨0⟩`
   (and analogously for `Wother`). Conclusion: `starEmbed1_F x +
   starEmbed2_F z ∈ Wmain ⟨2⟩ → x ∈ Wmain ⟨0⟩ ∧ z ∈ Wmain ⟨1⟩`
   under whatever 1→2 hypothesis (canonical or reversed) the caller
   supplies — for the e02-only-reversed sub-case the e12 push is
   still canonical, so the lemma may be specialised to that
   combination.

2. `d5tilde_core_F_proj2` — `core_F` analogue for `e12 = 2→1`
   reversed. Uses `starSecond_F` for the pull and assumes the
   canonical 0→2 push on the other leaf.

3. `d5tilde_core3_F_proj1` — `core3_F` analogue for `e43 = 3→4`
   reversed (line 800 of the case-split). Uses `starFirst_F` as a
   pull from `Wmain ⟨3⟩` to `Wmain ⟨4⟩`.

4. `d5tilde_core3_F_proj2` — `core3_F` analogue for `e53 = 3→5`
   reversed (line 798). Uses `starSecond_F` as a pull from
   `Wmain ⟨3⟩` to `Wmain ⟨5⟩`.

Each sibling proof should follow the **same skeleton** as the
canonical `d5tilde_core_F` / `d5tilde_core3_F`:

- Decompose the input `w = starEmbed1_F (starFirst_F w) + starEmbed2_F
  (starSecond_F w)` via the new `center_decomp_F` (already in
  `FieldGenericStar.lean`).
- Use the projection pull hypotheses to land the two projection
  components in `Wmain` at the leaf.
- Use `starFirst_F_starEmbed*_F` / `starSecond_F_starEmbed*_F`
  identities (`FieldGenericStar.lean:420–450`) to identify the
  projection components with the original `(x, z)` arguments.
- Conclude via `embed_sum_zero_F` (already in `FieldGenericStar.lean`).

The bodies are expected to be ~30–40 lines each, mirroring the
existing canonical-direction proofs at lines 500–532 (`d5tilde_core_F`)
and 558–590 (`d5tilde_core3_F`).
