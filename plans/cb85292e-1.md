The Lean statement is:

```
theorem Theorem_Dynkin_classification (n : ℕ) (adj : Matrix (Fin n) (Fin n) ℤ) (hn : 1 ≤ n) :
    IsDynkinDiagram n adj ↔
    ∃ t : DynkinType, ∃ σ : Fin t.rank ≃ Fin n,
      ∀ i j, adj (σ i) (σ j) = t.adj i j
```

i.e. a graph on `n ≥ 1` vertices is a Dynkin diagram **iff** it is isomorphic
(vertex-relabelling `σ`) to one of the standard types enumerated by
`DynkinType` (`A n`, `D n`, `E 6/7/8` — confirm the exact constructor list in
`EtingofRepresentationTheory/Chapter6/DynkinTypes.lean`).
